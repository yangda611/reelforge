# AI 分镜丝滑转场 Skill（无首尾帧硬拼方案）

本 Skill 用于在不依赖“上一段真实尾帧 → 下一段首帧图生视频”串行等待的前提下，通过**分镜衔接规划 + 提示词双向设计**，让相邻两段 AI 生成视频自然衔接。

## 核心原则

1. **首帧契约优先（`t=0` 不可违背）**：每段视频必须从当前已生成首帧/草图的真实状态出发向后演进。**禁止**为了迎合上一镜结尾而编写与当前首帧矛盾的开场姿态。
2. **双向协同而非孤立写词**：写第 `N` 镜提示词时，必须同时参考第 `N-1` 镜（承接其动势、视线或构图方向）与第 `N+1` 镜（在末尾 `1~1.5s` 主动铺垫出画引导或过渡落点）。
3. **只用画面内真实存在的元素**：做遮挡、视觉引导或匹配构图时，只能调用当前场景/首帧中合理存在的元素；**禁止**为了炫技凭空捏造飘花、烟雾或不存在的物体。
4. **场景/时空大跳保留干净硬切**：跨场次、跨时空或叙事明确转折时，不做勉强甩镜，优先使用相似构图切或干净的视点落稳硬切。

## 五大无首尾帧转场手法（单镜 / 跨镜通用）

在同场次或相邻情绪连贯镜头中，根据前后镜的 `visual_description` 与景别选择最契合的一种：

| 手法 | 适用场景 | 第 `N` 镜末尾怎么写 | 第 `N+1` 镜开头怎么接 |
| :--- | :--- | :--- | :--- |
| **1. 动作衔接 (Action Match)** | 同一连续动作、人物走位/转身/开门/拿取物品 | 让动作推进到关键势能阶段（抬步、转身未完、伸手探出），**不留结尾静止停顿** | 从当前首帧起沿**同一屏幕方向与运动幅度**完成动作 follow-through（落脚、回正、接住） |
| **2. 视线/视觉引导 (Eyeline / Visual Lead)** | 人物看某处切入所看对象、对话反应、悬念揭示 | 末尾明确写出人物转头/抬眼/视线落向画面特定方向，或镜头推向触发视线的对象 | 若首帧一致，顺着视线方向/正反打空间关系建立主视角或反应动作，保持轴线清楚 |
| **3. 前景遮挡 (Foreground Occlusion)** | 同场景移步换位、时空小跨度切换 | 利用镜头中**已有前景**（门框、廊柱、走过的路人、衣袖、桌面器物）在末尾近距离扫过遮挡部分或大部画面 | 镜头从前景旁侧/移开后顺势展开当前首帧主体动作，保持遮挡物运动方向连贯 |
| **4. 同向甩镜 (Same-Direction Whip Pan)** | 快节奏追逐、情绪突变、空间快速横移 | 末尾摄影机向左侧或右侧**加速平滑甩出**，形成动感过渡势能 | 开头沿**相同水平方向**快摇入画并柔和刹稳，落定在首帧主体上 |
| **5. 相似构图/形状/色彩 (Form / Framing Match)** | 跨时空转场、回忆切入、主体对照 | 末尾镜头终点把主体或几何轮廓/主色调稳稳框在画面特定位置（如居中特写、圆形器物、对称构图） | 下镜首帧若处于相近构图/色温区间，开场先延续相似构图节奏再缓缓拉开或推进 |

> **声画先导补充**：需要衔接但画面差异大时，可在上镜末尾保留环境声余韵或动作触发声（推门声、脚步声、风声），与下镜开头声场呼应。

## Seedance 2.0 较长片段（8~15s）结构策略

当使用支持较长单次生成的模型（如 Seedance 2.0 且时长 `>= 8s`）时：
1. **段内递进多阶段动作**：在尊重首帧的前提下，按时间先后自然串联 2~3 个动作或景别推进（起幅状态 → 主动作展开 → 镜头收束），避免过早做完动作陷入僵直或倒放。
2. **段尾必留衔接落点**：在最后阶段给出明确的镜头终点与下一镜引导（动作余势、视线方向、构图落点或前景擦边遮挡），不写“突然黑屏/硬停”。
3. **只用正统参考语法**：严格保留系统资产清单中的 `图片1`、`音频1` 编号，不输出 `@` 符号，不把 `duration`、`resolution`、`ratio` 等 API 参数写进提示词正文。

## 执行检查清单

- [ ] **首帧不打架**：提示词第一动作与当前首帧/草图 `t=0` 画面完全兼容。
- [ ] **单向运动不倒放**：无“前倾又退回”“伸手又缩回”等往复动作，无静止动词充当主动作。
- [ ] **相邻有照应**：同场次相邻镜头屏幕方向、视线轴线、运动节奏协调；有下一镜时结尾留出了自然的动作/视线/构图桥接落点。
- [ ] **跨场不硬拗**：场次头或时空明显切换时，果断采用干净落幅硬切或构图呼应，不硬加无关特效。
