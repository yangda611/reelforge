# AI 分镜丝滑转场 Skill（完整生产版 · 含跨集过渡）

> **核心定位**：在不依赖串行“上一段真实尾帧 → 下一段首帧”阻塞等待的前提下，通过 **六大转场策略 + `prev_beat ↔ current_beat ↔ next_beat` 双向衔接 + `ep - 1` 跨集锚点继承**，让整集分镜及跨集接续自然流畅。

---

## 一、四条不可违背的转场底层约束

1. **首帧 `t=0` 契约优先**：每段视频必须从当前已生成首帧/草图的真实画面（景别、站位、手持物、光线）起步；**严禁**为了迎合上一拍结尾而编写与当前首帧矛盾的开场姿态。
2. **双向协同而非孤立写词**：编写第 `N` 拍提示词时，必须同时读取：
   - **前承 (`prev_beat`)**：若是全集第 1 拍 (`beat_number == 1`) 且 `episode > 1`，**必须先读取上一集 (`ep - 1`) 的结尾剧情、悬念与最后一拍分镜/视频提示词**，以此作为 `prev_beat` 跨集承接；
   - **后启 (`next_beat`)**：明确在末尾 `0.5~1.5s` 为下一拍铺好“动作余势 / 视线指向 / 前景遮挡 / 同向甩镜 / 构图颜色落点”，**不提前演完下一拍的核心动作**。
3. **只调用画内真实存在的元素**：做遮挡、图形匹配或视觉引导时，只能利用当前场景与首帧中合理存在的实体（门框、廊柱、货架、衣袖、杯口、光影）；**禁止**凭空捏造飘花、黑烟、炫光或突然黑屏。
4. **单段单向演进、跨场干净收束**：同一段内保持单向动势不倒放；遇到**真正跨地点、跨时间、记忆闪回**时，不做违和甩镜，优先使用**图形/构图/色彩匹配、J-Cut/L-Cut 声画先导**，或**稳妥落幅后干净硬切**。

## 二、六大核心转场手法与写词公式

根据前后两拍的场景关系、景别组合（参考 `ai-shot-scale-combinations`）与运动趋势，选择最自然的一类：

| 转场类型 | 最佳适用情景 | 上一拍 (`N`) 末尾怎么写 | 下一拍 (`N+1`) 开头怎么接 | 验收标准与忌讳 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 动作顺接<br>(Action Match)** | 同一连续动作接力（伸手→抓起、转身→面向海边、开门→车门拉开） | 让动作推进到**关键势能未尽瞬间**（手已伸至桌面边缘、半转身、抬脚迈出），不完全停死 | 从当前首帧承接**同一屏幕方向与运动阶段**继续完成 follow-through（握住提起、转正面向目标），**严禁重头再次起手** | 运动轨迹与左右手固定不反；复杂奔跑/腾空优先切动作中段而非静止末帧 |
| **2. 相似构图/形状/色彩匹配<br>(Form / Color Match)** | 跨时空跳转、跨集呼应、隐喻对比（门把→车门把、圆盘→满月、蓝画布→湖泊） | 末尾把匹配物（几何轮廓 / 同位置主体 / 主色调光影）稳稳框在指定画幅比例位置并短暂停稳读取 | 下一拍首帧同坐标/同轮廓/同主色调呼应起幅，保持 0.5–1s 构图对齐感后再推进或拉远揭示新环境 | **借轮廓不等于材质/主体强行融化变形**；允许清晰匹配切，不必加“无形变融化特效” |
| **3. 视线引导与正反打<br>(Eyeline / Shot-Reverse)** | 人物察觉异样→揭示目标、双人对话对峙、情绪反应落点 | 末尾明确写出人物**抬眼/转头/视线投向画面特定方位（左上方/画右/门外）**，面部停在微顿好奇或警觉态 | 遵循 180° 轴线规律，新镜头按视线指向揭示所看客体，或切至被看者反应镜头，光照与时间线吻合 | 视线指向与对象方位一致；双人对话切镜不无故交换左右站位 |
| **4. 前景遮挡 / 合理黑场<br>(Foreground Occlusion / Wipe)** | 同场景移步换位、时空小跨度、门洞进入 | 利用画面内**实心不透明前景**（门板、墙柱、货架、行人肩背、暗门洞）随横移或靠近从一侧扫过并遮蔽大部/全部画面 | 镜头顺着**相同运动方向**从另一处前景边缘滑出或从暗门退出，顺势展开新首帧主体动作 | 遮挡物必须画内本来就有；无实心暗处时不硬写“镜头一黑” |
| **5. 急速甩镜动势<br>(Whip Pan)** | 快节奏追逐、突然听见声响转望、情绪陡转（同空间内） | 前段稳住构图，末 0.5–1s 摄影机向**明确左右方向**高速横摇，场景水平高速掠过产生自然动态模糊 | 下一拍同向高速甩入画面，迅速减速稳稳刹车落定在首帧主体上 | **摄影机向右摇时景物向左掠**，禁止写反；跨不相干时空时改用干净硬切或匹配切 |
| **6. 声音先导/延后与音色匹配<br>(J-Cut / L-Cut / Sound Match)** | 画面差异较大但情绪/事件强关联、转场或跨集开篇 | **J-Cut**：尾段留出下一拍环境声/脚步/门响先入耳；**L-Cut**：本拍末尾台词/情绪余音跨入下一拍首段 | 开头先承接上一段余音或被先导音效触发反应（转头/停手/开门），再展开本拍画面动作 | 留出自然气口不切断尾音；OS/旁白时禁止画面人物张嘴对口型 |

## 三、跨集丝滑过渡铁律（`Episode N-1` → `Episode N`, `N > 1`）

当制作第 `N` 集（`N > 1`）的**剧本分镜**与**开篇视频提示词（尤其是 Beat 1）**时，**禁止在未读取第 `N-1` 集内容的情况下盲写开场**：

1. **必须先读上集资产**：读取第 `N-1` 集的 `content_summary`、`cliffhanger`（集尾钩子），以及最后 2~3 个 Beat 的 `scene_id`、`narration`/`dialogue`、`visual_description`、`video_prompt` / `seedance2_prompt`。
2. **判断跨集衔接模式**：
   - **同场延续（Cliffhanger 直连）**：第 `N` 集 Beat 1 与第 `N-1` 集最后一拍处于同一地点与紧接着的时刻 → 直接采用 **动作顺接 / 视线承接 / 固定机位微动继承**，继承上集末拍的景别、光线色温、人物站位、手中道具与余势。
   - **换场呼应（新时间/新地点开篇）**：两集集间出现换场 → 采用 **相似构图/颜色匹配（Form/Color Match）** 或 **J-Cut/L-Cut 声画桥梁**（如上集末拍关键声响/台词回声或视觉几何锚点引出本集首拍）。
3. **首拍提示词显式声明**：在 Beat 1 的分镜与视频提示词生成上下文中，注入上一集结尾镜头摘要与末尾状态，保证观众连续刷下一集时体感连贯如同一部作品。

## 四、ReelForge 主流视频模型执行规范（Seedance 2.0 & 图生视频通用）

1. **5 要素写词公式**：`[初始景别与机位] + [运镜路径与速度(参考阿泽运镜卡)] + [前中后景视差/焦点变化] + [主体三阶段动作(起幅承接→过程→段尾转场预留)] + [光影声画与反漂移约束]`。
2. **4~15s 节奏分段**：`4~5s` 专注单个主动作/反应特写；`6~9s` 常规动作+微运镜；`10~15s` 用时间段推进 2~3 个因果连贯动作或景别推进，防止做完动作剩余秒数陷入僵直/倒放。
3. **音画口型严格分离**：仅现场有声对白（`dialogue`）写明人物张嘴说话与口型情绪；旁白（`narration`）与内心独白（`monologue/OS`）时**明确要求人物闭口**，仅通过眼神、神态和动作演绎。
4. **零废话与资产语法**：不重复参考图已锁定的静态外貌衣着长文；只用系统提供的正统编号（如 `图片1`、`音频1`），不输出 `@`，不把 `resolution/duration/ratio` 等 API 字段写进画面提示词；禁用 `8K、超高清、电影感、杰作` 等空词。
