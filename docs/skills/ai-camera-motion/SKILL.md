# 阿泽 AI 运镜 SKILL（ReelForge 生产优化版）

> **核心原则**：写出真实三维空间路径、前中后景视差证据与光学因果，而不是堆砌“电影级、大片感、8K、史诗级”等空洞形容词；并且清晰拆分**摄影机自身运动**与**主体自身动作**。

---

## 一、五组核心摄影控制量与光学因果律

1. **五组控制量（按需选取，不强求每镜全改）**：
   - ① **机位与路径**（起止方位、机位高度、运动轨迹）
   - ② **焦距与视野**（等效广/标准/长焦视角，影响画面裁剪与背景倍率）
   - ③ **对焦目标与距离**（静态锁定或随动追焦、或两层之间的 `Rack Focus` 转焦）
   - ④ **光圈与景深观感**（写可见虚实层次，如“眼睛锐利、远景灯光柔化”，不盲写 f/1.2 或 f/16）
   - ⑤ **速度与节奏**（匀速 / 缓推 / 急加速 / 缓停，匹配 4~15s 镜头时长）

2. **真实位移 vs. 原地旋转 vs. 变焦的铁律**：
   - `推(Dolly In) / 拉(Dolly Out) / 横移(Truck) / 升降(Pedestal) / 环绕(Orbit)` **必然改变三维空间位置与遮挡关系**（近处前景快速掠过、远景缓慢移动形成视差）。
   - `摇(Pan) / 俯仰(Tilt)` **只是原地改变镜头朝向**，不能冒充空间横移或露出现实中被实体墙完全挡住的后方空间。
   - `滚转(Roll)` 只是绕光轴倾斜画面，不能冒充绕行环绕。
   - **主体与相机分离**：推近时静止主体必然变大；若要推近同时保持主体占比稳定，必须明确是主体同步后退，或使用 **Dolly Zoom（希区柯克变焦）**。

3. **Dolly Zoom 光学方向校准（`f/d` 近似守恒）**：
   - **压迫版（背景放大向人物压近）**：摄影机真实**后退**（距离 `d` 增大）+ 焦距同步**加长**（`f` 增大，Zoom In），持续追焦人物眼睛，头肩占比近似稳定，纵深门框/走廊相对人物膨胀压近。
   - **展开版（背景缩小空间骤开）**：摄影机真实**靠近**（`d` 减小）+ 焦距同步**缩短**（`f` 减小，Zoom Out），头肩占比近似稳定，背景迅速退远展开。
   - ⚠️ **严禁**写作“前进+长焦还要求主体不变”或“禁止一切变焦”来写希区柯克镜头。

4. **用可见视差证明运镜**：
   - 每个推进/横移/环绕镜头都必须写出至少 1 个**前景/中景/背景空间锚点位移**（如“近处货架/门框从画面左缘快速滑出，中景人物占据中心，后方冷柜缓慢改变角度”），防止模型偷懒成 2D 图片数码裁切放大。

5. **固定机位 (`[LOCKED FIXED CAMERA]`) 兼容铁律**：
   - 当镜头标记为 `[LOCKED FIXED CAMERA]` 或剧照/固定机位表演锁定时，**严禁**加入推拉、摇移、环绕或手持晃动，保持三脚架固定机位 + 构图稳定，全靠画面内**主体动作调度、表情眼神切换或 Rack Focus 转焦**传递张力。

## 三、三段式视频提示词黄金结构（适配 ReelForge 4~15s 节奏）

1. **段首承接起幅 (`0–1s` / 严守首帧 `t=0` 契约)**：从当前已生成首帧/草图的真实景别、机位高度、角色位置与姿态起步，自然继承前一拍 (`prev_beat`) 的动作势能或转场引线。
2. **中段运镜展开与主体动作分离 (`1s–(T-1)s`)**：先写摄影机选定的一条主路径与速度（或明确固定机位），再写主体独立的物理动作过程与交互接触，并补上前中后景视差/焦点变化与现场对白声线（旁白/OS 时角色保持闭口）。
3. **段尾落幅定格与下拍预留 (`最后 0.5–1.5s`)**：镜头缓停或延续动势，停在可阅读的终态构图，为下一拍 (`next_beat`) 留出明确的转场交接点（未完动势 / 视线指向 / 前景擦边 / 同向甩出 / 构图对称），**禁止未完先切或强加不存在的烟雾/黑屏**。

## 四、常见失败快速修正矩阵

| 失败现象 | 根因诊断 | 提示词优先修复策略 |
| :--- | :--- | :--- |
| 写了推进但成片只像图片数码放大 | 缺少前中后景距离分层 | 增补近景门框/桌面物从画框边缘滑出与后景遮挡变化，固定焦距 |
| 环绕运镜变成人物像陀螺原地转圈 | 未写清机位世界坐标路径与主体朝向 | 写“摄影机从人物左后方绕至左前方，人物朝向原方向站稳不随相机自转” |
| 固定机位却画面乱飘或莫名推近 | 未明确锁定机位且动作过小 | 开头写“固定机位摄影机全程静止无推拉无晃动”，用更清晰的主体动作驱动变化 |
| 动作往复倒放（伸手又缩回、站起又坐下） | 单段写入闭环往返动作或冗余动作 | 强制单向演进轨迹，从起幅动作推进到末端状态即止，给关键动作留足时间 |
| 全片狂糊或微距尺度崩塌 | 全局强运动模糊或位移尺度过大 | 仅对快速掠过的近景边缘加方向模糊，微距将移动严格限制在毫米/厘米级 |
| Dolly Zoom 主体忽大忽小或融化 | 推拉方向与变焦方向写反或背景无纵深 | 明确“后退同时加长焦距使头肩占比近似不变”，选走廊/门框等纵深线背景 |
