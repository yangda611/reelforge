# AI 分镜：15 套景别组合与情景应用（ReelForge 生产优化版）

> **核心痛点解决**：避免整集分镜反复停留在单一`中景`（如连续多拍同角度站位对话），导致每段视频“不搭嘎”、节奏平庸或跳切。每组镜头必须由**叙事目的**驱动景别切换，让相邻 Beat 之间既有视觉信息增量，又有动作/视线/空间锚点衔接。

---

## 一、五级基础景别与叙事边界

景别由**主体在画幅中的占比**与**可见环境范围**决定（而非单纯机位米数或广角标签）：

| 景别 | 画面范围与构图边界 | 核心叙事作用 | ReelForge 分镜用法 |
| :--- | :--- | :--- | :--- |
| **远景 (LS / ELS)** | 环境占主导，人物在画面中较小 | 交代地点、空间规模、人与环境关系；表现孤独、压迫或宏阔 | 场次开篇建立镜头 / 跨集或转场宏大收尾 |
| **全景 (FS)** | 人物从头到脚完整入画，含站位与环境通道 | 看清全身动作、走位轨迹、双人距离与轴线关系 | 动作调度起点、双人对峙关系建立 |
| **中景 (MS)** | 通常取人物腰部或膝部以上 | 交代手部操作、人物互动、常规对话（动作偏下时需放宽） | 推进叙事与身体交互的主力景别，**忌连续 3 拍同角度中景硬切** |
| **近景 (MCU)** | 通常取人物胸部或肩部以上 | 清晰捕捉眼神变化、微表情与情绪递进 | 对话反应、情绪升级、准备转入特写前的蓄力 |
| **特写 (CU / ECU)** | 突出面部或单一关键局部（眼睛、手、钥匙、手机屏幕、器物） | 强制观众聚焦关键线索、触感瞬间与心理冲击 | 线索揭示、动作触发点、Match Cut 图形/动作锚点 |

> **光学提醒**：用`远景`不等于必须超广角畸变，用`特写`不等于把背景糊成完全不可辨色块；景深与视野服务于画面信息。

## 二、15 套经典景别组合表（按镜头数与情绪情景速查）

> 注：数字（2~6 镜）表示节奏单元长度，景别可按需要重复，但**每一拍必须提供新信息（新动作阶段 / 新线索 / 新反应 / 新关系）**。

### A. 2 镜微单元：干脆说明一件事
| 编号 | 景别序列 | 适用情景 | 情绪目标 | 结构模板与衔接关键 |
| :--- | :--- | :--- | :--- | :--- |
| **01** | **中景 → 特写** | 出门拿钥匙、按按钮、拆礼物、拔刀蓄力 | 干脆、有重点 | 第1拍`中景`伸手取物/起势；第2拍`特写`手指抓住并提起（**动作从伸出继续往下走，绝不重新伸手**，左右手/物体方位锁定）。 |
| **02** | **特写 → 近景** | 收到消息、看到照片、发现异常线索 | 惊喜、温暖、失落、震惊 | 第1拍`特写`信息源（手机/信笺/异物）；第2拍`近景`主体看完抬头给出情绪反应（**先看清触发源，再看反应**）。 |
| **03** | **特写 → 远景** | 地点反差揭晓、露营/穿越/悬崖揭示 | 意外、震撼、豁然开朗 | 第1拍`特写`局部接触（放咖啡杯/落脚）；第2拍`远景`揭示同一物体与人物身处的宏大环境（**核心道具、桌面与主光方向必须上下一致**）。 |

| 编号 | 景别序列 | 适用情景 | 情绪目标 | 结构模板与衔接关键 |
| :--- | :--- | :--- | :--- | :--- |
| **04** | **远景 → 中景 → 特写** | 寻物、发现地面/角落线索、进入暗角 | 好奇、逐步聚焦 | `远景`环境与人物停步 → `中景`弯腰视线投向目标 → `特写`目标物与环境参照（**人物视线向量必须指向第3拍物体位置**）。 |
| **05** | **特写 → 中景 → 远景** | 演奏、技艺展示、从局部沉浸到天地开阔 | 从专注走向惊艳 | `特写`手指触碰器物 → `中景`人物姿态与受光 → `远景`完整空间揭晓（**器物型号、受光侧与环境声贯穿三拍**）。 |
| **06** | **双人全景 → 近景A → 近景B** | 朋友商量、情侣交流、试探交锋 | 真诚、试探、关系变化 | 先用`全景`锁定两人左右站位与轴线，再分别切`近景A`与`近景B`完成对视问答（**严禁无故交换左右屏幕位置，视线保持一左一右相对**）。 |

## 四、ReelForge 全链路四条强制执行铁律

1. **先定目的与组合，再逐拍写词**：同一场戏连续 Beats 禁止在无导演意图下出现 3 个以上同角度同站位`中景`；每换一拍必须检查“新景别带来了什么新信息（新动作阶段 / 新反应 / 新道具 / 新方位）”。
2. **景别跳跃靠信息与视线兜底**：`远景→特写` 或 `特写→远景` 完全允许，只要有清晰的视线引导、声音触发或同物同光锚点；真正糟糕的跳切是“同角度同人物只无故放大一点点”。
3. **跨拍空间与资产一致性**：检查角色左/右屏幕朝向、固定服装、手持道具（左手还是右手）、光线方向与运动方向。连续动作切在“进行中”（第 N 拍未做完，第 N+1 拍接着完成，不重头起手）。
4. **严格分离“静态分镜瞬间 (`visual_description`)”与“视频运动轨迹 (`video_prompt`)”**：
   - **单张草图/首帧生图 (`visual_description`) 写法**：只写当前这一瞬间的画面定格 —— **`【景别 + 机位角度】+ 人物与固定服装 + 画面左右位置与朝向 + 当前动作定格阶段 + 场景前景/后景与光线`**。绝不在单帧图描述里塞入“先走过去、再拿起杯子、最后转身离开”的多阶段时间流。
   - **图生视频 (`video_prompt` / `seedance2_prompt`) 写法**：从首帧定格态出发，写清 **`[起幅承接] 从什么姿势/运动起点开始 → [中段运镜与主体轨迹] 朝哪个方向推进、产生什么视差 → [落幅预留] 在何种姿态/构图/视线处结束以便接下一拍`**。
