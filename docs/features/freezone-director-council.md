# 虾画：六部门导演会诊

在虾画里，虾导默认用六部门导演组处理场次设计、分镜、续镜和叙事提示词设计。你可以直接描述任务，无需说「六部门」或「YD」。查素材、挪节点、改错字和运行已有工作流直接按原操作处理。

可以选中剧本、人物、场景或道具节点，也可以直接在聊天里给一场戏。选择已生成的剧本节点时，会诊读取剧本成稿。参考图由虾导读取，供导演组使用的是有依据的文字观察。

## 用法

1. 在虾导里说「把选中的剧本拆成分镜，先给我预览」或「接着上一镜设计下一镜」。
2. 确认节奏、预计总长、风格、画幅和要交付什么。例如：「横屏 16:9，写实偏冷，按剧情定时长，同时预留视频和首帧提示词。」仅在已知平台限制时指定单段上限，不需要为凑秒数加镜。
3. 看预览的「分镜号｜时间｜镜长｜画面重点」。可以说「第 2 镜等抬眼后再切」或「这版确认，出视频和首帧提示词」。更改剧本、参考节点或交付类型后，先出新预览。
4. 要放回画布，可说「把这版分镜和提示词放到画布，不生成」。会诊本身不改节点、不重连、不出图、不跑视频。只有明确要求开始生成时才进入原有生成流程。

## 交付

- 总导演和场记先并行整理创作方向及接戏基线；表演指导、镜内执行导演、摄影指导再并行设计。总导演裁决后，由提示词导演做可执行性检查。
- YD 负责先定故事节奏，再按剧情断点分段和分镜。Gaven 的正向视觉描述用于静帧、首帧、尾帧；这些提示词只写单帧可见内容。
- 经用户要求才从指定预览编译。视频按段出词，图像提示词按镜号出词。六个岗位独立逐镜核对；可修的问题只补一次受影响的交付并复核，有阻塞则不交付可执行提示词。可以要求虾导展开指定镜头的六岗意见。
- 输入过长时选一场戏，不会静默截掉剧本。素材改动后需要刷新预览。模型调用使用项目原有的 Freezone 文本模型；无需安装外部 ZIP 或打开通用代理工具。
