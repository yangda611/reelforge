# 平台证据与时间语法

只在完整输入适配、入口变化、参数审校、参考能力或生成返修时读取；不为纯预览加载整套平台表。按产品、模型版本、入口、模式分别核实，不把模型名称当共用规格。

<a id="p1"></a>
## P1 参数记录

内部记录可选生成时长/单次上限V、图片视频音频数量与规格、首尾帧/声音参考/比例/时间控制支持；每项带实际页面、官方说明或用户入口证据和核对日期。没证据不填数字；用户陈述标“用户提供，未独立核实”。同入口/版本/模式未变且无相反证据复用记录，不重复问；新入口/冲突只更新受影响项。核实失败可继续准备稿，未核参数不能假称可投喂。空参数表不进入执行块。

门槛卡片的“每份最长30秒（推荐）/15秒”是计划上限选项，标“以实际入口为准”，不是已核实V；用户说明入口单次只支持15秒时按入口。素材引用/绑定机制同样不能以文本标签假设已实现，具体见[素材](assets.md)和[就绪](readiness.md)。

<a id="p2"></a>
## P2 已有写法依据与适配

既有来源：[火山方舟Seedance 2.5提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)，原核对日期2026-11-07；不是本轮新核实，产品/入口不同或有新证据以新资料为准。

- Seedance 2.0按镜头序号理解，不依赖时间戳对齐；保留“分镜N”和清楚先后，所列秒数仅标计划。2.0不建议多视图人物拼图；需要时用单张正面半身/全身替代，不用标签保证解决重复主体。
- Seedance 2.5可用连续整数秒时间区间；素材内累计边界取最近整数，不逐镜各自取整，块内总长就是该输入L。亚秒反应用“紧接着、半拍、句后半”等写入整数窗；精细自然计划保留内部/必要块外映射。取整挤掉台词或动作时移动相邻边界，不删内容，完整稿说明实际取整差。
- 整片连续模式只能剪整份首尾余量，不能逐内镜扣掉取整差；单镜独立各自适配各自L。2.5在5主体以内支持人物多视图为既有指南信息，仍核当前入口；编号优先沿用用户已确认映射；无既有映射的新任务才按首次出场顺序分配/上传，新增用未占号；入口实际标签不同则统一迁移所有引用，不混两套。文字映射同一人的多视图，空间参考职责仍依当前构图/布局分工。
- 未说明入口沿用通用完整模板，不预设支持任意秒数/数量/首尾机制。已锁一镜到底超已知能力时说明限制，只有授权且能力支持才延长/连续分段，不暗切或保证无缝。

<a id="p3"></a>
## P3 Kling 3.0（可灵 3.0）

用户明确要求可灵/Kling、或只做单镜表演提示词时，默认按 **Kling 3.0** 出提示词；沿用本包的表演写法（[acting](acting.md)、[facial-timing](facial-timing.md)、[performance-dimensions](performance-dimensions.md)），句法按可灵入口习惯改写。要点：

- 采用直陈式时序散文，按动作节拍（acting beat）写“0:00–0:0X”区间或先后顺序，不要逐镜表格化秒数。
- 每个节拍写一个主动作＋一到两个辅助通道＋一个时机/运动修饰；面部动作按 Onset/Apex/Offset 分层错峰，不用一条统一曲线。
- 结尾保留连续性与负向约束：动作与面部变化保持连续，不要表情突变、假笑冻结、面部变形、身份漂移、姿态复位或意外切镜。
- 身份、服装、首帧、构图、位置等锁定写在节拍之外作全局约束；台词与声源单独列。
- 输出模式三选一：只出提示词（Prompt 模式）／动作逻辑＋节拍表＋最终提示词（导演模式，默认）／概念与边界解释＋引用（研究模式）。
- 用户指定其他入口时按该入口证据改写，不把可灵语法当电影通则；本节为写法记录，不是当前任务所有参数的核实证明。术语与科学边界见[evidence-boundaries](evidence-boundaries.md)。

这些是特定指南的写法记录，不是当前任务所有参数的核实证明；默认无硬字幕/BGM及读法放在台词前等内容以[声音](audio.md)为权威，不重复复制一套。
