# 完整提示词编译

只在用户要求完整版、确认预览并要求细化、或返修完整稿时读。完整稿保留细节；预览摘要不能替代原稿对白和已确认条件。不得精简掉后半镜头。

## 1. 块外与模式

走过新故事闸门的完整交付，先给一次条件回执和时长结论（见[确认](gate.md)、[计时](timing.md)）；完整编译必读[双时钟容量与评估](timing-capacity.md)，逐份核L和保留映射。已确认预览不变可说“沿用已确认计划”。首份输入前集中列一次素材状态及“制作准备稿／可投喂稿／无参考稿”；用户未提供素材也未明确纯文字时按[assets AS01](assets.md#as01)默认准备稿列槽位，只有无参考稿才不列清单。

- **整片连续**：一大段一份输入，可含多镜，不等于一镜到底。块外标题 `大段K｜分镜1—N｜成片D秒｜全局A—B秒`，说明素材L与必要剪取；新段镜号和局部时间归一/归零。
- **单镜独立**：每镜一份自足输入，块外 `大段K-分镜N｜事件｜全局A—B｜保留d｜素材L`；每份从0秒起，段内镜号继续递增。另报大段并集长度D。
- D、L、平台V、用户U（另给成片段上限则U_D）、全局映射、剪取、后期分工放块外。顺接累加，叠化/并屏按实际保留并集计成片，各完整素材L另核。无变速映射：全局时刻=保留区间全局起点+素材局部时刻−剪取起点。未经授权不变速。
- 生成余量只放可舍弃起/收势，关键事件、原对白、揭示、接触必须在最终保留区间。参数未知标待核实，不把目标秒数当入口支持值。一镜到底超已知能力须说明限制，在授权内选延长机制/时长调整/拼接，不暗切。
- 启用完整空间蓝图时，第一输入前给一次不超过8行的俯视草图及逐机位清单，标“空间示意｜审阅用，不投喂”；清单里的A位、B位等代号只给用户审阅与内部核对，执行代码块内不得出现代号或“见空间示意”，每镜都展开成“在哪个地标的哪一侧、朝哪拍、背景是什么”；补的背景陈设列块外。
- 多个生成大段按[段界](story.md)执行；有助执行时在下一输入块前提供下方对照，按需要精简。同构与切换均须有观看依据；预览不加此附录，内部检查照常。

```text
【段界对照 大段K→大段K+1】
上段末画面：[景别/裁切｜机位/朝向｜主次｜人物道具和动作状态]
下段第0秒：[景别/裁切｜机位/朝向｜主次｜人物道具和动作状态]
观看选择：[切换或同构及其剧情/表演依据，不要求强制差异]
接续：[只写本处真正会断的1—3个接点，从动作相位、视线/运动画面方向、持物/接触、表演与声音状态中选；不逐项全列]
待验证：[仅列实际入口/接缝未知项，无则省略]
```

## 2. 共同字段与适用条件

两模式栏目名与顺序一致；不用“画面基调”替代全局光影画风，不用“贯穿表演”代替逐镜动态时间轴。不填不适用空栏。

| 字段 | 何时与写什么 |
| --- | --- |
| 【参考职责】 | 有参考、必要待绑定槽位，或用户未提供素材也未明确纯文字（按assets AS01默认准备稿槽位）时都输出；按实际素材写继承维度与适用隔离边界；不假定棚拍背景/静音音轨，不否定已授权首帧或构图职责；只有用户明确纯文字/不用参考的无参考稿省略 |
| 【全局光影画风】 | 每输入均有：介质、画幅、主光来源/场内方向、必要材质色彩；风格扩展见style |
| 【场景布局】 | 满足space启用条件：地标、人物锚位、世界关系、机位侧/投影与连续约束；背景互斥仅在真实几何支持时写；各输入按当前起态自足 |
| 【注意事项】 | 每输入均有：有效字幕/声音/口型限制；必要时写止于何事、不提前演下一事件 |
| 【角色声音】 | 有实际角色发声或明确角色发声静音约束：语言发声按audio稳定声线与当句读法分层，无参考时写音高、质地、共鸣或气息、吐字节奏及一项角色特征；非语言动物/机械表达声按AU05，不强填人类声线字段；已确认详细声线不裁；静默者不凑声线 |
| 分镜标题／景别与摄影机 | 每镜：事件、景别和实际裁切、主体/留白、挂地标的机位/方向/背景（不写块外机位代号）、主运动触发/路径/速度/落幅；空镜/插入/POV用必要参照；光学按需选焦距或明确FOV |
| 空间与主体 | 每镜写当前必要起态与机位投影、在场关系、持物/动作关键条件；稳定事实同输入共享，独立输入重写必要上下文；有角色图不堆静态外貌 |
| 动态时间轴 | 实际先后/并行；语义/事件触发→注意任务→具体动作或神态前后变化→必要回应及余势，按acting选部位、方向、幅度和时机；较长表演用镜内阶段，不增加镜数；非人按实际结构表达；可见且影响理解的惯性与受力；稳定倾听或观察写维持什么，不要求每镜新变化 |
| 物理与光影 | 本镜有变化或必要作用才写；不复述共享光影 |
| 音频与对白 | 实际声源、画内外、发声窗和完整原词；必要拟音与环境层次；按遮盖风险用退让，按真实跨切声音用声桥，不每镜齐套；读法在原句前 |
| 尾帧与转场 | 保留字段，写切出动作阶段、关键余势与接点；内部核全状态，正文不逐镜重复全量清单。连续匹配切核相位，省略/转场说明关系；段末不强制下段机位避让 |
| 局部风险锁 | 仅额外高风险穿帮时少量正向约束 |

## 3. 填写骨架

四个重点字段每份输入都按下面的写法展开，不压成一行，不留方括号说明。参考职责只在无参考稿（用户明确纯文字/不用参考）时整块省略，用户未提供素材时按默认准备稿槽位输出；场景布局未达启用条件时整块省略；其余两块每份输入必有。

```text
【参考职责】
@视频1：[实际引用时写清需继承的身份、环境、保留尾态及声音维度；摄影同构或切换按已定方案；隔离真实无关内容，不预设静音，不一律排除末镜机位。没有此素材整行删除。]
@图片1是角色[原名/身份]的形象参考：[已确认身份外观维度]；[实际存在且不采用的背景/姿态/文字风险，无特定风险时仅声明用途]。
@图片2是场景[场景名]参考：[已确认结构/光色/构图职责]；[仅隔离实际无关维度，不否定用户指定构图]。
@图片3是道具[具体道具名]的结构与状态参考：锁定外形、比例与当前特定状态；不继承未指定持握姿态。
@音频1是角色[原名或简短身份]的参考音色，仅参考音色（不迁移原样本台词、混响与环境噪声）。
[按本输入需要增减，编号沿用全任务映射；首帧/构图/路径/声轨等已指定职责必须保留。默认准备稿槽位用同样句式写职责，上传与绑定状态只写块外。无该素材或类别删整行，不输出本骨架的方括号。稳定空间写场景布局，当前起态写首个适用镜头，之后写变化。]

【全局光影画风】
- 视觉风格：[按已确认介质展开五项：成像或绘制方式、光的形成与衰减、材质或笔触、景深与轮廓、运动反馈。真人实拍不写CG渲染，三维CG不写真实摄影机证明，二维和三渲二不互相替换。已确认CG（三维动画）且采用写实渲染时写成：三维CG，写实渲染，UE5写实影视质感，Lumen全局光照与光线追踪反射；扎实的物理重力与承重形变，真实织物垂坠与环境材质细节。修仙题材或用户明确指定时，可加入类《仙逆》动画的修仙正剧气质；仅确认写实（真人电影质感）时按真人电影实拍展开，不混入UE5/CG术语。]
- 全局主光：[地点环境、必要站位轴线、主要光源或环境照明的来源、相对场景的方向与性质]。
- 色彩与材质：[本段必要的综合色彩、明暗与材质基调；参考已明确或本段不需要补充时省略本行]。

【场景布局】
[启用时按space写必要世界几何、人物当前锚位、机位侧与投影、反默认关系和连续约束；背景互斥只有几何证据时写，不填固定句数，不重复无关状态]
```

连续模式在同一代码块内按镜号递增重复逐镜部分，时间不归零；同输入内稳定的风格、声音和布局在头部声明一次；各镜写变化及本镜必要起态，已声明且未变的稳定事实共享，不逐镜重抄。单镜模式每镜单独一份代码块，标题在块外标段镜号，块内时间从0秒起，动态轴按实际阶段分行；每份重复必要的参考职责、全局光影画风、场景布局、注意事项和角色声音，不能只写“继承上镜”或“同上”。

两模式都保全关键角色的触发与行为，不以"笑着说/抬眼"代替具体变化；切镜不重演已完成的动作。acting A01/A07/A08的内容写进实际动态时间轴，不另增表演表格或角色长档案；细腻面部表演按[facial-timing](facial-timing.md)把各面部动作写成独立时间事件并错峰，细腻多节拍表演按[performance-dimensions](performance-dimensions.md)选窄，二者都不另增表格或配额；关键节拍细写，稳定状态共享，后半镜头的具体度不得下降。最终提示词不带思考过程、教程名称或"按某系统表演"的元指令，直接写出行为。

已授权动物叫声/机械角色表达声时，把默认【注意事项】声音组成中的“角色人声台词配音”适配为“已授权角色语言与非语言发声”；Lip-sync仅对具有发声口部的画内说者生效，无嘴角色按既定声源发声，不新增器官。这是与audio AU05一致的条件适配，不是新增声音授权，其余默认禁令保持。外语中文释义放执行块外逐句定位，不混入实际发声，执行块本身直接复制，无需手动删除释义。

默认注意事项使用上面骨架中的有效规则，不改写成“不添加硬字幕、文字条或水印”这类缩写；用户在有效上下文中明确覆写某项时，只同步调整该条款并删除与之互斥的句子，其余保持原文。剧情必要的招牌、书页、屏幕字另按事实和入口能力处理，不当硬字幕禁掉。

## 4. 时间格式与交付容量

入口明确为Seedance 2.5时按平台既有证据用连续整数秒；累计边界取最近整数，不逐镜上取整。亚秒先后放整数区间内的相对动作语句，计划小数留块外。块内总长等于素材L；连续输入只能剪整份首尾余量，不能假称逐镜剪掉取整差；单镜输入分别处理。取整挤掉必要动作/台词时调整相邻边界，不删内容，块外报差额。2.0按镜序表达，不依赖时间戳；写秒数只标计划。入口未知沿通用计划格式，最新实际证据优先，详见[平台](platform.md)。

先删装饰、重复与不适用字段，不删关键表演/因果/对白/空间/尾态。超过5镜不自动分批；确需分批在独立输入或完整镜头边界，标总范围/已交/剩余与合并顺序，续镜号/时钟，能继续就完成，不把部分称全片。当前范围交齐后按routing推进，不加固定口令。
