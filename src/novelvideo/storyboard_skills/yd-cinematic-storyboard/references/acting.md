# 角色表演：目的、感知与可见行为

<a id="a00"></a>
## A00 读取与输出范围

凡承担感知、选择、交流、追求目标或表现生命感的角色都适用：真人、动画人、自然动物、拟人动物、怪物、机器人、拟人物品。普通静物、背景动物及纯环境运动不强加意图。新建/细化角色镜头读A01—A03及A06；对白/倾听读A04，群戏/跨镜读A05，非人角色另读A07，较长连续表演读A08。A03的可读性与身体/口型兼容属于新建内部规划，只交时间总览预览也不免读；关键接触按其中入口加载readiness R03。用户事实、原话、知情、时长及锁定拍法优先。忠实提取不补演。

按需加载三个增强模块（不默认全读）：细腻、多节拍、多角色、对白密集或身体细节丰富的表演，或在多个表演细节间取舍时读[表演维度库](performance-dimensions.md)（七层：情境校准、戏剧驱动、感知认知、节拍构建、表演通道、运动动力学、连续与特异性，先宽分析再窄选择）；需要细腻面部表演、混合情绪、表情转变或用户点名微表情/FACS时读[面部动作与微表情时程](facial-timing.md)；解释方法、引用研究、使用FACS术语或作科学断言时读[科学依据与术语边界](evidence-boundaries.md)。三个模块的内容最终都编译进本文件的镜头字段，不单独成交付物。

内部设计最终必须进入实际镜头的空间与主体、动态时间轴、音频与对白、尾帧；不能仅写一份表演分析，正文却只剩“自然地说”。预览把关键动作、神态、触发及原话写进画面重点，不另加分析栏；完整稿在相同骨架内细化。写法拿不准时看[examples E-B](examples.md#e-b)，不迁入示例事件。

**表演细化不改节奏**：表演写在[story S0](story.md#s0)与[S6](story.md#s6)已定的镜数和镜长之内。写得更具体，是把同一段时间写清楚，不是增加时间：不为展示表演加停顿、“片刻后才答”、延迟回应、慢放、额外反应镜、特写或余韵。反应能与话尾、下一句或已有动作并行就并行；问答多数紧接或与话尾重叠，不在每句后留空。只有原稿必需的获知或反应确实没有可读时间，才回[timing T1](timing.md#t1)按一个窗口计一次。用户锁定的镜长、拍法和总长不因表演改动。

<a id="a01"></a>
## A01 正面编写方法：让角色在做事

先明确本拍角色正在争取、辨认、确认、等待或维持什么。目的可以指向对手，也可以是完成操作、观察威胁或继续休息；平静交流不必虚构阻力，每场不必失败，不必有掩饰和崩溃。已有情绪可以作为方向，但必须给观众看得见的证据。普通问答不强造冲突，平静人物不必每镜变脸，但须写清具体在听、答、看或保持什么。

**关键节拍的编写句式**：`角色承接[起态]，在[足够语义/可感知事件]到达时，[注意对象或判断任务]；[可见部位/已有动作]从[旧态]变成[新态]，写出决定效果的方向、程度或快慢；[有依据的回应/保持]，到切出时[尚未结束的状态]。` 这是自然动作段的编译方法，不是七栏填空、必写七项或独占秒数配额；可并行的共用窗口，必须先后的保留依赖。普通保持可只写注意对象、维持方式和未回应状态；不强凑转折。

目的与可见执行相连：不是“试探乙、眼神复杂”，而是“问完后仍观察乙是否回看，原先前倾的上身没有退开；乙回避时才把后半句放轻”。设计必须受当前故事支持，不能由语气擅判说谎、犯罪或秘密。

**具体度要到动作发生方式**：不能停在“抬眼、皱眉、露出笑容”。关键时可写“原本抬起的嘴角在听到拒绝后先停住，再放平；目光仍留在对方脸上，开口比刚才轻”。写部位、前后差别与触发，不堆形容词。幅度按场面选“刚能辨认的收住／清楚可见的停顿／整体姿态改变”等自然描述；没有统一强度数字，不能全写“微微”，也不能全夸张。

一个节拍先选一个主要表达，再带真正有作用的相容通道；不机械要求每镜脸＋手＋呼吸齐套，同一瞬间不堆眨眼、挑眉、咬唇、吞咽、耸肩、攥手、转头七项指令。强烈爆发、哭泣、怒吼、喜剧夸张、安静保持都可成立；细腻不等于压低所有反应。

原稿动作是表演载体：已在递物、擦拭或行走时，力度、节奏、路径和中断位置可成为证据，最强反应可以是听到某句后停住、减慢或恢复。没有手上工作，不新增擦杯、翻文件、捏硬币；没有靠近/退开，不按心理距离表强加走位。移动、急停、受击或转身时，按实际入画和作用写出必要的衣摆、发丝、既有随身物品或脚下介质的滞后/接触反馈；不是每项必写，不新增原场景没有的物件或介质。

<a id="a02"></a>
## A02 角色差异与当场任务

每场主要角色内部记：当前已知事实；向谁/什么争取什么；确有的阻力；当前做法；注意目标；已有身体与累积状态。用指向对象的动作动词和可观察结果，不直接命令"演出心虚"。角色仅按自己能感知的证据反应。先读完整交流和结尾再定做法，不由职业、造型或表情推断秘密；双方无共同目的就不强造共同目标。缺少动机时选不冲突的当场做法，不编履历、病理、秘密或新关系。

需要把表演写得更细时，按[表演维度库](performance-dimensions.md)的戏剧驱动补全七层内部驱动：**目标**（想获得/保护/隐藏/确认/改变什么）、**外部阻碍**与**内部干扰**（两者都重要时分开）、**赌注**（失败让什么更难、更险、更急）、**冲动与克制**（想做什么、又阻止自己做什么）、**策略**（可演的做法，不是情绪）、**贯穿线**（把局部策略连到场次目标）。冲动与克制之间的张力、以及"察觉自己泄露后主动掩饰"（自我监控）是细腻表演的关键来源；但平静交流不必虚构阻力，每场不必失败。策略只在原有失败、新信息或关系变化确实要求时调整，转策至少有一个可辨前后差别。

角色差异来自同一事件下的不同目标、信息和身体条件。例如一人检查对方是否答应，另一人留意出口；只有故事允许这两个目标时才这样安排。不同不等于人人都必须有反差，群体也可真实一致。所有人不都写成“抿唇—收下颌—移目”；不为求差异新增习惯、旧伤、年龄或履历。已确认的角色特征保留。跨镜的个人行为基线本版已支持：为角色建立一条克制的**行为指纹**（与该角色绑定的重复习惯，如常态的呼吸调节、句尾收住、紧张时仍把字咬清），并在不同镜头里改变其时机、强度或手别做**变奏**，避免习惯退化成机械抽搐（见[表演维度库](performance-dimensions.md)第7节）；同时仍只保证已确认特征与当前状态连续，不为求差异新增习惯、旧伤、年龄或履历。

按当前坐/站/奔跑、持物、伤势和遮挡选择可见表现。策略只在原有失败、新信息或关系变化确实要求时调整，转策至少有一个可辨前后差别；持续同一策略也可有强度、对象和反馈的推进，不设固定转折次数。回避不自动是撒谎，笑不自动是善意，言行一致也成立。言行落差、克制与泄露只在原意成立时用：先确定表面任务，再选实际泄露的一点。内在目标留内部，执行稿用可拍动作表达，不新造“内心独白”让模型误配音或生成字幕。

<a id="a03"></a>
## A03 注意任务、表达通道与兼容

目光要有工作：确认对方是否听懂、辨认既有物、追随移动、等待回应、避开已知刺激等。写目标、何时转移及落点，不写空泛“眼睛灵动”，不固定眼先头后、眨眼次数或扫视频率。原稿失焦、闭眼、走神或回避照实。保持注视可以有自然眨眼，不用眼神光代替思考；反光由既有照明决定。明确冻帧之外，不用“全身完全不动”冻结呼吸、眨眼和正常表演。

| 实际画面 | 优先选择的可读证据 |
| --- | --- |
| 脸部近景且清晰 | 眉眼开合与方向、眼睑张力、嘴角起落、准备发声与收口、下颌松紧；按本角色选必要部位，不逐区点名 |
| 中景、能见肩手 | 面部较大变化、肩颈/躯干开合、已有手部任务的力度/中断、与对手距离关系 |
| 全景、远景、背影 | 整体轮廓、重心、步幅/速度、转向、停住、支撑和对象距离；不写读不见的泪光或细微眉肌 |
| 单局部、遮脸或面具 | 已入画部位、接触、节奏、头身朝向和既定声音；没有第二可见通道不凑 |
| 非人角色 | 先读A07的实际结构与表达自由度，再按当前裁切选择 |

判断脸的朝向、受光、遮挡、焦点和有效时间。双人中景不自动等于微表情可读；关键反应落在失焦或转身中已经结束时，先在授权内修时机、景深、取景或表达尺度，不能称写过即看得见。摄影机靠近不替代表演发生。重心高低、动作快慢、身体开合只在当前画面可读时使用，不固定对应自信、恐惧或服从。

**身体与发声兼容**：说话中嘴唇随语音活动，紧抿/咬住可放在非发声间隙；占用的手不同时握拳或接新物；看准操作与持续盯人不能强并行。移动、受击、急停按实际需要写支撑、重心与滞后。涉及推拉、抓握、跌倒、受击、承托或其他关键接触时，必读[readiness R03](readiness.md#r03)：触点、发力/受力、支撑、重心与距离相容；保持抓握不等于冻结腿部步态，受动者不无故主动配合。夸张程度服从既定写实/动画方向。

专业肌肉名默认不写进提示词，不能替代可见描述，也不能宣称模型存在该控制参数。需要细腻面部表演、混合情绪或表情转变时，面部动作的时程写法（Onset/Apex/Offset、分层错峰、可读尺度）按[面部动作与微表情时程](facial-timing.md)执行：每个面部动作是独立的时间事件，不把整段情绪套一条统一曲线，且仍写在本镜已排镜长之内。FACS/AU 编号仅在用户明确要求且证据充分时使用，术语边界见[evidence-boundaries](evidence-boundaries.md)。

动作过载先删同义修饰和装饰性辅助反应，再选更清楚的观察方案；保留原稿必要动作、关键反应与时间依赖。不能靠全部同时发生、擅延镜长或压回情绪标签解决；仍装不下按时长冲突处理。

<a id="a04"></a>
## A04 台词、倾听与相互影响

把最终原话当表演的语义时间轴：内部先标说话前起态、足够信息到达处、必要重音/换气、说完后的状态。触发可以是一个短关键词、句首/中/末的语义位置或既有动作；不要整句台词在时间轴和音频栏各写一遍。原词只在音频与对白完整出现；必要短关键词仅定位，不当新增台词。台词前读法规则由[audio AU03](audio.md#au03)定义。

听者可以句中反应，也可以听完再判断，关键是足够信息确已到达，不提前知道句末内容。不强迫所有反应抢在句末前，也不让所有答案机械匀速衔接；但这不等于每句后都留停顿，普通问答照自然语速紧接。翻译后按最终语言词序定位。重要信息后的评估可与剩余话语或相容动作并行，真实需要独立理解时才留窗口，按timing计算一次。

当场景依赖新信息而非单纯对白时，按可信的**感知决策链**组织：预期→察觉→定向→辨认→解读→决定→行动。可跳过不必要的步骤，但不要把感知、辨认、决定和行动压成同一瞬间；需要可读时加入反应延迟、注意力转移路径、焦点深度变化或不确定性。角色察觉到自己的外露并主动掩饰（自我监控）时，把"补回面具"写成可见动作。察觉阈值、倾听、可打断性等细分见[表演维度库](performance-dimensions.md)第3节。

对手戏关注相互影响：甲试图让乙做什么，乙通过哪种可感知反馈回应，甲是否真的看见/听见这点并维持或调整；不是每次都要闭环转折。画外听者、背对者、隔墙者按真实感知范围处理。脸不同时可读可分配到既定覆盖，不强制同框。

沉默也具体：正在等对方给出答复、看住某条路径，或维持尚未撤回的动作。没有新刺激时可保持，无须加移目攥手。已有工作可持续、迟疑、中断或恢复；只有原稿支持恢复才恢复。

当句声音服务行动：质问、确认、安抚等落实为相对音量、速度、重音或实际换气，原句读法放句前，稳定声线不改。没有授权不加“嗯、哈哈”、结巴、叹气、删字、吞词和新重叠。可见呼吸不自动等于新可听喘息，具体边界见[audio](audio.md)。原文已有的笑声、不完整句和打断照原样保留。说话者也有表演：当前看谁、原有笑容维持还是收住、说完后等待还是继续做事，不是只有听者在演。

## A05 跨镜、群戏与余势

切镜继承当前注意、表情阶段、支撑、动作、身体张力、疲劳、伤势与未结束声音。情绪可随实际经过时间、自然收势或新刺激发展，不切镜重笑、重惊、反打复位或立刻恢复。强事件后的气息、手部不稳和身体惯性带到下一拍或下一镜，不能借自然消退抹去伤势。压力按原刺激维持、加重、失守或缓解；原稿突然爆发就不补铺垫，原稿平静不造破裂。时间省略/平行剪辑按其时点更新，不锁成同一瞬间。

群戏按每个角色可感知的信息分配反应时机和程度：能同时听到突发声可以一起惊跳，获知不同就不同步；不强制反应波、不镜像复制所有人。背景角色维持必要在场与已有活动，不抢主观察目标。高地位不必静、低地位不必乱，不用表演动作推断社会等级，不套固定距离、不强造胜负。

对手戏与群戏可用更细的**配合维度**：轮流、打断、镜像、同步、失同步与地位交换——例如一方的呼吸节奏先带动另一方，或两人刻意错开反应时机以显出关系落差。这些维度按[表演维度库](performance-dimensions.md)第5节选用，只保留改变可见关系的一两项，不为求复杂把所有人写成反应链。

同一角色不无故循环“抿唇—吞咽—握拳”；有剧情依据的重复和持续行为保留。较长镜头通过注意、做法或强度的真实变化推进；稳定保持本身有观看职责时不强造变化。

起态明确不等于可以省掉唯一交接、接触或后果；普通微反应不拆碎成单独镜头。过肩只露后脑时嘴角不算证据。细化不能擅改已确认的关键机位。人物在场/画外/离场归[camera C06](camera.md#c06)，空间投影归[space](space.md)。

<a id="a06"></a>
## A06 编译到现有字段与一轮验收

- 空间与主体：角色当前必要起态、身体/头脸或朝向、注意对象、支撑/持物。
- 动态时间轴：使用A01句式连接语义/事件与可见行为；关键处写清部位、方向和相对变化，较长表演按A08分镜内阶段。把"想让谁怎样"落实到动作，不止停在目标标签。细腻面部表演按[facial-timing](facial-timing.md)把各面部动作写成独立时间事件并错峰；运动按[表演维度库](performance-dimensions.md)第6节写启动点、传导链、惯性、制动与回收。区间是计划，不伪造微动作实测精度。
- 音频与对白：原词、声源、发声窗、关键重音/换气；按真实发声结构匹配口型或声音，声音与动作相容。
- 尾帧与转场：尚未结束的注意、动作相位、情绪和声音。内部完整核对；正文写关键接点，不逐镜抄全量清单。同输入共享不变事实，独立输入重写必要上下文。

既定机位/镜长/事件/方向内补收笑、视线落点、肩颈变化是细化；新增关系判断、秘密、动作事件、台词，或改镜长/关键拍法仍按授权边界。压缩时先删摄影装饰和重复解释，不把成品退回“笑着说、神色复杂、自然反应”；容量不足按原分批规则完整交付。

统一质检只做一轮：从实际正文能查到关键起态、触发、可见变化和接续；稳定镜头能查到具体注意/保持；非人通道与已定造型相容。不另加表演评分或复核轮，不能把"眼神有戏""表演自然"当执行说明。模板不加每镜配额，文本具体也不代表媒体演技已验证。

表演连续性的负向约束（写在【注意事项】或镜末，按需）：动作与面部变化保持连续，不要表情突变、假笑冻结、面部变形、身份漂移、姿态复位或意外切镜；冻结帧之外保留自然呼吸与微调整。这些是防 AI 视频常见失败模式的约束，不是新增动作授权。

<a id="a07"></a>
## A07 动物、机器人与拟人物品：先认结构，再导演

先内部判断三件事：主体是自然动物还是获准拟人；参考/设定实际具有哪些能动部件；本片允许何种变形和发声。拟人程度按已给设定，不因会说话就自动长人手、眉毛和人类牙齿。普通物体受风或重力移动不是角色意图。

| 主体 | 可选表达通道及边界 |
| --- | --- |
| 自然动物 | 按该物种实际感官、头颈/躯干、耳尾翼、步态与距离表达探查、趋近、回避或警觉；不凭单一动作断言心理，不添加人类笑、泪和台词 |
| 拟人动物/怪物 | 保留既定口吻和目的，用已有面部自由度、耳尾翼、重心与动作节奏落实；四足不强成人类站姿，材质/能力不因情绪临时改变 |
| 机器人/机甲 | 用已有镜头头、传感器朝向、关节启停、机体俯仰与支撑；灯/屏幕只在已设功能内用，不默认红=怒蓝=悲，驾驶者与机体分开 |
| 有脸的物品 | 只在已有脸部与活动结构内表现；刚性壳体不凭空弯折，造型里没有嘴和手就不增 |
| 无脸的拟人物品 | 用朝向、姿态、路径、速度、停顿、距离、接触和已有机构；台灯用灯头转向/关节收展，不因需要“目光”长出眼睛 |

通用链仍是“感知已知刺激→朝对象采取行动→对结果继续/改变→余势”。人类目光任务可翻译为嗅闻、转耳、传感器对准、灯头朝向等真实可用的感知通道。身体、手别、支撑规则按实际结构映射为爪/足/翼/轮/夹具，保留已确认的数量和连接；种属不明不填不存在的器官。四足、飞行、轮行不套人类脚步和双手规则；骑乘时骑者与坐骑分别跟踪动作和支撑。说话、叫声和机械声按[audio AU05](audio.md#au05)。

## A08 镜内连续表演

一个摄影镜头可容纳多次表演节拍。只在原有信息、目标/做法、强度或关系发生变化处细分阶段，不把每个阶段另编号成镜，不按固定秒数、固定节拍数切片。按已排镜长和最终台词安排行为，而不是为公式延长剧情。

复杂变化先定真实起态与结果，找原故事中中间如何发生。原意有克制、迟疑时，可以呈现原做法维持→局部失效→改变；原稿直接爆发就直接爆发，不强套“所有人忍住再崩溃”。泪落、笑开或声音破裂只在相应触发后发生，不提前演出结局。起势—可见峰值—保持/自然消退只在本次变化适用时选用，不是每个表情都走三拍，也不为走完三拍延长镜头；镜长不够时让余势带到切点之后。入口对细时间控制未知时用先后和句中位置，不假装逐肌肉毫秒控制。多层混合情绪的精细编排本版已含：按[facial-timing FT3](facial-timing.md#ft3)以"主行动＋一个真实泄露通道＋分层时程"写，表面任务的消退与真实情绪的出现错峰，不只写"悲喜交加"。仍不增加镜数、不为走完层次延长镜长。
