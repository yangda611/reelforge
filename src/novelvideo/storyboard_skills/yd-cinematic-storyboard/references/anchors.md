# 可选1秒静止静音锚点

只有用户明确开启、发送 `/锚点镜 开` 或询问锚点时读取；默认关闭，不作前置必问题。它是技术参考镜，不是给每份输入自动加的剧情。

- 后面还有独立生成大段需接续、且该锚点能提供有效空间/姿态参考时，才在前序段末追加1个分镜；末段默认不加，用户明确留后续参考例外。文字续批、同大段内单镜独立输入不自动产生新锚点边界。
- 有效生成区间固定完整1秒；成片只计实际保留部分。整片连续模式该秒计入所在输入L；单镜独立模式锚点单独输入。入口不支持1秒则选支持L，其余仅可舍静止静音余量，逐份检查U/V；不能把“全剪”当“不生成”。增减段数后重核锚点数、T/L、段号和接续，不压剧情腾空间。
- 采用四分之三侧面全景，可略俯、固定无运镜；在实际可执行机位、轴线和揭示边界内展示允许看见且关系有用的地标、人物和道具结束状态。已遮挡/收纳仍真实遮挡，必要位置用文字说明；装不下时优先下一段接续关系，仍无有效参考则说明限制，按授权处理。蓝图启用时机位挂地标、写背景并留同侧。
- 该1秒内场景、人物姿态、衣发、光影和粒子全部承接前镜结束瞬间定格，无新动作/位移；音轨完全静音，无台词、拟音或环境声。这是明确技术冻结，不把日常人物静止表演也冻住。
- 用途为截尾帧的当前可见空间/姿态参考，不自动锁下一段首帧构图，也不保证模型一致。下一段按[故事S7](story.md)选择有动机换画面或同构接续；锚点只作参考，不保证动态接缝。
- 保留锚点时拿最后保留锚点画面与下一段第一保留画面比；剪除时拿上一段剧情实际保留末画面比。改剪取后同步核景别/视点、动作、声音。未生成只能检查计划边界。
- 技术编号、生成长、成片保留/剪除及映射保留在内部计划与完整稿必要说明，按[双时钟](timing-capacity.md)核算。时间总览预览不追加技术附录；全剪锚点不伪造为0—1秒成片行，也不把生成有效1秒误报成完整素材必为1秒；用户另要生成清单/完整稿时给出其编号和实际口径。
