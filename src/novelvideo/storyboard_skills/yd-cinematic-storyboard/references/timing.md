# 计时、节奏与分段

新建、重估或时间相关返修读取；只把旧稿转预览不重估。计算在内部完成；预览只显示一句总长和逐镜时间，完整稿才按[完整输出](full-output.md)显示评估。时长是计划、计时朗读还是媒体实测必须区分。

<a id="t1"></a>
## T1 先建立唯一事件时间轴

使用已确认发声语种和最终词句，先定本句自然说法，再估声音、动作及有效阅读窗口；确定全片T后才在剧情断点分段，再在段内排镜（见[story S0](story.md#s0)）；不从段上限、分镜字数、句数或预设镜数倒推总长。

- 优先同语种、同词句、同表演方式的录音或计时朗读；区分首尾静默、句内停顿及额外反应。异文/异语音色样本不能证明本句时长；相近样本仅辅助。无对应录音按发音、词长、连读、情境、身体和气息文本估时，数字/日期/缩写/专名先展开实际读法。
- 连读、重音、变速和换气按意图变化确定，不按标点逐个加秒。争吵直接承接既有状态；情绪大/声音响不自动更慢，不能每句前后固定加0.5—1秒。激动可能抢话变快，也可能因重音、断气变慢；音量和情绪强度不能单独决定语速。日常“今天我们去哪儿吃饭啊”约2—3秒、急促回怼“今天我们吃锤子”约1.5—2秒仅为相应情境的声音估例，不是统一镜长；原镜能承载下一句就可留镜。
- 动作从实际切入姿态、距离、接触阶段算，只计本镜确需看见的预备/执行/后果；依据阻力、体量、熟练度与状态，不按动作名派固定秒数。普通拨号、解锁、拿放、起坐、走向/转身等过程能由后果推知时可省或中途入镜；过程本身是看点（慢慢、犹豫、悄悄）或决定后果才呈现。紧凑最省，标准留关键过程，舒缓按职责展开；必要接触和唯一结果不能省掉。
- 用先行条件与可见时间窗组织事件：同起且真实兼容取较晚结束者，依赖前序结果的累加，错峰按起止并集。原文顿号、逗号连写的小动作不必逐个串行，身体允许就部分重叠；部分重叠不等于每项都已听清或看清。不同角色独立行动能并行，不代表观众能同时读清多个新信息。双手、目视操作、口型、注意与发声都允许同时才并行；看清/辨认/对准后才能继续的步骤保持先后。
- 反应从足够获知时开始，句中已到可与余下台词并行；句末才成立或须先读清判断才能理解后续，就保留必要窗口。不提前理解、不为每句留空，不把表演五环拆成五段秒数。尾帧余势是切出状态，本身不另计秒；承担评估、笑点、等待或接点的停留按职责只计一次，不用0.3秒封顶。
- 阅读从关键对象/接触/表情确实清楚时开始；入画、遮挡、失焦与注意未落定按实际可读度处理。能在动作或对白中读清则共用窗口，必须分阶段理解则留先后。相机在动不一定不可读，停稳不代表已读懂；不等摄影机走完而无端加长。
- 硬切0秒，普通新画面识别与首个事件重叠；首次复杂多人定向才可能单留约0.5—1秒。单边通话未写对方台词时不补整秒空等，只留实际换气/短动作（常约0.3—0.8秒），反应可与之或下一句重叠。
- 自动分镜的默认镜长取必要事件、反应和持续观看的自然占用（紧凑档取自然区间偏短的一端），不向上取整到习惯秒数，不加统一缓冲。话说完、接触完成或结果刚可辨认，只说明可判断切点，不要求立刻切走；原镜仍承载交流、等待压力、关系变化或余韵时继续，后续确无职责才收紧。不为“再看一眼”机械续1—2秒，也不为紧凑删掉必要反应。

## T2 三档、发声合计及适用边界

发声合计S为全部对白、旁白及指定非语言人声逐声源时长之和；无人声S=0。重叠人声的S可大于T，不能把T−S当非台词独占时间。参照只作复核：普通话自然约4—5字/秒、急促约5—7、有依据慢说约2.5—3.5；英语自然约2.5—3词/秒、急促约3.5以上、慢说约2。其他语种同理；省略号/结巴按真实读法，不再加整秒。落在参照外需本句依据，不能用统一平均语速抹平多语言或表演差异。

| 档位 | 非台词过程与反应 | 对白主导R=T/S参考 |
| --- | --- | --- |
| 紧凑 | 常规过程省略；真实可并行就并行；必要评估/反转/笑点按可读窗口 | 1.3—1.6 |
| 标准 | 关键过程与重要信息后反应，常规过程仍可省 | 1.6—2.0 |
| 舒缓 | 有职责的铺陈、等待、对峙和余韵 | 2.0—2.6；原文长等待可更高 |

按原稿判断是否对白占主体，不按算出的R反判：一两句短话但主要内容为交接/打斗/走位时属动作主导；动作/环境主导或S=0不算R，核全片事件链、阅读窗口与非台词占用。

**卡片自然粗估**：先判断主体，按下面三条算，填卡前再过一次“演一遍复核”。

- 对白主导：S×1.45/1.8/2.3。
- 动作主导：先数因果节点，不数镜头：一次接触及紧接的可见结果算一个节点，同一结果的反应、声效和余势并入该节点，不另计；追逐、连续射击、多人混战按整段冲击计，不把每次击中、每次脚步拆成节点。**紧凑每节点默认约1秒（常见0.8—1.3秒）**，只算该节点的接触和结果，前因能并入上一节点就并入。只有原文明确写了慢、停留、完整接近、僵持、脱困，或必须单独读清的揭示，这个节点才取约2—4秒，并能指出是哪一个节点；不按想象补过程。标准约紧凑×1.25、舒缓约×1.6（正式参考分别为1.15—1.35和1.4—1.8），只服务尚未被固定总长约束的自然估时。三档共用同一节点；标准只加决定成败的预备、逼近和关键反应，舒缓只加原文已有的停留、等待和余韵。不用慢动作、重复覆盖、无关空镜或新事件凑比例。
- 动作中夹对白：边做边喊、边打边说的短句与动作并行，不另加S；只有人物停下动作专门说话、或说完必须留出反应的独占交流，才把这段发声按对白公式另计。**不把全部动作节点时长和全部台词时长直接相加。**

**演一遍复核**（卡片秒数填写前必做，正式排镜后再用一次）：按原文顺序在心里把事件实际演一遍、台词按自然语速说一遍，得到“演一遍时长”。紧凑粗估比它长出约两成以上，或动作主导时平均每节点超过约1.3秒，就逐项查：同一次接触是否拆成了几个节点；边做边说的对白是否和动作串行相加；是否给每个节点都加了预备、反应和余势；抬头、照亮、看清是否拆成几次计时；是否普遍取了上沿；是否给原文没写的过程派了时间。去掉这些再填卡。校准参照：约20个连续冲突节点、两三句短对白、含一次原文写明“慢慢”的揭示，紧凑约24—27秒、标准约30—33秒、舒缓约38—43秒；同类故事做成30秒成片已略显拖沓，紧凑超过35秒基本可以判定有重复计时。节点少、原文写明长时间僵持或等待的故事按实际节点算，不套这组数字。卡片秒数是粗估，不是正式排镜的最低时长或上限。

三档自然粗估原则为紧凑<标准<舒缓；短故事取整相同则留小数或注明接近。没有可展开职责时可以低于参考或说明差别很小，不伪造过程。**固定全片X是共同成片预算，不能因“三档递增”改成三个总长；递增只比较不受固定预算约束的自然估时，已选档只影响X内分配。**紧凑档用因果阶段合并来防止把同一次接触拆成多段计时，不删表演，也不压碎真实动作阶段：单一接触及紧接可见结果紧凑通常约1秒、最多约1.5秒；原文写明完整接近、接触、摆脱、还击与反应链时，整条链约2—3秒。原文写明的起身、接触和受伤确实装不下才据实延长，不为贴数字砍掉；原文没写的预备、眼神反馈和余势能并入接触或结果就并入，不单独占时。揭示从证据出现计到威胁可辨，抬头、看清和停住并入同一次阅读，不各计一次。标准档在决定成败的预备或结果需要单独阅读时放宽；舒缓档保留原文已有的停留、等待和余韵。原稿或本镜职责需要的眼神、呼吸、手部、重心、表情、台词停顿和反应保留，不把它们当每镜清单；实际兼容的才与接触或结果同时计时。

正式总长超过所选档粗估10%时，先查是不是把同一次接触拆成多次计时、重复覆盖了同一结果、把边做边说的对白和动作串行相加、给原文没写的过程单独派了时间，或保留了无职责停留。不能用“保留连续动作”掩盖注水，也绝不为了压进粗估把真实动作阶段或必要表演反应删掉。必要接触、唯一证据、指定等待和锁定拍法确实需要时保留，并写明是哪一个环节。这个复核不改变人物表演底线，也不把有职责的长镜头切碎。

用户说“太拖/再紧/太赶/再松”时反馈优先，调整指向的具体节拍，再算T/R；可超经验区间并记录采用依据，不设R±固定步长，不改自然发声或制造停顿。反馈只对本故事有效，明确“以后如此”才沿用。固定总长、范围、原台词和锁定拍法仍受T5约束。

<a id="t3"></a>
## T3 采用值与反注水检查

在自然成立区间选采用值：紧凑偏短、舒缓可偏长、标准按具体说法；不普遍取上沿。按累计边界精确合计、允许必要亚秒计划，不逐镜向上凑整；输入时间格式另按[平台](platform.md)。偏慢/上沿仅用于硬上限风险复核，不自动抬高采用值。

对当前范围一次核对：①常规过程是否全拍；②单边电话是否凭空空等；③反应是否可真实并行却重复计时，或句末必要反应被删；④硬切是否机械加识别秒数；⑤起势/余势是否无职责独占；⑥表演链是否各派时间；⑦是否普遍取估时上沿；⑧是否有隐性最短镜长；⑨是否把镜长向上取整或每镜加了同样的缓冲；⑩同一次接触、近战链或揭示是否被拆成多次计时；⑪边做边说的对白是否和动作串行相加；⑫是否给原文没写的预备、反应、余势或交代过程单独派了时间。紧凑1—2秒反应/插入可成立，仍看职责与可读性。用户说“太拖”时，先删这十二项里没有职责的占用，再动自然发声和必要动作。

对白主导且S>0才用R复核，超区间先审上述原因；高R确因原文等待/必要内容可保留，低R未快读删词漏动作也可保留。动作主导同样核全片：每笔独占须挂因果、接触、揭示或明确等待，先去重复/常规过程，再真实并行，不逐句译成串行动作。接近硬上限的依赖链，用合理偏慢或估时上沿只复核会不会超限，不把上沿改成采用值；成立性脆弱时说明具体环节，移动段界、重排真实并行或按T5处理，不给每镜加同样缓冲。全片约30秒按全片目标，不变“每段30秒”。

切出前问“下一秒承担什么必要信息、反应、悬念或指定体验”；没有职责才收紧。继续原镜能承载后续交流、操作、持续观察时可留，不因刚可读就立刻切。不均匀节奏、连续短镜和长镜都按职责成立；普通连续1—2秒碎镜复查必要视点变化，同构无职责重复才合并，合并保持真实占用与接续、不重演动作。

容量不足按顺序修：冗余覆盖→真实并行→取景可读性→无职责拖尾，保留自然发声、动作先后、等待和必要后果；不等比例压全部镜头、不靠加切镜或拆输入虚减时间。仍不足按T5处理。

<a id="t4"></a>
## T4 约束与全局可行均衡分段

“整条/整片/总共/控制在/30秒够了/大约30秒”是全片T的目标或上限，除非明确每段。按内容定时先定自然T；范围内选匹配内容的采用值，不默认上限。U仅限制每份完整输入，V是已核实平台上限，用户另限成片段才有U_D；不分段无U仍核V。锚点和生成余量计入L，**每份L≤U且≤已知V**；全片连同余量能单份容纳就按实际长度做一份，不填上限。**U是上限不是目标**：每段长度等于该段剧情自然占用，剧情16秒、U30就一份16秒；不为用满U拉长镜头、加停顿/空镜/慢放或加戏。单镜独立每镜一份，不能因全片短就合并。

S0初分时按节拍单元的自然占用计算，段内排镜后按实际镜长用同一方法复核；两次的合法边界都以剧情断点为先。

整片连续模式按最少段数与合法均衡：
1. 在剧情断点（场次/地点变化、时间省略、节拍转折、完整交流或动作链结束处）和其他既有镜界中确定合法边界，不截断对白、接触或必要后果。先从理论下界 `ceil(T/U)` 起找K；有已知更紧V、锚点、余量、U_D时一并核验，理论下界不当成已找到可行解。
2. **先找整组可行段界，再比较均衡**。候选为严格递增的一组切点，各段及其实际L均满足约束，且余下内容仍能装进剩余段；不要把每个i×T/K最近的单点独立选完就判定。可行组合中全部段界都落在剧情断点的优先，同类组合中再使段界靠近累计i×T/K；只有剧情断点组合会超限或留下短于U/3的尾段时，才用普通镜界，并确认那里没有劈开一次交流或动作单元。局部最近超限时换组合/回溯，不因此直接增加K；只有该K不存在合法可行组合才加一段再选。
3. 复核各段、真实段界的观看选择与接续；均衡只重新归组，不改镜长、事件、顺序或新增动作。T/K是参照不要求相等，合法切点远就接受不均。单镜独立的大段只按场景/节拍组织，不套均衡生成算法。

排后任一段短于U/3或仅一两个孤立短镜，回查能否整段并入邻段且所有约束合法；能并说明K尚非最少。否则尝试移动邻近完整节拍/镜界；确无合法方案才保留短段并记录限制。未知最短可生成时长不预设；已核实最短值大于所需段时可用合法余量后剪，或重排，不拉剧情填空。

同顺接无余量通常 `D_i=L_i≤U`、`T=ΣD_i`；叠化/并屏、锚点保留/剪除及剪辑映射必须读[双时钟容量](timing-capacity.md)。完整稿、固定预算冲突或需逐份核容量同样读取；简单单段预览无需整份低频公式。分段变更不增T、不靠分组消灭真实占用。

反例：镜长3/9/2/7，T21、U10、K3、合法累计3/12/14；独立最近目标7/14会选3/14，段长3/11/7超限；全局可行选择3/12则3/9/9。仅三段已合法，不应加第四段。此为算法边界例，不作剧情或默认镜长。

<a id="t5"></a>
## T5 固定总长与真实冲突

先列必要事件的先后/并行、自然范围与采用T，再比固定X；硬事实、原台词、锁定拍法与总长没有默认可牺牲项。X在自然范围内，用原有且有职责的观察/行动/等待安排即可；X明显更大不能把差额当停顿，只在已有持续体验足够时延续，否则需缩目标或获准加内容；X更小先按T3修，仍不足需延长目标或授权删改，切镜/拆段解决不了全片缺口。

有明确调整授权直接执行；否则仅暂停受冲突部分，指出真实差额及2—3个可行选项，不谎报满足。时间总览预览只在确有无法兼得的约束时给最短必要冲突说明，不输出整套估时推理或追加附录。原事件仅2—3秒且说完必须结束，不能声称可闭合12秒；明确双人持续等雨则可有职责地安排等待。
