# 摄影、构图与调度

<a id="c00"></a>
## C00 读取范围

新建排镜读C01—C03；选择机位、透视或运动读C04；光线/材质影响身份、证据或揭示读C05；多人在场、走位或状态接续读C06；有切镜、快闪或生成段界读C07；有角色表演承担关键变化时读C08。上述内部规划不因交时间总览预览而免读，完整稿也按实际触发项加载。只润色或忠实提取既有稿不重新选镜。光学与专业运镜词典仅按[camera-advanced](camera-advanced.md)触发，不整表默认加载。

内部判断编译到现有字段，不输出选镜分析或要求用户填表；四列预览按preview写清景别/机位/主运镜、关键动作与完整原话，不以一句话限制截断内容。阶段、授权、镜长和段界分别服从相应主流程。

<a id="c01"></a>
## C01 证据、观察对象与切点

先问观众此刻要读到什么、由谁/什么承载，再选尺度与覆盖，光学参数最后。选择者、信息承受者、第三人、手/物/空间都可作主体；说话者、主角或最激动的人不自动得特写。声音已交代含义而变化在听者就看听者，台词仍由原说者发出；听者获知不足只延续此前状态。

须同时判断脸、手、目标、接触或距离时保其关系；不能为拍反应漏掉唯一交接。局部变化需集中辨认才进特写，保起态和读清所需停留，再按新信息、悬念或注意变化离开。持续特写、固定长镜、无运镜无转焦均可由表演/信息/持续观察成立；同构或长本身不算停滞。

**长对话唯一判断**：逐语义节拍查信息、人物策略/行动、关系与持续体验是否清楚；只有必要证据读不清，或这些均无推进且有无职责重复时才调整。先去冗余，再在未锁定范围选择同框、过肩、反应镜、局部或镜内重构；不得为形式变化改锁定拍法。每镜一个主要观察目标，可容纳兼容次要信息；不一句一镜、按固定秒数切或预设镜数，不拆碎可连续完成的简单动作，不把复杂事件硬塞到不可读。

空间明确后可直接靠近，也可从有悬念的局部开始，不强制全景→特写。重大后果的反应可留原镜，不自动加空镜；指定等待、停顿、余韵、突变或连续冲击保持。情绪可由停留、距离、动作或声音表达，不固定紧张快推/悲伤远景；反向选择须更清楚，不为反常而反常。删并覆盖后复核实际时长和接续，不改锁定事件/原话。

<a id="c02"></a>
## C02 景别、裁切与构图

景别术语存在口径差异，执行稿写实际裁切、必要入画部位、主体大小、遮挡与可读时间，不以名称代替画面。

| 观看需要 | 比较的尺度及限制 |
| --- | --- |
| 地点/路线/相互位置 | 远景/全景容纳地标、全身、行动空间；太小的人物只用整体动作，空间已明可收紧。 |
| 身体策略、持物、距离或接触 | 中景/中近景按需保腰/胸以上及双手；手低于胸线就放宽，不裁关键触点。 |
| 态度变化与肩颈/手势 | 近景保承载部位；只有脸部变化可更紧，画外关系要读则放宽或换覆盖。 |
| 面部/局部选择证据 | 特写明确边界；已可读且更近无新价值可不收，保理解所需上下文。 |
| 极小证据/触点 | 大特写/插入标部位、归属、状态；不自动套微距、慢动作或浅景深。 |

同镜可因已有走位、机位移动或取景变化改景别，写触发与终点。收紧丢关键手、同时性或距离时，放宽或使用已成立覆盖，不以更近的脸牺牲因果。

**景别转换按观看职责**：依据需读信息的尺度、人物关系、空间定向和节奏选下镜。近景直接切双人中景、特写切全景或连续同景别都可成立，不要求逐档经过，也不设封闭的跳档例外。若切换造成无意跳动或方向迷失，修正实际视点、裁切、动作接点或必要的空间建立；不为过阶梯添无职责过渡镜。跨生成段遵循同一标准，不为技术分段制造尺度变化。

构图独立说明先看哪里、还须同时看到什么：主证据的画面位置/大小，必要视线空间或运动前方空间、前景遮挡、纵深/地标、背景分离；空白需有悬念、孤立或方向职责，字幕安全区仅用户要字幕时安排。不套九宫格或堆满术语。看向/运动方向通常留可用空间，有意压迫、逼边或藏目标就写明实际效果，避免被自动居中。换画幅逐镜重查双人关系、关键手部、道具、视线和行进前方空间，不把中心裁切当自动适配。

多人/多物有主次；背景不凭动作、亮度或细节抢唯一证据。遮挡若参与信息控制，写遮什么、由谁何时解除；无职责则不可盖脸/手/触点。原稿已有偷听、埋伏或暗中观察时，可比较前景窥视遮挡、干净视点或其他能保知情边界的拍法，不自动套遮挡。采用遮挡时只用已有物体，范围、虚实和受光按实际构图决定，15%—30%仅为候选构图参考而非配额；焦点反转仅在纵深与揭示时机成立时使用，不能提前露出秘密。没有依据不另加门缝、树叶或肩背。可读性不足先修裁切、站位、焦点和动作时机，再考虑加镜。

<a id="c03"></a>
## C03 覆盖、主观与空镜

- **同框**用于同时反应、试探、先后、距离或共同目标；按画幅与纵深/景深安排，装得下不等于读得清。
- **过肩**用于在场、观看方向、距离或遮挡参与关系；谁的身体哪侧肩、前景位置和谁为重点都明确。肩的大小/清晰度服从任务，不固定虚化。前景不能盖住关键表情、手部或证据。
- **干净单人**用于独立读表演或排除无用前景；保已建立视线/声源，不由单人画面推断孤独、决裂或对方离场。关系开始/转折/换位按需建立，无主镜/双方单人/过肩/反应各一遍的配额；高低与景别差有依据，不强求双方参数相同。
- **POV**来自人物合理眼位或明确主观位置，遵守朝向、高度、遮挡与可辨条件，可稳定且不必出手。过肩不是眼位；物件特写可为客观插入，不自动成为人物已知。客观插入可按既定结构让观众先知，看向—所见—反应能同镜完成，已清楚环节可省。
- **阅读/操作面**先定有效面朝谁、谁能看/接触，再选肩后/侧上方/插入/POV。观众看清不能改角色知情/可达；仅已有动作允许时调物件倾角，不因摄影需求另加展示动作。
- **空镜**为环境职责，物件局部证据另按插入判断。只用已有时空、路线、环境变化、缺席/痕迹、指定等待或声音/余韵的观察对象，不增天气/象征物/事件。离开人物前查漏何反应、镜外行动和声音如何延续；原镜能读必要反应先留人物。无新信息也可有既定持续体验，但计入预算。转空镜不默许人物完成未交代的关键动作，也不擅自暗示时间跳过。

<a id="c04"></a>
## C04 透视、运动与可行机位

大透视服务已有纵深、逼近、尺度、阻隔或冲击：明确近端部位/远端主体及关系，以近机位和足够视野容纳。不能凭广角标签建立纵深，不能改变世界尺寸或遮关键触点/身份，也不自动用于所有脸。俯仰/倾斜按上下关系、遮挡、尺度或主观体验选，不绑定善恶、地位或胜负。

表演自足可固定；固定时机位、朝向和焦距不暗变，不推拉、不摇移。集中局部可推、显露环境可拉、跟随/解除遮挡可移、注意变化可转焦。摄影机平移/转向/变焦与主体移动分开；变焦只改视野，没有机位移动的视差，不能冒充推拉。每镜一个主运动，写起幅、触发、目标、路径、速度倾向与切出位置/运动状态；实际停住才写停点。复合运动须说明先后或协同，不堆推拉绕升降清单；专业写法见[camera-advanced CA02](camera-advanced.md#ca02)。不设最低运动种类、特写率或出镜配额。

按已知墙、门窗、通道、障碍及高度查路径：拉远查后方、横移/绕行查沿途、俯拍查高度/遮挡，不只凭房间面积或焦距判可行。不编未给的精确面积/层高/距离；先选不依赖未知余量的构图，未知决定锁定画面可否实现才补缺或提替代。室内不一律禁景别；普通写实不得穿墙/穿顶/无路径绕行，用户指定虚拟/超现实除外。

强俯仰、倾斜、急移、手持须有观看作用，不持续遮住必要脸/手/触点。人物和道具都要辨认则保持两者清晰，不自动给特写极浅景深；转焦写A/B纵深、前后清晰关系及触发。已有遮挡/距离/受光/清晰度可组合建层次，不填满所有层，不增路人、摆件或背景活动；背景锚点的有限补充只按[space S02](space.md#s02)。

<a id="c05"></a>
## C05 光色与材质

主光来源、场内方向、软硬写清；有依据的天空散射、墙反射、窗外来光和画外灯可用，不必光源入镜或逐表面参数化。同场固定世界光源，反打画面受光侧可变；人物过遮挡、光移动或时间变化才引起相应变化，不能换镜就换照明。

光照服务允许看见与暂藏的信息，不一味抬亮或压暗。散射/硬光/轮廓光按场景，不默认夕阳、逆光、冷暖对打。可见光束要有光源与介质依据，不凭空添烟雨尘；已有雾也非每镜光柱。全局只定必要明暗/综合色彩/饱和，主色优先取已有环境衣物光源；同场识别连续，跨场/昼夜/已授权主观段可变，不硬套全片滤镜。

肤色、识别色、结构与照明/风格相容；阴影色不是色温，不编色码/胶片型号/开尔文数。颗粒、雾化、晕光、过曝、虚化各有职责，遮边缘/接触/地标先减无用效果，不用效果项数配额。材质只写本镜相关的变形、反射、磨损，延续干湿/破损，不全改湿亮、磨皮或额外纹理。先保脸/触点/证据局部可读，再控背景；冷暖、饱和、景深互不自动绑定题材/善恶。

<a id="c06"></a>
## C06 在场、空间与动作连续

多人内部区分在场可见、在场画外、已离场；收紧不等于离场，反打不需全员入画，回宽景恢复仍在场且应可见的人，不凭空消失/复制。明确谁影响谁、身体/头脸/目光对象、本镜观察谁，次要人物仅作必要活动。人物表演执行[acting](acting.md)，不可用镜头术语替代其具体行为。

互动、走位、反打或交接必须同时有当前画幅投影与稳定场内参照；具体站位四要素、走位四要素、身体左右与世界位置、手别及输入自足统一读[space S02—S04](space.md#s02)。人物的道具所有权与当前持有人分开。已确认全输入不变的必要状态可共享，后续写变化；每镜画面投影仍随当前机位写，跨输入不以“同上/继承”代替事实。

关键交接/围挡/接触写发起者、对象和结果，不能为兼顾所有人的反应漏掉改变归属/位置的瞬间；接触物理读[readiness R03](readiness.md#r03)。切出记录准备/接触/完成阶段，下一镜兼容承接，不重做已完成动作，不从准备跳到不可理解结果；刻意省略仍须因果可懂。

<a id="c07"></a>
## C07 连续剪辑、快闪与段界

切点回应动作阶段、视线落点、信息到达或延迟揭示，先定为何离开再定下镜对象，不轮流拍每个说话者。交流方向、目光与声源保持；正反打视线、越轴、出入画按[space](space.md)。普通相邻镜同主体/相近尺度时，检查无意跳动与无职责重复，优先有观看作用的视点/尺度/主次差异；约30°仅经验，不凑角度添镜，有意跳切/越轴须有表达依据。

**默认不越轴**：正反打、段界换视点、插入后回到人物，都留在关系轴同一工作侧。换侧只走已有的可见跨轴运镜、人物穿轴、中性插入后的宽景重建，或用户明确要求的直切；后两种按[space S05](space.md#s05)声明对调和地标。需要段界切换时，不为制造差异而越轴；留轴线同侧按观看需要选择尺度和视点，也可同构接续。

**生成大段边界**：技术分段不自动成为摄影切点。有新观察职责时可换尺度/视点，连续表演、持续观察或已定长镜有依据时可保持同构，不限用户点名的特例。是否能无缝接续另核入口与真实媒体，不以尾图或文字保证。完整判据归故事S7；预览体现实际镜头结果，完整稿给必要接续说明。

插入用已有相关物件/身体/环境，单证据可独撑一镜、不要求露脸，不用无关空镜遮必要动作，不默认每镜转场特效。跨场可用已有动作/形状/声音连接，有意硬切不强行平滑。声桥、续声与画面时钟由[audio AU04](audio.md#au04)统一：只有声音跨切不加画面秒，独立输入拼音轨说明留完整稿块外。

快闪仅用户要求或原故事需要时使用，区分当前动作切片与记忆闪回，不把普通受击变回忆，不默认重击声、回现实或静音结尾。成片占用和完整生成素材L分开：短剪辑目标不等于入口可生成秒数，按入口支持素材加余量再剪连续区间；全片从0到采用T连续覆盖，黑场停顿计时，叠化按并集一次计T/D而不缩L。全规则按路由容量，不附未落位快闪；仅已知fps才把秒换帧。剪取要保所需起止状态及接触/结果，不能只截起势。

交付只走质量检查一轮，不把专业深化加成默认前置或额外验收轮。

<a id="c08"></a>
## C08 摄影为表演留证据

在已定镜头内确定本拍真正要读的变化：人脸、整体轮廓、动物耳尾、机体朝向、已有手部/机构或对手反馈。先让该通道有可见尺寸、对焦和受光，再选择运动；不因“演技增强”全片改特写。小表情与关键交接同样重要时，优先选一个能同时读清两者的取景；不为“演技增强”加反应镜、插入特写或补拍覆盖，镜数仍按C01和story判断。

背面不能读嘴角，拉焦前后写清谁能看清；表演发生在运动/转焦中可以成立，但关键变化不能在不可读时已经完成。无脸角色依轮廓、朝向和节奏可读性选景别；大幅表演可在宽镜完成，近景也允许真实爆发。稳定构图可持续有戏，无需为了避免“生硬”固定每秒微动、每镜换尺度或新增摄影机运动。关键面部变化需读清时，按[facial-timing](facial-timing.md)把面部动作写成独立时间事件并落在可读尺度；该变化必须发生在脸可读且在焦时，不为微表情擅自加特写或加镜。
