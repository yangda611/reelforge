# 双时钟容量、剪取与完整稿评估

仅完整提示词、逐份输入容量核算、固定预算冲突、叠化/并屏、锚点或剪辑余量触发读取。普通无重叠单段预览在[计时T4](timing.md)核简单L/T即可；只提取旧稿不重新估时。参数证据与入口语法见[平台](platform.md)。

<a id="c1"></a>
## C1 同一候选方案的两套时钟

| 量 | 定义与检查 |
| --- | --- |
| T | 成片全局时间轴所有实际保留区间的并集；顺接才可直接相加。 |
| D_i | 第i大段成片保留区间并集；跨段重叠只去重一次，不随意挪归另一段。另有用户成片段上限U_D才核D_i≤U_D。 |
| L_j | 第j份完整生成素材长度，含实际生成的完整锚点与可舍余量，无论最终是否剪除；逐份同时≤用户U及已知平台V。V未知标待核。 |
| U/V | U为用户单份输入上限，V为当前平台/版本/模式已核实单次上限；不分段无U仍受V。单镜独立核每镜L，不拿所属大段D与V比。 |
| Y/W/A_keep | 核心剧情、未计入Y的快闪/过场、锚点实际成片保留占用。各项不重叠且不重复覆盖时T=Y+W+A_keep=ΣD_i，否则直接取全局并集。 |
| P/Q | 固定X的余量P=X−T；P<0的缺口Q=−P，P>0不等于已发生的停顿，成立性按计时T5。 |

必要事件、完整对白、关键接触和首次揭示都须在最终保留区间，不落到可舍弃余量。快闪/黑场/过场也占成片，不能附在已排满时间轴之外；目标0.7秒或2秒不是生成参数，只有已知帧率才换成帧数。原稿要求另计后期黑场时限定当前T范围，不冒称最终全片已闭合。

生成输入局部从0开始，成片使用全局时钟。无变速时，保留区间内 `成片时刻=该区间成片起点+素材局部时刻−剪取起点`。用户授权且不破坏声画才变速。整片连续输入只能对该输入整体首尾取舍余量，不声称每个内镜可独立剪掉取整差。

<a id="c2"></a>
## C2 不重复扣除、不偷减素材

- T已计实际保留锚点；锚点关闭/全剪时A_keep=0。无跨输入重叠，从T推总素材只加未保留锚点与其他余量；有跨输入重叠直接ΣL，不机械“T+余量”。同一输入内部叠化不自动增加L。
- 比较总容量时不能把完整锚点扣一次，又与已含保留锚点的T比较再扣一次；最终以每份L核U/V为准，总容量足够不证明每份可行。
- 并屏各独立镜仍保留实际源长度，共同映射区间按并集计成片；源保留长度之和不等于已核实ΣL。叠化两份各保留5秒，映0—5与4—9，则D=T=9；无其他余量时L各5、ΣL=10。只是映射例，不授权为了压片长自行叠化。
- 锚点有效完整1秒，成片只计保留部分。入口不支持1秒独立生成时，选支持的L并另标有效1秒，其余只能是可舍静止静音余量。增加段数后重核适用锚点、L/T、编号与保留端点，不能压剧情腾锚点。
- 所有Y/W/A_keep及段长来自同一排期；更改剪取或分段后只重核受影响数据、合法切点与接续。接近硬边界用合理偏慢/上沿检查脆弱点，不把上沿改成采用值，不宣称算术证明表演成立。

<a id="c3"></a>
## C3 结果与呈现

满足约束直接交当前阶段，不再问是否开始。勉强要定位自然发声、动作依赖或阅读的脆弱环节；可在现授权内修就修，牵动硬要求按[计时T5](timing.md)。单份超容量但全片自然T可行时，允许合法拆输入；全片X本身不足不能靠拆段解决。当前入口、参数或绑定未知时仍可交准备稿，不能冒称可投喂。

完整稿新建/条件改变时给简短评估；已审预览未变只说明沿用，局部细化只报本范围。可依适用项压为2—5行，不填空字段：

```text
【时长评估】语种、录音/朗读/文本依据、固定/范围/按内容/U约束、节奏。
发声与事件：S；对白主导且S>0才列R及所用区间，动作主导列主要非台词事件占用；核心约Y秒。
采用：去重后T秒，K段，各段D_i；必要时列L_j、余量/剪取/重叠/锚点保留及容量例外。
档位：所选档自然粗估与采用值偏差；超过约两成或邻档时写具体原因；固定X不按三档改总长。
结论：满足／具体脆弱点／具体缺口及可行调整。
```

时间总览预览不展示以上评估、不附计算过程或折叠说明，只显示标题、一句真实总长性质和四列表；有尚未解决的硬冲突不能把目标标成满足，按计时T5最短说明处理。计算能力仍在内部执行。
