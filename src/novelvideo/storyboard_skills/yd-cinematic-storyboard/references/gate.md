# 前置确认与条件状态

仅在新故事、新建分镜、把故事变成视频提示词、或剧情另起的续集时读取并执行。仅润色、已有稿忠实转预览、只报告问题、解释/修改技能不走闸门；同故事返修、往下接拍、换画幅和加版本沿用已确认条件，只处理新冲突。用户本轮及此前有效授权优先。

<a id="g1"></a>
## G1 一轮确认

新故事默认第一轮只发【开拍前确认】，然后等回复；六项条件加可选处理方式；第6项仅按G3可省，其余不论用户是否已给都列出，已给值预填“你给的”，其余填“推荐”。这一轮不输出时长评估、预览、分镜片段或默认试稿；可以内部读取故事和粗估，只有卡片中的粗估秒数/段数可显示。

| 项 | 参数与预填 |
| --- | --- |
| 1 | 成片发声语言。中文原稿不等于普通话发声。 |
| 2 | 时长约束：按内容定时（通常推荐）／固定全片总长／范围；单份上限不能代替总长规则。 |
| 3 | 节奏：紧凑／标准／舒缓。按剧情职责推荐：短促喜剧、连续冲突、快节奏短片可推荐紧凑；普通剧情、关系交流、温情叙事通常推荐标准；有明确铺陈、等待、抒情或仪式体验时可推荐舒缓。信息不足推荐标准，不把未指定等同于紧凑。固定总长只改变预算分配，用户已指定优先。 |
| 4 | 视觉方向：一级选项固定分为“写实（真人电影质感）”“CG（三维动画）”“二维动画”“三渲二”。写实与CG分别成项，一次选择其一；卡片、逐项选择工具、总推荐和复制回复块使用同一名称。未指定时推荐写实；本任务已明确选择CG则预填CG。CG内部的材质、光照与动画表现按本任务已确认参考展开，不将渲染风格拼入一级选项。旧项目偏好只作参考，本轮明确分类与选择优先。 |
| 5 | 画幅。未指定时推荐16:9；仅说竖屏或发抖音时推荐9:16，并注明依据。 |
| 6 | 单份生成输入上限U：未指定时推荐“每份最长30秒”，另列“每份最长15秒”“不分段”“其他”（常见AI视频入口单次上限多为30秒或15秒）；用户说明实际入口单次只支持15秒时把15秒标推荐并注明依据。**U是每份的上限，不是要凑满的目标**：先按剧情定全片自然长度，再在剧情断点分段，每段只装这段剧情的自然长度；剧情只有16秒就出一份16秒，不为用满30秒拉长镜头、加停顿、加空镜、慢放或加戏。流程见[story S0](story.md#s0)。推荐不是平台能力证据。 |
| 7（可不答） | 处理方式：第一项“先预览（默认预填）”，第二项“直接完整提示词”。当前请求未明确选择直接完整版时，一律预填先预览；“做分镜”“出提示词”“使用这个skill”不视为跳过预览。只有当前明确要求直接完整版、明确跳过预览，或当前骨架已确认且要求细化，才采用完整版。历史测试、引用对话、示例和文件名不作为本次阶段选择。 |

故事语言、题材、另一个故事参数、技能示例和助手判断都只能作推荐，不能记为用户已指定。需翻译的语种与采用授权按[路由](routing.md)处理。

<a id="g2"></a>
## G2 免确认与回复语义

- 明确“不用前置确认／不用确认／不需要前置询问／跳过确认／不用问我／全权交给你”才免确认：用已给值，余项按推荐，直接进已授权阶段；仅本故事有效。“以后都不用确认”适用于本对话后续新故事。
- “直接完整版／直接出提示词／跳过预览”只选第7项，不免前置确认；初始需求中的“其余你定／按推荐／默认就行／沿用上一套”只决定预填，仍发卡片。
- 回复“确认／没问题／可以／就这样”，或仅修改几项，即整卡确认：改项用新值，其余沿用预填。回复卡片时“其余你定”，未改项按推荐执行。
- 只在某项明确未定、自相矛盾、或歧义会改变结果时问该项一次，如动漫介质不明、只答英语却不清楚是否授权翻译、非常规画幅冲突；不重问其他项。确认后“改成16:9”等明确变更直接生效，不再发卡片。“考虑换横屏”只讨论。
- 用户说“严格模式／先逐项确认”就是默认确认，不增加审核轮。已有授权不能因技能条款被拒绝。

<a id="g3"></a>
## G3 粗估与分段项

先按[计时T2](timing.md)粗估：对白主导可用S×1.45/1.8/2.3辅助；动作主导按唯一因果节点与真实动作过程估计，不把每次击中拆开重复计时。节点秒数和档位倍率仅是参考，必要过程/反应有内容依据时允许偏离。未定语言暂按原稿语种并注明。三档只比较同一故事不同观看职责，不为显示递增加戏；固定全片X时只改变X内分配。卡片秒数不是正式镜长的下限或上限。卡片上三档秒数填写前必须过[计时T2](timing.md#t2)的“演一遍复核”：紧凑档动作节点默认约1秒，边做边说的台词不和动作直接相加；复核不过先查重复计时，不把偏长的数字直接上卡。

三档粗估中最长的一档不超过15秒（用户固定全片总长时按该总长）时，无论选哪种上限都只有一段，卡片删第6行，其他编号不变；内部记“不分段，粗估最长约X秒”。否则两种上限分别写三档段数 `ceil(各档粗估/U)`，三档相同可只写一个数；段数为1表示按实际长度出一份，不补满到上限。用户确认后按[story S0](story.md#s0)先在剧情断点正式分段，再在段内排镜，最后用实际镜长复核，不把粗估当定稿。

免问第6项后不重发卡片：已有用户上限优先；否则采用U30（技能判断），用户已说明实际入口单次更短时按入口；入口未核实时注明只是计划值。全片能装进一份就按实际长度出一份，不补满。已核实V更小时同时核V，不把U当平台能力。选“不分段”且长度需要入口支持时说明具体限制，超过已核实V按[容量冲突](timing-capacity.md)处理，不默改拍法。

<a id="g4"></a>
## G4 条件状态与呈现

只在当前任务上下文记“待确认→条件可执行→当前阶段”，不另建问答状态文件、不伪造历史。六项加处理方式的值各附合法来源：用户指定／用户确认推荐／用户授权代定／本任务沿用／技能默认（仅处理方式）／技能判断（仅分段免问及自动分段）。推荐值获“确认”后用“用户确认推荐”；回复卡片时“其余你定”或免确认选推荐时用“用户授权代定”。

状态不能认定为“已确认”或“用户免确认”，或者来源不合法，就不可交分镜；回到必要的确认卡片。**时间总览预览不显示条件回执或来源表，也不把它们放进折叠区、复制文本或下载MD；内部条件检查照做。** 仅审校、润色、忠实提取本就不显示回执。完整稿按[完整输出](full-output.md)保留回执；分段免问/免问后自动分段的原因放完整回执相应项。

完整回执格式：
`【条件回执】确认：[已确认/用户免确认]｜语言：[值]（来源）｜时长：[值]（来源）｜节奏：[值]（来源）｜风格：[值]（来源）｜画幅：[值]（来源）｜分段：[值及必要原因]（来源）｜处理：[值]（来源）`

<a id="g5"></a>
## G5 卡片

运行环境有逐项选择工具时，必须用工具逐项提问，不用长文把六项挤在同一段里。每项单独一问，选项写全称和后果，推荐项标“推荐”，已给值预填为当前项。用户可以逐项改，也可以对全部推荐直接确认。没有逐项选择工具时，才用下方文本；文本同样逐项分行，不合并成一段说明。

无论用工具还是文本，都再给一个可复制回复块。块内每项独占一行，写编号、所选全称、必要秒数和来源，不用“1A 2B”这种缩写。用户复制后只改要动的行，整块发回即可。回复块前另给一句“总推荐”，把当前推荐项连成一句，方便整句复制后只改其中几项。

```text
【开拍前确认】可以逐项选择；也可以复制下方回复块，只改要动的行，整块发回。没改的行沿用当前值。
1 对白语言：普通话（推荐） / 英语（由我翻译） / 其他
2 时长：按内容定时（推荐） / 固定全片__秒 / 范围__—__秒
3 节奏：紧凑约__秒（常规过程省略，保必要反应，适合短促喜剧或连续冲突） / 标准约__秒（关键过程与关系变化看清，适合普通剧情与温情交流） / 舒缓约__秒（有职责的铺陈、等待和余韵）；按G1在适用项标“推荐”，固定总长只影响分配
4 风格：写实（真人电影质感，推荐） / CG（三维动画） / 二维动画 / 三渲二 / 其他
5 画幅：16:9横屏（推荐） / 9:16竖屏 / 其他
6 分段：每份最长30秒（推荐；紧凑__/标准__/舒缓__段） / 每份最长15秒（紧凑__/标准__/舒缓__段） / 不分段 / 其他；这是每份的上限，不是要凑满的长度：按剧情分段，剧情只有16秒就出一份16秒；需要分几份时在剧情的自然断点切开，尽量不留很短的尾段（常见AI视频单次上限是30秒或15秒，以你实际用的入口为准）
7 处理方式（可不答）：[当前预填：先预览（技能默认）] 先预览（默认首选） / 直接完整提示词（用户明确选择时采用）
[必要的粗估前提；没有删本行]
以后不想确认，可说“不用前置确认”，或“以后都不用确认”。

【总推荐，可整句复制后修改】
[本轮语言]；[本轮时长]；[按剧情推荐的节奏]；[本轮视觉方向]；[本轮画幅]；[本轮输入上限及未核实状态，免分段时省略]；[本轮处理方式]。

【复制后修改】
1 对白语言：[当前全称]
2 时长：[当前全称及必要秒数]
3 节奏：[当前全称及对应秒数]
4 风格：[当前全称]
5 画幅：[当前值]
6 分段：[当前全称及对应段数]
7 处理方式：[先预览（技能默认）；仅当前明确直出授权时改为直接完整提示词（用户指定）]
```

节奏和分段项说明应保留实际选择的含义；推荐标记按本轮剧情和入口证据动态填写，不照抄示例默认。逐项选择工具、文本卡片、总推荐句和复制块全部使用本轮实际预填值及来源，彼此一致；用户已给的值也写入，不另造推荐。处理方式未明确时，工具把先预览放第一项并标默认预填，文本与复制块也填先预览；不根据旧对话自动选完整版。风格一级选项保持写实与CG独立，已经选择CG时总推荐也同步为CG。按G3删去第6行时，总推荐和复制块同步去掉分段项。卡片后结束本轮。

（说明：如果用户选择了 `CG（三维动画）`，且后续需要进一步定写实渲染还是风格化渲染，可在进入完整版或确认卡后由[视觉风格展开](style.md)承接，不在一级选项里把两者拼成混合标签。）
