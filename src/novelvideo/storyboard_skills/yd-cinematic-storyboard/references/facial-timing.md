# 面部动作与微表情时程

仅在需要细腻面部表演、混合情绪、表情转变，或用户点名微表情 / FACS 时读取。普通远景、背影、纯身体表演不读本文件。面部写法最终编译进 [acting](acting.md) 的动态时间轴，并受其铁律约束：**写在已排镜长与镜数之内，不为展示面部细节加镜、加停顿、延迟回应或拉长时长**。术语与科学边界见 [evidence-boundaries](evidence-boundaries.md)。

<a id="ft1"></a>
## FT1 核心：每个面部动作是独立的时间事件

对每一个相关的面部动作，分别描述其时间过程：

- **Onset 出现**：动作开始并增强。
- **Apex 峰值**：达到最清晰的强度，或短暂保持。
- **Offset 消退**：减弱，或转入另一个动作。

不同的面部动作可以重叠，也可以在不同时刻达峰。**不要把整条 Onset–Apex–Offset 曲线套在整个情绪或整个场景上**：真实表演里，嘴角可能已开始回落，而目光仍停在对方脸上，下颌的紧张更晚才松。

时间写法遵守分镜计时：入口为连续整数秒时，把亚秒与错峰写进整数窗内的相对位置（"紧接着""句后半""半拍之后""话尾时"），不伪造毫秒级精度；不为展示微表情新增镜头或延长镜长。脸部可读性先于细节：该部位失焦、被遮挡或处于远景时，先按 [acting A03](acting.md#a03) 改用可读的身体通道，而不是把细节写进看不见的地方。

<a id="ft2"></a>
## FT2 面部通道与可读尺度

| 取景 / 可读性 | 优先使用的面部通道 |
| --- | --- |
| 面部近景且清晰 | 目光方向与焦点、眼睑开合与张力、眉、嘴角起落、抿唇、下颌松紧、面颊、必要时的湿润或轻颤、左右不对称 |
| 中近景 | 较大的面部变化、准备发声与收口、下颌与嘴部紧张；细微肌肉只在确可读时写 |
| 全景 / 远景 / 背影 | 不写读不见的泪光或眉肌；改由轮廓、重心、转向、停住、距离承载 |
| 遮脸 / 面具 / 局部 | 只用已入画部位与既定声音；没有第二可见通道就不凑 |

面部通道是"可读证据"而非必配清单：一个节拍先选一个主要表达，再带真正起作用的相容通道，不要同一瞬间堆齐眉、眼、嘴、下颌、呼吸七项。

<a id="ft3"></a>
## FT3 混合情绪的分层编排

多层情绪按"主行动 + 一个真实泄露通道 + 分层时程"写，不写"悲喜交加""神色复杂"这类并列标签：

1. 先定表面任务（此刻在维持什么：礼貌的笑、平稳的声音、未撤回的动作）。
2. 再选实际泄露的一点（哪个部位、在哪个触发之后失守）。
3. 用分层时程安排：表面任务的 Offset 与真实情绪的 Onset 错峰，而不是同时切换。

原稿直接爆发就直接爆发，不强套"先忍住再崩溃"；克制、迟疑、喜剧夸张、安静保持都可成立。泪落、笑开、声音破裂只在相应触发之后发生，不提前演出结局。泄露按角色当场能感知的证据发生，不由语气擅判说谎或秘密。

<a id="ft4"></a>
## FT4 保持与冻结的区别

有意的 Apex 保持仍需自然呼吸与微小调整，不等于把脸冻住。区分"有意保持"与"模型冻结伪影"：除明确冻帧外，不写"全身完全不动"去冻结呼吸、眨眼和正常表演。反光与眼神光由既有照明决定，不用来替代思考。

<a id="ft5"></a>
## FT5 FACS 与术语使用边界

- 默认用**可见的解剖描述**（"嘴角先停住再放平"），不写专业肌肉名。
- 需要更精细时可用 **FACS-informed 的面部动作时程**写法；AU 编号仅在用户明确要求且证据充分时使用，并写"可能的 AU"。
- 不把 AU、FACS 当作模型已具备的控制参数来宣称；也不靠面部配置诊断角色的内心、真假或欺骗。
- "微表情"只用于短暂、自发、难控的泄露，且有充分证据时；编排的多秒表情不叫微表情。详见 [evidence-boundaries](evidence-boundaries.md)。

<a id="ft6"></a>
## FT6 写法示例

**收笑（贴近台词、不加停顿）**

- 弱：乙愣了一下，神情失落，停顿片刻后强颜欢笑。
- 强：乙问完仍看着甲，原本抬起的嘴角在"约了人"说出时停住（Apex 保持），随后嘴角小幅逐级回落（Offset）；"哦"出口时目光短暂垂向桌面，"那下次"时回到甲脸上，嘴角重新抬起但低于刚才。收笑与甲的话尾重叠，不另加停顿，也不新增道具或动作。

**告别（混合情绪的分层时程）**

- 弱：她笑着哭，表情复杂。
- 强：她维持着刻意的笑向前走（主行动：撑住体面）；风力吹乱头发时她别到耳后，呼吸保持自然以免笑冻结。对方的背影远去不回，她的嘴角开始小幅度逐级下降（面具 Offset），眼部的收紧慢慢松开，目光失去固定目标；随后她移开目光、抿唇、下颌逐渐收紧（泄露 Onset）。再往下，目光垂下，唇与下颌的紧张缓缓松开，嘴唇微张、一次克制的呼气（释放）；最后她重新抬眼，一个很小、带苦意的笑渐渐形成，而残余的紧张仍在。各动作错峰，不共用一条曲线。

示例只演示写法；镜长、镜数与台词不变，不迁入真实故事。接入完整分镜时按 [full-output](full-output.md) 写进动态时间轴，并按 [timing](timing.md) 核时长。
