# 任务阶段、翻译与修订

本文件只管阶段和授权；新故事前置条件见[确认闸门](gate.md)，估时与分段见[计时](timing.md)。只改skill、只解释、只审校，不启动故事创作。

<a id="r1"></a>
## R1 阶段

- 默认新建：条件可执行→内部排镜计时→[时间总览预览](preview.md)→当前范围获准后完整细化。前置卡和选择工具把“先预览（默认预填）”列第一项并实际采用；“做分镜”“出提示词”“使用这个skill”沿此默认，旧测试或引用对话不构成当前直出授权。当前明确跳过预览或要求直接完整版时按下一条执行。只要预览则交付后结束，不附强制升级话术。
- “只要提示词／一步到位／直接完整版／跳过预览”、骨架已认可且要求细化、或明确“修改后直出”，直接完成相应范围；这些词不等于免前置确认。“直接分镜”仅跳故事润色，默认仍先预览。
- 已约定“确认预览后做完整版”，当前范围已完整交付且无待改项时，“出完整分镜提示词”（预览末尾提醒里给的回复语）或“确认／没问题继续／确认继续”都可直接推进；用户用别的说法明确确认也照样推进，不强求这句原话。只预览、纯提取或纯询问里的“确认”不扩权；预览未交完时“继续”只续剩余预览，部分确认只覆盖明确部分。混合阶段确有歧义只澄清影响范围。
- 纯问题先解释；明确修改或本次已确认编制错误在授权内直接修。完整稿返修仍给完整稿，不退全片预览。

<a id="r2"></a>
## R2 翻译

区分原稿语言、成片发声语种和说明语言。明确“翻成英语并做分镜／英文对白版”即授权翻译及采用，不复问。只说“英语”而不清楚由谁译，或与原词必须保留冲突，只补问译稿/翻译授权，其他参数不重问。

要求先审译稿才等待，否则获授权后连续执行，不加译稿审批。翻译不授权新笑点、删意或加词；按最终发声句重算语速、信息到达和切点。释义位置按[声音](audio.md)，不能混入实际发声文本。

<a id="r3"></a>
## R3 三条任务路径

**A 润色**：只在授权内细化既有感官与可见行为，保留原台词、画内外声源；不补未知天气、物件、人物、事件、履历或结局。仅润色交付即止；明确“审润色后分镜”才等，明确“润色后直接分镜”则连续完成，不再问一次。

**B 新建/细化/返修**：按条件和阶段调用[故事流程](story.md)。新建先内部完成时长/容量判断；时间总览预览只显示标题、一句总长和四列表（聊天最后另附[preview](preview.md)规定的固定提醒），不能夹回执、估时分析、段界对照、空间或长对白附录。完整稿按[完整输出](full-output.md)列必要素材状态、条件回执/评估及执行字段。预览细化时保留镜号、事件、原对白、镜长与关键拍法，只展开已定表演和空间；条件未变不重做公开评估。

**C 忠实转预览**：直接按原镜头单位提取，保留原号/分组/顺序/时钟性质、动作、声源、空间与揭示，不重导演或重估。原稿无号才加“审阅序号”，重复号附原段名。未知或矛盾按对应行最短标明；缺视角、运镜、全局映射写“原稿未说明”，不补表情、译文或素材映射。原稿仍是完整内容依据；对应预览行写全原话，未经授权不改词、删词或重新定时。转完结束，不因条件不齐卡住。

<a id="r4"></a>
## R4 修改与续批

只动点名镜头及真正受影响的接续、时间、分组、素材引用；不为维持旧总长改无关镜。同故事明确参数变更直接生效，新画幅分支保留原版参数；上下文不足先读可用授权资料，不翻无关项目、不声称找回未有记录。改硬事实、原台词、总长或锁定拍法未获授权时报告具体冲突及可行选项，只暂停受影响部分。

镜号变动需迁移新旧内容与确认状态；仅编号改变不撤销确认，不受影响大段不重编号。独立输入仍补齐自足上下文，不用“同上”。用户明确要全片更新才重发全片。

分批是文字交付，不改变镜头、大段、输入时钟或编号；有实际容量限制才在完整镜头/独立输入边界续写，标总范围、已交付及剩余范围，能继续就做完，不能因篇幅漏后半却称全片完成。当前阶段完成后按R1推进。
