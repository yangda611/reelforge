# 摄影深化（低频分节）

<a id="ca00"></a>
## CA00 明确加载条件

普通固定/推拉/跟随等任务先用camera核心，不读本文件。用户给出焦距/FOV/光学疑问，只读CA01；命中特定专业运镜，只读CA02的该行及总则。关键场次的拍法比较按[story S4](story.md#s4)在内部简要完成，不加分析字段或额外交付轮。

<a id="ca01"></a>
## CA01 光学口径

36×24mm全画幅、直线投影的近似**对角**FOV：24mm约84°、50mm约47°、85mm约29°、135mm约18°；同机位从宽环境到窄局部。不是水平FOV或平台参数定义，画幅裁切会改变实际视场。

透视由机位位置主导；保持主体景别时后退机位常带来背景压缩，不能归因于焦距本身。景别还依主体尺度/距离/视场，景深依光圈/对焦距离/画幅，不把焦距绑定距离、浅景深或锐度。一般选焦距或明确口径FOV之一，再独立写景别/机位/运动；如85mm＋中近景＋平视＋推近并非重复，其他参数只有实际需要才加。

<a id="ca02"></a>
## CA02 运镜词典与复杂路径

先按camera判断动机与可行性。专业名称后补看得见的运动；器材名（无人机、摇臂、轨道、稳定器）可能入画，优先视角/机位描述，实际误生器材时换写法。一个主运动，必要组合说清先后/协同；写起点、方向/路径、速度、终点或切出中状态，停住时落幅有人与画面侧；实际仍动不得写成停稳。

| 运镜 | 实际是什么 | 写法要点 | 常见误写与陷阱 |
| --- | --- | --- | --- |
| 固定镜头 | 机位、朝向和焦距全程不变，只有画内的人和物在动 | 写“固定机位，镜头完全静止，不推拉、不摇移”，再写画内动作 | 只写“固定镜头”时，模型常自行加缓慢推近或漂移；必须静止就把这几项都写上 |
| 推 / 拉（含轨道推拉） | 机位朝主体靠近或远离 | 写从什么景别到什么景别、推到谁身上停 | 不同于变焦：变焦时机位不动，前后景没有相对位移 |
| 摇（水平摇、上下摇） | 机位不动，镜头原地转向 | 写“镜头原地向右（或向上）转，从[A]摇到[B]”；需要时补“画面内容向左滑过”。可附 pan / tilt | 不是“镜头向右移动”，平行移动叫横移；只写“向右”时，模型可能理解成画面内容向右移 |
| 横移（含轨道横移） | 机位沿与镜头朝向垂直的方向平移 | 写镜头朝向哪边、机位向画面左/右哪侧平移，例如“镜头朝向橱窗，机位沿街向画面右侧平移”；跟着谁、停在哪 | 机位朝走廊深处拍、顺着走廊前进，是推进或跟拍，不是横移；跟着对话的两人横移时，机位仍留在轴线同一侧 |
| 升降 | 机位整体升高或降低 | 写起止高度，例如“机位垂直升高，镜头保持水平”，必要时再写“同时略微下摇，保持主体在画面中” | 只写“镜头向上”，会被画成上摇（机位不动、仰头） |
| 摇臂 | 机位沿大弧线升降，常带横向位移 | 写起止高度、横向方向和落幅，例如“机位从人群头顶高处缓慢下降并向画面左侧移动，落到甲的中景” | 同时升降又横移就是复合运镜，按本节末尾写主导运动和起止状态 |
| 跟拍（前跟、后跟、侧跟） | 机位随主体移动，保持距离 | 写机位在主体前方倒退、身后还是侧面；用景别表达距离（如“保持中景跟随”），写主体在画面哪侧 | 不写具体米数；侧跟时主体的行进方向就是银幕方向，前后镜保持一致 |
| 稳定跟随 | 机位平稳流畅地跟随，路线自由，没有晃动 | 写“平稳流畅地跟随[人物]穿过[地标]，没有手持晃动”，以及跟随位置和景别 | 和手持在同一镜冲突时只保留一种 |
| 环绕 / 弧形 | 机位沿弧线绕主体移动 | 写起点在哪一侧、绕多少度、终点在哪一侧；绕过90°时写落幅里谁在画面哪侧 | 绕过两人连线就是越轴，按[空间越轴S05](space.md#s05)写明对调后的左右 |
| 滑动变焦（希区柯克变焦 / dolly zoom） | 机位移动同时反向变焦，主体在画面里大小不变，背景透视改变 | 写“主体在画面中大小不变”，再写方向：机位后退同时变焦推近时，背景逐渐逼近、显得变大；机位前推同时变焦拉远时，背景向后退远、空间被拉长 | 中文里的“变焦推拉”通常指普通变焦，不要用这个名字；不写“背景严重扭曲”，容易被画成鱼眼畸变 |
| 光学变焦 | 机位不动，只改视野 | 写“机位不动，镜头变焦推近，画面等比放大到[主体/景别]，前后景之间没有相对位移”，速度另写（缓慢或急推） | 不能代替推拉；背景压缩感来自机位远，不是变焦本身 |
| 快速变焦（急推 / 急拉） | 机位不动，短时间内急速变焦 | 写“机位不动，镜头急速变焦推近到[主体/景别]，约半秒完成” | “快速推近”会被理解成机位冲上前；要变焦效果就写“变焦”“画面等比放大” |
| 拉焦（转焦） | 焦点从A转到B，通常机位不动 | 写A、B各在前景还是后景，转焦前A实B虚、转焦后B实A虚，由什么动作或声音触发 | A、B必须在不同纵深才看得出转焦；转焦前后两人的必要信息都要可读 |
| 手持 | 机身带呼吸感的不规则晃动 | 写晃动强度（轻微/明显）和用途 | 需要看清的脸、手、证据不能被持续晃动遮住 |
| 甩镜 | 快速摇镜，带运动模糊，常作转场 | 写从哪甩向哪、在第几个镜头（入口为 Seedance 2.5 时可写第几秒） | 不能用甩镜遮掉必须看见的动作；作转场且两镜分开生成时，前镜结尾和后镜开头都写同方向的甩动模糊 |
| 主观镜头 | 机位在人物眼睛的位置 | 写“第一人称视角，[人物]本人不在画面中”，以及这个人的手是否入画 | 画面里不出现此人的脸和头（镜面倒影除外）；输入里带了此人的参考图时更要写明，模型常把此人画进画面 |
| 航拍 | 从空中移动拍摄，从低空掠过到高空俯瞰都有 | 写高度、方向和俯角，例如“高空俯瞰视角，缓慢向前飞越河面” | 器材名可能入画，见本节开头 |
| 一镜到底 / 长镜头 | 较长时间不切，可由连续表演、场内调度或摄影机运动推进；固定机位亦成立 | 按时间段写机位路径和人物调度，例如“0—4秒跟随甲进门，4—8秒停住，转向乙” | 超过平台单次时长时先说明限制；只有用户授权连续分段/延长，且入口支持所选接续机制时，才拆为多份并写清接缝状态，否则按路由处理冲突，不自动承诺首尾帧接续或暗中切镜；保留长镜头的职责以[camera C01](camera.md#c01)为准 |
| 遮挡揭示 | 前景物挡住画面，移开后露出主体 | 写挡住的是什么、怎样移开、露出谁、露出时在画面哪侧 | 揭示时机服从故事第三步的知情边界 |
| 穿越 | 镜头穿过门框、窗口、缝隙进入另一空间 | 写穿过的东西长什么样、穿过前后各是什么空间 | 写实场景不能穿墙，用户要求超现实时除外 |
| 荷兰角 | 画框绕镜头光轴倾斜，倾斜角度固定 | 写“镜头绕光轴倾斜约15°，地平线和门框从画面左低右高” | 不是让建筑或人物本身歪斜；和运动中旋转的镜头区分；不当成“紧张”的默认写法 |
| 俯拍 / 仰拍 / 顶拍 | 机位高于、低于主体，或在正上方垂直向下 | 写机位高度和角度大小；顶拍写“镜头垂直向下” | 只写“正上方”可能被画成大俯角斜拍；不把仰拍固定等于“英雄”、俯拍等于“弱小”，按要显露的上下关系选 |
| 子弹时间 | 主体动作定格或极慢，镜头环绕 | 写“时间几乎静止，摄影机以正常速度环绕约[角度]”，并写哪些东西一起静止（水滴、碎片、头发） | 模型常把“极慢”也套到摄影机上；环绕角度大时同样涉及越轴 |

复合运镜拆成“主导运动＋起止状态”来写，一镜只保留一个主导运动；不越过关系轴，越轴按[space S05](space.md#s05)。原稿/用户已指定慢动作时保留并计入真实总长，不新增慢放凑时长。
