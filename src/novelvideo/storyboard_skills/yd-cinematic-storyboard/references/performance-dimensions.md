# 表演维度库（按需加载，不整库进提示词）

本文件是角色表演的内部审查清单：先宽分析、再窄选择。不要把整张维度表复制进提示词或分镜正文；每个镜头只选真正能改变可见表演的少数维度。表演仍受 [acting](acting.md) 铁律约束：写在 [story S0](story.md#s0)/[S6](story.md#s6) 已定的镜数与镜长之内，不因细化加镜、加停顿或拉长时长。

读取时机：设计细腻、多节拍、多角色、对白密集或身体细节丰富的表演，或在多个表演细节之间取舍时读取。普通单人镜、纯走位或无需细腻表演的场景不必读取。面部动作的时程写法另见 [facial-timing](facial-timing.md)。

## 1. 情境与校准

| 维度 | 怎么定 | 示例 |
| --- | --- | --- |
| 前史 | 镜头开始前刚发生什么 | 她已经等了两小时 |
| 入场状态 | 以一个进行中的身体与注意状态进入 | 手指发冷、双腿疲惫、注意锁定到站人群 |
| 行为基线 | 角色常态的动作、声音与自我调节水平 | 平时克制，因此一次下颌轻颤就足够可读 |
| 关系与地位 | 亲密、距离、亏欠、权力、信任与地位压力 | 她想靠近，但仍保留一步距离 |
| 潜台词 | 说出/展示的信息与真实意图分开 | 嘴上说"没事"，手上反复抹平围巾 |
| 社会面具 | 公开行为与私下流露分开 | 她一直撑到人群散去才松 |
| 身体状况 | 疲劳、伤病、疾病、年龄、训练、醉酒 | 旅途疲惫让他停下后恢复更慢 |
| 感官环境 | 温度、风、疼痛、声音、地面、重量改变行为 | 寒冷让她耸肩、呼气成雾 |
| 角色身份 | 职业、文化、经历、习惯塑造行为但不刻板化 | 医生先观察再伸手 |
| 表演风格 | 写实、情节剧、喜剧、惊悚、风格化的校准 | 写实偏余势与克制；喜剧可锐化反应时机 |
| 镜头尺度 | 表演幅度匹配取景 | 近景靠呼吸与焦点转移；远景靠重心、路径与距离 |

## 2. 戏剧驱动与矛盾

| 维度 | 怎么定 | 示例 |
| --- | --- | --- |
| 目标 | 角色试图获得、保护、隐藏、确认或改变什么 | 确认他是否还在乎 |
| 外部阻碍 | 来自环境或他人的阻力 | 乘客挡住了她的视线 |
| 内部干扰 | 来自角色自身的干扰 | 害怕被拒绝打断了她的寻找 |
| 赌注与紧迫 | 失败的代价，以及为什么必须现在行动 | 站台正在清空，这可能是最后机会 |
| 冲动 | 角色想做的动作 | 朝他跑过去 |
| 克制 | 角色阻止自己做什么 | 维持体面，不先动 |
| 策略 | 可演的策略，不是情绪 | 扫视、核实、呼喊、掩饰、拖延、对峙、抽离 |
| 策略转变 | 仅在失败、新信息或决定之后换策略 | 电话无人接听，她停止寻找、准备离开 |
| 贯穿线 | 把局部策略连到场次目标 | 每一次扫视、呼喊、停顿都服务于确认这段关系 |
| 动作层级 | 主动作与次要事务分开 | 主：辨认他；次：整理围巾以掩饰紧张 |
| 反差 | 让通道在需要时相互矛盾 | 脚步稳定，手指却收紧 |
| 克制动作 | 把拒绝、延迟、未完成当作主动行为 | 她抬手要挥，却停在半空 |

## 3. 感知、认知与反应

只在场景依赖新信息时用完整链条：

`预期 → 察觉 → 定向 → 辨认 → 解读 → 决定 → 行动`

| 维度 | 怎么定 | 示例 |
| --- | --- | --- |
| 预期 | 角色预测什么 | 她预期他随最后一批乘客出现 |
| 预期违背 | 现实修正预测 | 最后一名乘客离开，再没有人跟出来 |
| 察觉阈值 | 刺激何时真正进入注意 | 第一声呼唤只被当作不确定的背景声 |
| 定向 | 眼、头、身体按顺序转向刺激 | 眼先动，头随后 |
| 辨认 | 把"感觉到"与"认出"分开 | 她先找到声源，再认出那个声音 |
| 解读 | 信息获得意义的那个瞬间 | 听懂是谁在叫之后，她的扫视停住 |
| 决定阈值 | 承诺行动之前允许犹豫 | 她上身开始转，脚却仍钉在原地 |
| 反应延迟 | 加入可信的延迟而非瞬时反应 | 转身之前有半拍停顿 |
| 注意力转移 | 跟踪焦点路径 | 人群 → 手机 → 空站台 → 声音 → 他的脸 |
| 焦点深度 | 有意使用近、远、失焦、重新锁定 | 目光先失焦，再锁到他脸上 |
| 倾听 | 表现"接收"，而非只等自己开口 | 她屏住呼吸，等第二声呼唤 |
| 自我监控 | 角色察觉并调节自己的外露 | 她察觉笑在褪，刻意把它补回来 |
| 可打断性 | 新信息能中断或改向未完成的动作 | 那声音打断了她转身离开 |

## 4. 动作节拍构建

当以下至少一项改变时开新节拍：触发或可得信息、注意目标、解读或决定、策略或动作方向、关系地位或距离、主动作。

每个节拍记录：时间区间、入场余势、触发或新信息、当下意图/策略、一个主动作、一到两个辅助通道、一个有用的动态修饰、切出状态。

用场景专属节拍名，如"维持面具""核实声音""允许靠近"。不要把创作序列当成普遍情绪定律。节拍不等于摄影镜头：只有观察对象、空间判断或揭示时机确有需要才切镜，见 [acting A08](acting.md#a08)。

## 5. 可见表演通道

| 通道 | 可用控制 |
| --- | --- |
| 注意与倾听 | 目光目标、凝视、回避、扫视、预期、焦点深度、倾听、反应延迟 |
| 呼吸 | 吸气、屏住、吸气中断、浅呼吸、呼气、叹气、恢复、句中换气 |
| 声音 | 起声、停顿、重音、音高、语速、音量、气声、紧张、渐弱、打断 |
| 姿态与重心 | 重心、平衡、开合、肌张力、肩、胸、站姿、重心转移 |
| 移动 | 起步、停步、步幅、节奏、路径、靠近、退开、犹豫、变向 |
| 手与手势 | 预备、划动、保持、收回、自我触碰、未完成手势、替代、修正 |
| 道具与衣物 | 握持、压力、重量、摩擦、物体状态、织物阻力、延迟的次级运动 |
| 头与目光 | 头角度、眼头顺序、焦点转移、眨眼时机、会聚、不对称 |
| 面部 | 眼睑、眉、面颊、嘴角、抿唇、下颌、下巴、湿润、颤抖、不对称 |
| 生理 | 吞咽、眨眼、可见呼吸、颤抖、呼吸紊乱、疲劳；仅有动机时写 |
| 走位与空间 | 朝向、领地、高度、距离、停点、靠近、退开 |
| 接触 | 预备、部位、压力、时长、回应、松开、回缩 |
| 对手配合 | 轮流、打断、镜像、同步、失同步、地位交换 |
| 环境反应 | 冷、风、声音、疼痛、地面、物重、人流、空间阻挡 |

不要把姿态、眼泪、目光、呼吸或吞咽当作 FACS 动作单元；不要用单一可见征象诊断隐藏的情绪真相。

## 6. 运动与时间动力学

| 维度 | 怎么定 | 示例 |
| --- | --- | --- |
| 启动点 | 选哪个身体部位先动 | 眼先启动，头与躯干随后 |
| 传导链 | 让运动或张力沿身体传递 | 下颌紧张传到肩，再到手指 |
| 轨迹 | 直、曲、绕、扩张、收缩、回撤 | 她的手走一个小弧，而非直线靠近 |
| 力度与阻力 | 轻/重的用力、内部阻力、控制程度 | 转身像从胸口被抵住才开始 |
| 预备 | 可读时给出动作前的组织 | 拥抱前一次轻吸气与抬肩 |
| 执行 | 以可行密度主导主动作 | 本节拍只完成转头 |
| 保持 | 有目的地静止，仍带呼吸与微调整 | 她保持对视，胸口仍在起伏 |
| 回收与收回 | 动作后身体回位、重组或撤回 | 手放下，手指却仍蜷了一瞬 |
| 惯性 | 停步后发、衣、道具与身体仍带运动 | 她脚停了，衣摆仍向前 |
| 制动 | 运动如何减速或被制止 | 向前的步子在完全停下前先变短 |
| 平衡与稳定 | 重心转移与恢复 | 她前倾，再落回双脚 |
| 节奏 | 停顿、加速、减速、重复、静默 | 每一次扫视都更慢 |
| 重叠与滞后 | 通道起止错开 | 呼吸先停，头随后才转；肩更晚才松 |
| 完成状态 | 标完成、取消、悬置、替代、打断 | 挥手变成整理围巾 |
| 同步 | 身体、脸、声音、对手节奏对齐或错位 | 她说"没事"，笑却迟了两秒才到 |
| 重复与变奏 | 以改变的时机或强度重复母题 | 第二次整理袖口更快、更不受控 |
| 动静比 | 把静止当作戏剧资源 | 高潮处去掉手势，只留呼吸与目光 |
| 不完美 | 小的修正、过头、犹豫、恢复 | 手机滑了一下，她接住 |
| 动作经济 | 删掉不服务策略的多余动作 | 不要让眼、眉、嘴、手、肩同时动 |

单个面部动作的时间写法见 [facial-timing](facial-timing.md)：Onset / Apex / Offset，且不同动作可错峰。

## 7. 连续性与角色特异性

| 维度 | 保留或变化 |
| --- | --- |
| 状态余势 | 呼吸相位、目光、重心、肌张力、湿润、未完成手势 |
| 能量与疲劳 | 累积消耗、枯竭、恢复速度、用力后动作减少 |
| 道具连续 | 握持、手别、物体位置、丢下或放下状态 |
| 衣物与环境惯性 | 飘动的发、衣摆、围巾、雪、风的反应 |
| 跨镜连续 | 视线、朝向、运动方向、动作进度、强度、呼吸相位 |
| 场景弧 | 从入场状态到有依据的切出状态 |
| 行为指纹 | 与角色绑定的克制性重复习惯 |
| 变奏 | 改变时机、强度、手别或情境，避免习惯变成机械抽搐 |
| 社会可见性 | 决定对手看见什么、只有观众看见什么 |
| 多角色连续 | 保留相互距离、时机、触碰与反应依赖 |

## 8. 选择规则

先宽分析，再窄选择。每个节拍：

1. 选一个主动作。
2. 选一到两个辅助通道。
3. 选一个让转变可读的时机或运动动态。
4. 连续性需要时保留一条入场或切出余势。
5. 生理细节仅在其服务动作且镜头可行时加入。

优先级：因果先于装饰；注意与决策先于表情；身体因果先于同时动作清单；转变先于静态标签；角色特异先于泛泛"电影感"；少而强先于多而弱。

不改变可见表演的维度一律省略。除非用户要求拆解，不展示维度审查过程。

## 9. 紧凑示例

情境：一位女子在车站等久别的伴侣，最后一名乘客离开，身后一个声音叫她的名字。

- 入场余势：握手机的手已垂下；重心已开始向离开方向移；下颌仍紧。
- 驱动：她想确认，却阻止自己显得急切。
- 认知链：察觉不确定的声音 → 停住 → 倾听 → 辨认声音 → 决定核实 → 转身。
- 主动作：核实呼唤者。
- 辅助通道：吸气中断；眼先于头动。
- 动态：向前的惯性先在脚上停住，躯干与大衣随后落定；转身在接近侧脸时减速。
- 切出余势：目光锁定他，下颌与握手机的手仍紧一拍，肩随后才松。

可直接用的写法：

> 她正要离开，身后一个声音叫她的名字。她的脚先停住，衣摆却仍向前。吸气到一半停住。她不转身地听，随后把目光移向声音来处；头跟上，躯干最后转。转身在接近侧脸时放慢，她辨认出呼唤者。对视之后，下颌与握手机的手仍紧了一拍，肩才松开。整段保持连续、克制。

此例只演示写法，不代表默认镜数、镜长或时长；接入分镜时仍按 [timing](timing.md) 与 [story](story.md) 计时、分段。
