# 已确认视觉方向的展开

仅创建或变更视觉方向，以及完整稿需要具体化风格时读取。前置一级选项固定分别为“写实（真人电影质感）”“CG（三维动画）”“二维动画”“三渲二”；用户先选择方向，再按该方向展开材质、照明及运动表现。下面对CG渲染表现的细分只供用户选定CG之后参考，不回填为混合一级选项。已确认的CG人物或场景参考保持动画媒介，不因材质真实而切换真人方向。题材、职业和“电影感”不自动改变所选方向。

风格确认后必须展开成一组可执行特征，不能只重复选项名称。固定写五项：成像或绘制方式、光的形成与衰减、材质或笔触、景深与轮廓、运动反馈。每项用当前故事真正可见的对象写具体，不把整张风格表复制进每镜。用户另给参考时，以用户参考覆盖同项通用描述。

- 真人实拍：写实拍摄影成像、场景中的实际光源及衰减、皮肤和织物的真实纹理、符合镜头与距离的景深、重力下的接触和惯性。汗液、污渍和湿润只在环境和动作已经产生时出现。
- 三维CG·写实渲染：写三维建模，再写写实渲染、可追踪的全局照明和反射、有重量的皮肤与织物、实体接触后的形变和回弹。它是CG，不是实拍摄影，不写镜头型号、胶片或真实摄影机证明。
- 三维CG·风格化渲染：同样是三维建模，保留体积、透视和光照，但造型、材质和运动按已确认的夸张程度处理。不因为“三维”自动加入写实皮肤或摄影景深。
- 二维动画：写明确的线、色块、阴影形状和逐帧运动。身体可以有动画夸张，但不补三维体积、真实镜头景深或写实皮肤毛孔。
- 三渲二：写三维空间和体积，再写二维线稿与色块渲染。它既不改成纯手绘二维，也不改成写实渲染。
- 水墨、定格及其他方向：只沿用用户确认的材料、边缘、帧率或运动特征，不另换介质。

赛博、暗黑、温情等只改变已选介质中的色彩、光源和材质，不改变人物身份、空间事实或事件。时间总览预览不输出风格附录，但内部规划仍使用这五项，避免正式稿才临时改画风。

当前用户参考优先于本页通用句。工具名、渲染器名和画质口号都不是已执行制作流程的证据。
