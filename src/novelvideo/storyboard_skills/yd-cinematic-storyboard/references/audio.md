# 角色声音、对白与声场

<a id="au00"></a>
## AU00 读取范围

新建、细化或修订中有声音事件/对白、或明确静音约束时，读AU01、AU03及AU04参与内部规划；只交时间总览预览也不免除原话/声源/时序判断。完整稿有角色语言发声或声线修订时，再读AU02对应分支；非人发声、叫声、机械表达声或无嘴角色说话另读AU05。只做声线/台词/发声时点修订读取对应小节和受影响接续。四列预览按完整原话估时，对应行逐字写全实际承担的对白及必要声源；不另输出声线档案或长对白附录，不以概括代替原词。纯提取不补音色、发声或译文。参考素材的状态/绑定归[assets](assets.md)，表演可见行为归[acting](acting.md)。

<a id="au01"></a>
## AU01 声源、适用栏目与授权

输入有对白、旁白、内心独白、指定非语言角色发声（含动物叫声、机械表达声），或明确角色发声静音约束时用【角色声音】。逐实际声源列，不漏画外说者；只有静默人物/环境且无人声约束可省整栏。静默者仍在对应画面承担必要行为，无台词不自动等于全静音或闭唇。

新喘息、叹气、笑声等须原稿或授权，标角色/种类/区间；明确人声静音标范围，物理拟音另判。设备回放区分已录声源、现场声源及播放处理，仅剧情本有同录音重复时沿用该段内容/长度；不禁止原有现场重叠，也不添无依据第三人声。声源名字、身份、语种遵守知情边界，未揭示者用允许识别的称呼。

默认声音是已授权人声、必要拟音和环境，不加背景音乐、配乐、BGM或器乐旋律；默认无硬字幕、水印、文字条。剧情本需可见招牌/书页/屏幕文字另按证据与入口，不误当硬字幕。剧情音乐、非剧情配乐、拟音、环境、人声、静音分别判，不能用“氛围音”绕音乐限制。用户明确覆写时同步模板/音轨，不留互斥默认。

<a id="au02"></a>
## AU02 稳定身份与当句表演

**有指定主音频**：以其稳定声线为准，文字写已确认语言/方言与本段必要发声范围，可补有依据且相容的简短听感；未知年龄、声部、共鸣不凑。未实际听取只记录参考关系并说明未评听，不称对齐/实测。文字与参考冲突按用户主参考消解；主参考不明且影响身份/锁定方案才补缺。用户要求详细文字＋音频可并存，不把设计当测量。

**无参考音频/明确不用**：每个实际发声者做一套可复用的文字音色设计，标“本次文字音色设计”。至少写四项：音高倾向、音色质地、共鸣或气息位置、常态吐字节奏。再加一项只属于该角色的稳定发声特征，例如句尾收住、用力时气声变重、紧张时仍把字咬清。同场发声者至少在音高、质地或吐字节奏中的两项上可区分，不能都写成“偏厚、略粗、清亮、有力”。

设计必须能从年龄段、身体状态、职能、关系或当前长期处境推出；原稿没有依据时，选一个不冲突的具体听感并标明是本次设计，不推断精确年龄、口音来源、职业经历或生理声部。当前这句的喊叫、喘息、吃痛和压低声音写在原句前，不写进稳定音色。用户明确不设计时仅保语言与一致性；只有非语言人声不强填语种。拟用但未提供音频可留明确槽位，明确不用删槽位但保文字设计。

四项加一个角色特征是无既有声线时的起步，不是裁掉已确认详细声音的上限。原有稳定音高、质地、吐字和节奏中影响身份的特征完整保留。

困倦、紧张、吃痛、克制、忍笑、当前气息、音量/重音/速度和停顿都属当句表演，贴原句写，不变成新音色。样本混响/偶发情绪不当永久身份。改声线只同步该角色实际相关输入；生成漂移先查声源与参考职责，统一后期音色/重配只在授权及入口支持时提出，未操作不称已解决。

需要声线句法时看[examples E-AU](examples.md#e-au)，无需加载整组例库。

<a id="au03"></a>
## AU03 原话、译文与触发

采用的原话完整保留，译写/压缩/新增服从路由授权。每句标声源、引号、必要受话者、画内/画外/内心及发声窗口。执行块的发声原句只含目标语言；已授权外语对白的中文阅读释义放在整个执行块外，按镜号/台词号逐句对应，中文不发声、不计时、不匹配嘴型、不作字幕，不要求用户从执行块手动删除。用户要净版则省释义；流程C只提取原文不新增翻译。说明文字可沿用用户语言，不将中文说明误判为中文对白。

长对白跨镜在同输入选一种：起声处全文一次并标续声，或逐镜按原文拆分；合并不缺不重。独立输入分别写实际承担片段，拼音轨在完整版块外交接，不承诺必然连续。换语种/翻译/语码切换后，反应按最终信息到达，不沿用原词序；嘴型只归画内说者，画外声不让听者对口型，自然嘴部动作允许，发声不能持续闭唇。旁白和内心独白不驱动画面人物逐字对口型，人物继续既定动作和自然表演，不冻成只呼吸。声音距离、气息与音量按原稿和实际声源设计，贴耳平稳只是可选表现，不是所有旁白的通用声线。

读法写台词前，采用“声源（必要读法）：“原句””；引号外不再复述台词原词接情绪/表情。需标重音/停顿位置用句首/句尾/第几个短语；一句不同读法可按自然断点拆段，合并仍逐字完整。时间来自对应实音频/计时朗读，或明确标文本估算；异文/异语音色样本不能证明本句时长。视频模型专用风险说明和参数仍以当前入口证据为准，不把历史指南措辞当所有模型能力。

<a id="au04"></a>
## AU04 声场、声画与跨镜

影响定位或理解的声音写清谁/什么、画内/外、方向/空间层次、相对人物或相机位置、起止与动作关系；距离、遮挡、墙体反射、混响只在有场景依据时写。切向声源仍保世界声源位置，除非主体/机位真变，不因切镜重启或移位。

对白、关键动作拟音、持续底声分层：必要台词清楚，拟音/环境不盖关键信息；接触、落物、声源揭示与对应动作同步，不编峰值、分贝或混响毫秒。必要台词或关键拟音受到遮盖时，可用环境声层次退让（Audio Ducking），结束后按实际场景恢复；已经清楚时不每句机械起伏，明确以嘈杂遮词为剧情事实时服从原稿；底声不断掉，也不在每句之间重新从零响起。声桥/提前入声/切后续声写具体跨哪些镜与起止；只有声音越过切点不另加画面时间。同输入放连续轴，独立输入重写必要声场并在完整版块外说明音轨接续，效果待实际音轨验证。

可见表演仍写动态时间轴，声音不替代画面证据；跨输入必要声线和声场重复是自足要求，不作为冗余删除。验收并入质量检查，不另开声音复核轮。

<a id="au05"></a>
## AU05 非人角色发声与口型

【角色声音】也容纳已授权的动物发声、机械角色声音或无嘴角色说话，不因栏目名称限制为人类。会说话的非人角色可按AU02设计稳定音色及语言；自然动物只有叫声时，按已给种类、音高/质地、长短和触发设计本次叫声，不强填语言、口音、吐字或人类胸腔共鸣。已有音频以实际可听证据为准。

画面有发声口部者按该造型实际结构匹配发声；没有嘴的台灯、屏幕或器物说话时，说明声音属于该角色、由已定声源位置发出，保持原有造型，不新增嘴，不强配人唇。屏幕嘴型/指示灯仅在已有设定允许时使用。新叫声、吼叫、伺服鸣叫等具有角色表达作用的声音沿用原稿或授权边界，不因“加强演技”自动添加；动作本来产生的机构/接触拟音仍按AU04。动物口部自然运动不是人类逐字口型；固定注意事项的Lip-sync条只对具有发声口部的画内说者适用。
