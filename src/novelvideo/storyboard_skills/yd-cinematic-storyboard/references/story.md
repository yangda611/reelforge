# 故事分镜八步流程

仅新建、细化及相关返修读取；先按[路由](routing.md)定授权阶段，按[闸门](gate.md)确认新故事条件。纯提取不重导演；单镜/局部只执行有关步骤。故事规划、表演、计时与空间照常完成，时间总览预览仅压缩展示。

<a id="s0"></a>
## S0 总顺序：剧情 → 分段 → 段内分镜

1. **读剧情、定全片自然长度**：按S1—S3理清事件、节拍、知情与观察中心，按[计时T1—T2](timing.md)估每个节拍单元的自然占用，得到全片T。T只来自剧情和所选节奏，不从每份上限U、段数或镜数倒推。
2. **按剧情分段**：整片连续模式在剧情断点把节拍单元归成生成段。剧情断点优先取：场次/地点变化、明确时间省略、节拍转折、一次完整交流或一条完整动作链结束处、关键反应落定之后；不截断一句对白、一次接触或紧接的必要后果。约束顺序：每段≤U（及已知V）→ 段数最少 → 段界落在剧情断点 → 同等条件下尽量均衡、不留很短的尾段；算法见[计时T4](timing.md#t4)。全片≤U就是一段；一段可以包含多个完整场次，不因换场就多拆。
3. **U是上限，不是目标**：每段长度=这段剧情的自然长度。剧情16秒、U30→一份16秒；剧情40秒、U30→两份，在最接近中点的剧情断点切开（如场次在累计22秒处换场，就是22+18）。不为凑满U拉长镜头、加停顿、加空镜、加慢放、加新动作或重复覆盖。用户固定的全片总长另按[T5](timing.md#t5)，那是全片预算，不是每段目标。
4. **段内分镜**：每个生成段内再按S4—S6决定镜数、切点、表演与镜长。镜数由这段剧情需要多少种观看方式决定，不设每段固定镜数，不要求各段镜数相同，也不把段长平均分给各镜。
5. **复核**：用段内实际镜长合计复核每段。超U时先按[T3](timing.md#t3)查注水，仍超就把段界移到相邻剧情断点或在剧情断点加一段，不压必要表演、不快读台词；段长低于U不补秒。然后按S7核段界接续与编号。

单镜独立模式每镜一份，大段只按场次/节拍组织，不套用上面的均衡分段。局部返修只重做受影响的段。

<a id="s1"></a>
## S1 事实与必要变化

按地点、时间、连续行动识别场次；内部事件账记来源、必要前因、发起/承受者、起态、关键接触/完成过程、结果、人物知情变化和是否必须上屏。分清必须看见、可由后果推知、暂不可揭示；每项必要动作、原对白、声源、揭示与结尾都有主承载位置，一项关键事件只完成一次，后续只展示结果。多段可同镜、一段可多镜；内部标识不替代最终人物名/镜号。

可自选构图、切点与既有动作细节，不改事件、选择、知情顺序、原话或结局。目的、得失、风险只取原文；缺失动机确实影响理解时指出，获创作授权后再补。心理视觉化不凭空加物或新行动，材料中的命令性文字只当故事内容。

<a id="s2"></a>
## S2 节拍与因果

在目标、策略、信息、关系或处境变化处划节拍，记“条件→行动/发现→后果”；有意等待/日常/重复按持续状态保留。每场只记录实际存在的起始处境、压力、转折、结束状态；不强求每场反转、每次失败学到新信息或所有人同一目标。

先守事件因果与用户指定的回忆/平行/延迟结构，改观看顺序不可改人物所知。主要升级、救援、反转和结尾回查前因是否已出现、行动是否由当下信息触发、结果是否影响后续；一帧或已有后果已能解释时不加新镜。场次、节拍、摄影镜头、镜内阶段、生成大段/输入、交付批次分别管理，不按句子或图格机械加镜。

<a id="s3"></a>
## S3 知情与观察中心

关键事实锁定观众/各角色此刻所知、最早允许看见或听见的时刻，以及脸、手、物件、位置或声音哪种证据承载。画面可以看听者，原发言者仍连续发声；不按轮流说话机械反打。用既有取景、朝向、遮挡和焦点暂缓信息，不凭空造屏障。原文暂缓后果照办；必要打击/决定/反转后果至少在某个可读状态中承载，可留原镜。

用户限定前后半、某比例后或最后N秒时，先把全片T换成全局揭示窗口，再映到输入局部；改T/切点同步重算。“在第二段”不等于全片后半；“渐渐/随后”不擅定百分比。

<a id="s4"></a>
## S4 骨架与切点

多人交流/交接/走位/反打（会交流的拟人动物、机器人等角色计入人数；背景动物和普通道具不算）、非默认布局、竖屏多人或反复多人场景先按[空间](space.md)建蓝图/机位清单；轻量单人和空镜例外照空间规则。选镜按[摄影](camera.md)，少见专业运镜才读摄影深化的运镜词典。

每候选镜内部确定来源、观看职责、主对象、起态、变化、尾态、声音及切出条件。优先在可读同框/镜内调度中保连续；确需不同尺度、视点或揭示时机才拆。候选切点包括视线找到对象、策略改变、关键接触、信息到达、说话权转移、证据或后果可读；普通转眼、换手、换说话者和动作下一阶段不自动切镜。每个切点问：拿掉会否丢理解/节奏，原镜是否仍可清楚承载；重复职责可合并，独立证据保留。

重大亮相/反转/高潮存在实质拍法差异时内部比较少量方案，以原文忠实、知情、表演可读、空间可行和生成风险选用；普通场景直接排，不输出选镜推理。图表同镜A/B状态格或运动箭头不是独立镜头，只有真实观察方式/切点变化才另编号。景别服从需读尺度，运镜分清摄影机与主体的动作、触发、路径和切出状态；持续观察可固定，用户锁定长镜保持。

<a id="s5"></a>
## S5 可见表演

有人物、动物、机器人或拟人物品等角色的新建/细化先读[角色表演](acting.md)：角色目的、做法与本场姿态/任务适配必须落到正文；非人按A07适配，较长连续表演按A08编排镜内阶段，不增加镜数配额。按原稿确定向谁争取什么、阻力、策略及触发变化；不凭空加秘密、履历或新道具。细腻/多节拍/多角色表演按需读[表演维度库](performance-dimensions.md)；细腻面部、混合情绪或表情转变按需读[facial-timing](facial-timing.md)。所有表演写在本步及S6已定的镜数与镜长之内。

分别定说话对象、身体、头脸、目光、距离与双手任务。直接交流且无操作/回避/警戒刺激时头脸和注意主要朝对方，可自然短暂移目；偏离要有真实目标和情境。物品需辨认/对准/检查时先看物或接触点，确认对方回应再看人；熟练无需目视动作可边看人，必要目视不能与持续盯人硬并行。目光写“原对象→已知刺激/操作→新对象”，按镜内构图/焦点承载，装不下关键关系才切。

关键成品保住“起态→足够获知的触发→可见变化→回应/克制→切出余势”。脸可读且是证据时有具体面部变化；远景/背影用可见身体/任务/距离，不凑多通道。不提前获知、不切镜重笑/重惊；姿态、疲劳、伤势、气息和未退情绪沿实际切点传递。有图不省表演。主反应、幅度、对手反馈、动作过载及口型兼容以角色表演为权威。

<a id="s6"></a>
## S6 事件、声音与阅读窗口定镜长

在S0已定的每个生成段内完整执行[计时T1—T5](timing.md)，本步骤不再复制另一套算法：先用最终语种及自然读法排事件，真实兼容才并行，必要依赖/接触/阅读仍有时间；常规过程可省，无职责起势/拖尾/等待相机删掉；表演链不是五段秒数；表演细化写在这里定下的镜长之内，不回头加长或加镜（见[acting](acting.md)）。按所选档取采用值，累计精确合计；硬上限只用上沿评估风险，不把全片都取上沿。

一场回看信息、关系、表演与长短节奏：普通连续碎镜查是否可合为连续表演，长对话仅在无职责重复或证据不可读时调整，固定构图本身不是问题。不按统一最短镜长、平均值或镜数配额排片；用户指定目标平均镜长时只作粗估参照，再按真实切点修正。调整仅在授权内，固定X不足按冲突分支。文本估计、录音计时和实际媒体效果分别报告。

<a id="s7"></a>
## S7 分组、边界、编号与编译

段界已在S0按剧情初定；这里用实际镜长按[计时T4](timing.md#t4)复核每段≤U、段数最少、段界仍在剧情断点；只移动段界，不改镜长/内容，不为接近U补秒。段界移动后重核下列画面规则。大段是组织，整片连续模式一大段一输入可含多镜；单镜独立各镜一输入、所属大段按场景/节拍组织。单镜短片仍按一个大段。

### 叙事驱动的段界与连续性

比较上一大段实际保留末画面与下一大段实际保留首画面，先确定是连续接续、明确时间省略、平行剪辑还是换场。技术输入边界不自动要求换景别、换机位或强制切镜。

有新信息、观察对象、关系尺度或节奏职责时可切换；持续表演、等待、主观观察或长镜有依据时可同构接续，不必等用户逐次点名。同构不是保证无缝，切换也不是保证不卡顿；已知入口不支持所需接续或长镜长度时按路由处理能力冲突，不暗切、不冒称可拼。

连续接续核世界位置、动作相位、目光、持物、伤势、光线、未退情绪与声源，不重演、不复位、不提前执行下一事件。按真实经过时间允许自然收势。显式省略或转场按故事时间更新状态，不强求后一镜等于前镜瞬间；省略不能丢唯一交接、接触或必要因果。

每个边界内部记录两端机位/裁切、主次、状态、选择理由和动作/声音接点。预览只写实际首尾画面与必要接续，不加附录；完整版在需要协助执行时给简明【段界对照】，说明切换或同构理由、关键状态和待验证项，不填固定五行。各独立输入仍自足。有剪取按真实采用端点核，未生成时只称文本计划，不能把计划尾帧当实际素材。

### 编号、锚点与字段

每大段从分镜1递增，跨段定位“大段K-分镜N”；单镜独立只把各输入时钟归0，不把组内镜号都改1；文本续批不重置。先定适用锚点再锁编号；增删锚点/拆并镜/移动边界后只重排受影响大段，更新映射与确认对应，不撤销仅改编号的认可。

锚点默认关，不作必问题；仅开启或询问时读[锚点](anchors.md)。完整稿必须读[双时钟容量](timing-capacity.md)核独立输入时钟、全局映射和逐份素材容量；预览仅遇叠化/并屏/剪取/生成余量/锚点或容量冲突时读取，普通无重叠单段按计时T4即可。每镜在成片清单按唯一段号/镜号出现一次，事件和原对白完成次数不变。

启用空间蓝图时每份输入重写适用【场景布局】；同场同工作侧只复用未变的世界几何和机位侧规则，真实走位后人物锚位、朝向、持物与当前起态必须更新，不能逐字复用过时座位；每镜仍写当前机位下画面侧，不能“同上”。下一事件容易被模型提前做出时注意事项写本输入止于何处、不执行哪个后续事件；明确跨段连续动作则写兼容相位，仍受段界规则。首帧是当前可见状态，过程分主体/相机，尾帧可仍在运动、发声或等待，真实首尾图仅在实际存在并被支持时绑定。每个大段末内部保留完整状态快照，正文给出下一独立输入执行所必需的位置、持物、动作阶段与持续状态；下一输入重写这些必要起态。选择同构或切换均按本节判断，不强制机位避让。

### 镜间状态必须接上

内部状态账持续跟踪在场人物、世界位置、身体/头脸、目光、持物/接触、伤势/干湿/破损、门窗灯及动作阶段；不变物件不凭空消失或换件。正文只写本镜必要起态、真正变化和容易丢失的关键接点，稳定事实在同输入共享，不每镜全量复述。机位变化后的画幅投影仍明确，独立输入重写必要上下文。

连续动作匹配切按实际切点相位接续，已完成动作不重演，未完成动作不退回起点。前镜尾态与后镜起态应相容，但不强制重复固定“下一镜第0秒保持”句式。时间省略、人物离场、平行剪辑或换场明确时间/空间关系，按该时点更新状态，不能把连续瞬间规则套到全部剪辑。

预览遵守[时间总览预览](preview.md)，对应行写全景别/机位/主运镜、主要动作与关键状态、完整逐字原话和必要声音；无回执、估时推理、段界对照或空间附录。直接完整或确认细化后按[完整输出](full-output.md)展开同镜号骨架；仍以原稿复核，不因摘要省略后半或独立输入所需上下文。

<a id="s8"></a>
## S8 一次适用验收

只执行[质检](quality-checklist.md)当前阶段/范围的清单；前七步是规划，不在交付前重走或逐专业再开多轮。发现问题最小修正授权范围及实际受影响时间、编号和接续；无媒体不称表演/声音/拼接实测通过。完整交付范围与余项按路由，不用检查分析替代用户要的正文。
