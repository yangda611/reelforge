# 素材与稿件就绪

<a id="as00"></a>
## AS00 读取范围

准备完整输入时读AS01判断稿件状态；明确无参考且无待绑定项后，可不读AS02—AS03。实际引用/新增/替换参考、确认绑定或状态冲突时读AS02—AS03。没有实际参考职责或素材问题的普通时间总览预览可不读本文件；已有参考影响身份、状态或构图时，仍按当前职责加载AS02—AS03参与内部排镜，素材状态问题读AS01，但预览不列素材清单或附录。用户此轮专问素材状态则只答其范围。声音设计在[audio](audio.md)。

<a id="as01"></a>
## AS01 三项证据与三种稿件

文件提供、对应关系和入口绑定分别记录：真正收到可称已提供，收到不等于可识别；用户确认编号只证明映射，文本标签不证明入口绑定。状态可为待准备/已提供/无法读取、未确认/映射已确认、未绑定/入口已绑定/未核实。不可用“已绑定”混称；未核实照说，不重复催上传，不称读过未读图/音频。入口标签与预设不同，迁移所有相关引用，不混两套。

- **制作准备稿**：确需参考可有必要待绑定槽位，块外列缺项及职责；不称直接复制即可生成。音色文字可独立设计。
- **默认准备稿槽位**：用户没有提供参考、也没有明确说“纯文字/不用参考”时，完整稿默认按制作准备稿输出【参考职责】，不整块省略，也不写“不虚设素材编号”。按首次出场顺序给以下对象各设一个`@图片N`槽位：有画面的命名或主要角色（每人一张形象参考）；承载主要动作的场景（一张，启用空间蓝图时可兼布局职责）；跨镜重复出现、外形或状态影响连续性的关键道具、特殊生物或怪物。每条写对象、负责维度（身份外观／结构材质光色／形状比例与当前状态）、适用状态与生效范围（如伤前/伤后、首次揭示前不可见）和实际隔离边界。一次性路人与普通群体可不设，或合并为一个群体外观槽位；只有用户计划用音色参考时才设`@音频N`，否则声线用文字设计。块外素材状态写“待准备｜映射待确认｜入口未绑定”，块内不写“待上传”这类状态词。正文首次出现该对象时写“名称（@图片N）”，之后用固定称呼。用户之后改说纯文字或不用参考，转为无参考稿并删除全部槽位。
- **可投喂稿**：引用均已提供、映射明确、入口绑定有依据、执行无占位；参数已核实或由用户明确指定。若仍有未核实必要参数/绑定仍是准备稿；就绪只证输入准备，不证结果。
- **无参考稿**：只有用户明确不用参考或授权纯文字时才采用，删除全部无用标签，以已给名/身份/状态自足；条件齐可注明可投喂。不补外貌/年龄/道具/剧情，不再问上传。

稿件状态与预览/完整、整片/单镜模式独立。缺图不阻塞获授权文字工作。准备转执行按新证据更新、移除废槽、同步正文引用/声线/首尾态；主参考与锁定故事/设计冲突具体说明。完整稿必要清单首个代码块前一次，后续只报变化，不输出空清单。

<a id="as02"></a>
## AS02 编号与参考维度

全任务编号稳定，先沿用户映射，新增用空号，每输入只列必要对象及职责；不为无关键道具、路人、画外声凑图片。新编号上传顺序仅在不与已确认映射冲突时按角色首次出场。示例人物/道具不迁入故事；格式示例见[examples E-AS](examples.md#e-as)。

**每份参考写清实际继承维度与适用的隔离边界**，按已读素材和已确认职责决定，不套一组统一否定词。未知素材内容只记录待核风险，不假称含三视图/静音等特征；无特定污染风险可写“仅作上述用途”，不编风险。用户指定首帧、构图、动作或声音参考时，不能用总隔离声明否定已授权职责：

- 角色图：绑定已确认身份、外观与服装；仅当确有设定板背景、文字或无关站姿时隔离相应内容。有图正文不堆静态外貌，仍写动态姿态、必要身份标签、干湿/破损与当前表演；角色图的静态中性表情不冻结剧情中的表演。自然动物、机器人或拟人物品的角色图同时确认实际可动部件和拟人程度，不把人类脸部结构加进原设计。
- 场景/道具图：绑定结构、材质、光色或当前道具状态；是否继承构图、持握按本次职责，不自动排除。
- 风格图：只在授权维度继承光色、材质和表现，不能自动改身份/空间。
- 真实首帧：在入口支持且指定绑定时继承实际起始构图、姿态和可见状态。
- 布局/机位侧图：用户自备时只继承世界几何与机位侧，不继承当前裁切；作首帧须用户指定且入口支持。
- 上段视频/截图：取实际可证的身份、环境与保留尾态；摄影是否同构由story S7决定，不普遍禁止继承末镜机位。声音按实际素材和本段需要继承或隔离，截图不能证明音轨，不能假定上段必有静音。截图只证可见事实，非保留末帧不能冒称尾态。
- 白模/参考视频：按授权取路径、构图、运镜或切点，隔离实际不需要的简模外观/生硬表演。
- 音频：默认只参考指定角色稳定声线，不迁异文台词、无关噪声或未授权人声；指定声音/节奏参考另按授权。

一参考可负责多维；稳定身份、当前状态、世界结构、当前构图、光色、动作路径、声音分别判断，同维有相反证据只选有依据主参考或移除/修正，不能靠堆提示同时满足。固定称呼、身份锚点和职责不为避重复逐镜换同义词；变更同步，只复写自足必需内容。

<a id="as03"></a>
## AS03 状态变化

服装、伤势、血污、姿态、开合/破损可变而身份不变。本输入只挂当前态，伤前不能用伤后、开前不能用开后；状态变化写清从哪一镜、哪个事件起生效，之前的镜头不提前出现新状态。缺对应状态图仍可交准备稿，用文字写清当前态。母版派生图规划与资产漂移排查不在本版范围（本版只做文本分镜，用文字写清当前态即可）。
