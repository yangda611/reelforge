# 空间、机位与连续投影

<a id="s00"></a>
## S00 读取范围

S01是所有新建/细化镜头的判定入口。满足完整蓝图条件读S02—S06；单人轻量只读S03的机位/目光及S04适用动作，不读多人布局；空镜/物件插入/POV按S01例外。仅换文字呈现或流程C不补空间。示例只在对应问题难以表述时读[examples E-S](examples.md#e-s)。

内部定真实世界关系，再随机位推导本镜画面左右/纵深，不能换视点后照搬旧左右。关系必须成为可见几何；稳定布局与当前投影分开，反常布局正面说清。时间总览预览不输出空间图、机位清单或附录；这里只为内部排镜与完整版提供依据。

<a id="s01"></a>
## S01 启用与豁免

任一情形启用完整蓝图（会交流的拟人动物、机器人等角色计入“人”；背景动物、睡着的宠物和普通道具不算）：两人以上同场且有对话/交接/走位/正反打；布局不同于常见画法；竖屏多人；两人以上同场分多份输入或系列反复回同场景。

单人即使分输入或走位，只在景别与摄影机写地标机位/背景，在动态时间轴写运动/视线画面方向；看画外人注明朝画面哪侧。不强写场景布局、身份标签或空间示意。空镜、物件插入、POV、天空水面等无可挂地标时，只写观察方向及必要参照，不编地标凑格式。流程C只保原稿已知空间，未知不补导演。

<a id="s02"></a>
## S02 内部世界蓝图

按需记录以下信息，不原样变成长分析交付：

1. 主视方向，如入口→电视墙；作为稳定布局的观察基准，不代替每一机位的实际投影。
2. 固定地标优先2—4个已知且可分辨的门窗/家具；记相对位置及可见侧。原地标不足可补1—2件仅作背景、无人接触且不参与剧情的固定陈设，完整版块外列本次设计；用户限制不添物时服从限制。
3. **可见背景与条件互斥锚点**：按既定地标位置、机位朝向、视野与遮挡推导当前背景。只有真实几何证明X与Y在该机位不可能同见时才写互斥，不能由对峙/反打题材直接推出“拍A只见X、拍B只见Y”。合法斜侧或宽视野可以同见两个地标；裁外写画外，不删掉实际应可见的地标来凑锁。此方法保留为防空间漂移的条件工具，不能替代关系轴与投影检查。
4. 人物锚位：在哪个地标的哪侧、坐/站、朝哪、接触距离；同锚位不叠人，并排同家具分各端，不新增人物。未指定时可比较对立者隔物相对、对话最多两人间不隔第三人、重要人物不要都背对、需用门在相应人可见方向；不是强改原站位。
5. 名字与可辨身份标签：取用户/参考的一个特征，同服装状态段稳定；换装或状态改变同步，不强锁衣色全片不变。无特征用名＋锚位/持物，不编服装；这是定位而非重复外貌设计。已有角色参考图时，静态外貌由参考图承担，正文不复写，只写动态姿态、泥水汗湿与新增破损。
6. 当前主要互动/运动轴和有效机位侧。三人以上按本拍主要行动对更新关系轴，用同框、地标或可见走位定向，不硬锁所有人全片画面位置。
7. 主光固定到场内来源/地标，再推各机位画面受光侧，不用反打后屏幕侧变化判断换光。
8. 内部机位清单：可编内部代号A、B、C……；记相对地标的位置、朝向、背景、主光投影、谁在左右前后、各自视线；先复用，真实信息需要才添机位。代号只用于内部核对和块外空间示意，执行代码块内每镜展开为地标描述，不写“A位”“机位B”。
9. 与常见画法不同的1—3处及必要越轴计划；没有差异不凑项。
10. 多人追逐/打斗/救援/交接/狭道时记录路径：起点、目标、方向、障碍/地标、触点、停点/出画；主体移动与相机移动分开，轴线/投影变化及时更新。静态对话、简单单人无需路径图。

站位检查“在哪、相对谁、身体/头脸朝哪、看哪”，普通两人可用一两句满足；身体方位必须具名并有朝向。转身只改以身体定义的左右前后，不代表另一个人位移；稳定世界位置用地标保存。

<a id="s03"></a>
## S03 写入完整版

启用时每份输入的【全局光影画风】后有【场景布局】，通常4—7句：空间与主视方向、地标及确有几何依据的背景约束、人物锚位/标签/关系、允许机位侧、当前成立的画面投影、必要反常说明/人数锁、连续性。未揭示者不提前写入，或明确本输入不出现；单镜独立只有一人入画时注明本输入只见该人。

**复用只限未变事实**：同场景的世界几何、未变布局与同侧机位规则用固定措辞；人物发生走位、状态改变或关系轴更新后，每份输入按其实际起态更新锚位/朝向/投影，不为逐字一致把人写回旧位置。越轴或换主视方向同步相应侧与投影句。布局图规定的几何在文字中同样存在，不上传图也完整。跨输入仍须把当前必要状态写全。

每镜【景别与摄影机】用“在何地标/区域哪侧、朝哪拍、背景是什么”，角度仅补充。起幅有谁/各在哪，有运动写路径/跟谁，落幅或切出状态明确；固定时不平移、不转向。同机位复用机位措辞，可只改变景别；不误锁人物动态状态。

每镜【空间与主体】按本机位重写画幅侧/纵深、面对/背对/侧对、人物之间隔什么。单人镜写位置、脸朝向、画外对象方向；视线另句，别把目光方向混成人物位置。“对面/身后/旁边”配地标或当前画面方向。某人近机位时，明确肩入不入画，避免自动过肩。

有意在画外的地标明确画外；近景容不下窗时写“左侧画外窗，只见左来光”，不硬要求画内窗。人物看摄影机身后目标时，身体/头分写，目光落镜旁而非直视镜头；只有原动作允许头转则身体保持，不同时要求矛盾正面/侧脸。具体句法在[examples E-S](examples.md#e-s)。

<a id="s04"></a>
## S04 动作、目光、手别与方位

目光写对象及当前画面方向，转移写从何对象/侧到何对象/侧。倒下/转身/伸手/走动也给方向。有实质走位写目标、画幅路径、切出地点及状态；到达才写停点，仍走则保方向、位置和步态阶段，简单动作可直述但不丢关键关系。真实路径与当前投影决定进出画；同向横向且相容机位时常右出左入，纵深/转弯/换机位/省略剪辑不机械套用。

切出状态携带姿态、位置、朝向、目光、持物手/持有人、悬空/接触、伤势、破损和干湿。所有权与持有人分开。一个输入内确认不变的必要事实可共享，之后只写变化；跨输入必要事实重写，不用“同上/继续上一镜/保持原样/回原位”。同输入已有明确起态后可用“仍/继续”。

躺卧写头靠何端、身体腿向哪、着垫侧、脸朝哪；特写补头顶方向，不能只写头枕扶手。看正后方须肩随头转等符合身体的动作；要求躯干不动，就将目标处于已知的身后偏侧，原文约120°仅作避开扭颈的写法参照，不把未知人体转角当实测，也不擅移锁定道具；冲突时修拍法/报告约束。

关键物原文未指定手时，选靠镜头侧以保触点。选定后全场不换手；之后某个机位让这只手转到远离镜头一侧，就接受部分遮挡或调整机位，不悄悄换手。原文指定手以原文为准；明确换手须有动作和连续状态。

裸“左/右”指当前画面，身体左右具名；世界布局里的左右以已声明主视方向为基准。地标方位需明确观察基准，东南西北可用于内部世界图，执行稿优先画面/地标参照。“靠近/远离镜头”仅描述本镜投影，不定义持久布局或机位；用沙发靠电视一端，不用沙发靠镜头一端。

<a id="s05"></a>
## S05 反打、竖屏与越轴

同组关系轴与相容机位下，反打两人视线相反；位置可变但目光不无故反向。高度按真实站坐匹配，站者向下、坐者向上。过肩写谁身体哪侧肩、前景大致范围/清晰度、看谁；不入画明确连肩也不入画，允许入画明确画面边缘，非一概虚化。

竖屏未指定站位可优先纵深，实际并肩按原文；前后景随机位重新推导。三人以上固定名字/标签和锚位，说明画内/画外与成组对象，外形近似群演用稳定编号。多人背影/远景需标签，单人轻量豁免仍有效，无身份特征可用名＋锚位，不编衣服。

默认留轴线同侧。并排同向者背后→正面会左右对调且越轴，不强镜像锁旧左右；面对面对话、世界位置与关系轴未变且同工作侧时保持相容投影，走位/新轴/越轴则按实际更新。越轴选：可见跨轴运镜、人物穿轴、中性轴线上镜/不含方向性视线的插入或空镜、宽景重新建立。正对双人同框不自动算中性镜；单纯另开生成输入不替代观众的重新定向，仍需可读关系/地标。

越轴镜说明换到哪侧及对调后左右，后镜按新侧写。用户锁定不加过渡的直切可保留，但该镜须声明对调、至少一项两侧可见地标帮助定向、完整版块外提示短暂迷向风险。地标/光源投影应与机位清单一致；正常反打光侧或背景换侧本身不等于越轴。

<a id="s06"></a>
## S06 建立镜、反常几何与审阅示意

整片连续模式同场第一份输入、越轴/重建后的首份输入，第一个多人镜原则上较宽且能辨主要人物及至少两个地标，不远到人脸/身份丢失。例外：单镜独立；空间已建立且接续清楚的后续段首镜；有依据的同构/同首帧接续；延迟揭示的局部开场；用户锁定开场。例外靠本输入布局与适用参考定向，锁定开场补足必要地标/左右；空镜或插入开场后第一个多人镜承担建立。建立不另设固定秒数。

异于常见几何的布局用正面可见关系说明，可再加一句短否定；只说“不并排”不够。客厅沙发朝向、隔桌而坐、右舵、躺卧方向、门不居中、围坐空位/人数等实例迁到[examples E-S](examples.md#e-s)，只有命中问题才读，不把全部反常例表塞进每个任务。

完整版启用完整蓝图时，仍在第一个输入块前给一次空间示意：不超过8行俯视文字草图＋逐机位清单，标“审阅用，不投喂”；输出模板只决定呈现格式，不能因预览变简而取消完整版空间能力。用户最新时间总览预览不输出该示意、图片建议或折叠附录，内部蓝图仍必须做。改布局同步蓝图、场景布局、机位、视线、尾态；对用户用“摄影机所在一侧”等直白词，不铺内部术语。

空间验收交统一质量检查一轮：盲读完整版能画出布局/机位/投影，不用另开空间检查轮。空间参考图与构图图不在本版范围（本版只做文本分镜）；用文字【场景布局】与逐镜机位保证空间自足。
