# 写实电影场景生成

把一句场景需求转化为可直接生图的中英文提示词。让场景的真实感来自空间、光源、材质和使用逻辑；以用户主题为中心，延续参考的纪实观察方式。

## 激活后立即执行

1. 提取用户已给出的地点、年代、时间、天气、人物、事件、画幅、用途与模型。锁定明确条件。
2. 只在场景主题本身缺失、参考彼此矛盾或必须区分两个不同地点时，提出一个关键问题；其他缺项自行选择，最多用一句话说明默认值，不阻塞输出。
3. 按下方工作流完成一幅场景；用户指定数量时才扩展。默认输出提示词，不自动调用生图、视频或付费服务。用户要求直接出图时，再使用当前环境的图像生成能力；不可用时交付提示词并说明。
4. 除非用户要求，不叙述蒸馏过程、评分过程和思考链。单独的“只给中文”“只给提示词”等输出要求覆盖默认格式。

## 风格锚点与优先级

优先级：用户明确约束 > 当前参考的可见事实 > 本Skill的风格建议 > 可选题材预设。

固定锚点：实拍感、可解释光源、连贯空间、有限而有效的细节、克制调色、自然生活状态。

可变项：地区、时代、阴晴雨雪、昼夜、冷暖、整洁程度、有人无人、室内外、干湿、景别。六张原始参考偏向中国当代乡土与工业日常，但不把这个样本偏好强制推广到所有题材。

缺省：16:9、单幅、平视或合理观察位置、中远景或远景、无画外文字和界面；用户没有要求人物时默认空镜。天气和时间依据场景选择；只有无任何线索的普通日景才选薄云散射日光，不自动添加降雨、湿地面或雾。

## 六个生成模型

每个模型均为本次对样本的归纳，名称不代表原作者命名。完整样本依据见 [风格证据](references/style-evidence.md)。

| 模型 | 在新场景中的操作 | 参考证据 | 失效条件与替代 |
| --- | --- | --- | --- |
| 使用行为塑造空间 | 先确定空间用途，再选3—6个有摆放原因的物件；用一项具体痕迹表现日常 | 缝纫间的工作台与收纳柜；车内的小风扇和驾驶器件 | 新房、医院、洁净空间可以干净；改用功能布局表现真实 |
| 摄影机有站立位置 | 先定相机在哪、朝哪拍，再选一个主构图手段；让遮挡与透视服从位置 | 列车内透过窗框看外部；拆迁入口向铁轨深处；船上望向船尾 | 狭窄空间不能塞入不可能的超远机位；改用局部环境景别 |
| 光线有来源和路径 | 明确主光来自天空、窗、门或可见灯具，写出遮挡、反射与明暗过渡 | 老屋门窗侧光和暗部；河面天空光；车体与林地的柔光 | 晴天或夜景不套阴天低反差；分别允许硬阴影或局部高反差 |
| 材质记录局部因果 | 选2—3种关键材质，说明使用、接触、重力和天气如何影响表面 | 铁门接缝附近锈蚀；船板积水；桌面接触磨损 | 不把所有表面做旧；干燥、新建或维护良好的表面保留本色 |
| 层次靠距离与遮挡 | 建立前、中、后景，明确一条通行或视线关系；远景仅适度减弱对比 | 层叠山村；工地轨道；窗外站房与远山 | 无远景的房间不凭空加山雾；用门洞、家具尺度和光照区分层次 |
| 色彩来自场景本身 | 取2—3种现场主色，最多1种局部强调色；保留真实肤色与材质色 | 木船蓝衣黄裙；工地绿植黄机械；室内木色与红纸 | 不固定青橙或青绿滤镜；雪景、沙地、暖灯空间按自身色谱处理 |

## 工作流

### 1. 判断任务

- 新场景：建立完整场景设计。
- 参考迁移：区分“参考里有什么”和“新场景需要什么”，迁移固定锚点。
- 修改现有提示词：保留已经锁定的主体、动作、地理与机位，只修改用户指定方面。
- 多视角或连续场景：先做一致性锁，再分别改变机位，不在同一提示词堆叠互斥视角。
- 特定真实地点、年代或建筑复原：优先使用用户资料；关键事实缺失时查可靠一手资料；无法核实时注明合理设定，不能伪称精确复原。一般虚构场景无需联网。

### 2. 填写内部场景卡

先整理以下内容；除非用户要求，不逐项展示。

- 硬约束：必须保留与必须排除的内容。
- 场景用途与状态：地点、时代、日夜、天气、正在发生什么。
- 视觉中心：空间结构或人物行为，选择其一为主，避免人物大特写吞掉环境。
- 空间关系：相机位置与朝向、前景/中景/后景、门窗或道路如何相连。
- 光照因果：一个主光系统，可有合理的弱辅光；光源方位与照到的表面一致。
- 材质证据：2—3种材质及局部状态；3—6件支持场景用途的物件。
- 色彩与尺度：主色、强调色、人物或标准构件提供的尺度参照。

### 3. 选择摄影表达

景别和机位优先于设备型号。单幅默认一个固定观察位置；不要同时写无人机俯拍、室内平视和低机位仰拍。

| 场景 | 机位与层次建议 | 光照建议 |
| --- | --- | --- |
| 居住/工作室内 | 门口或房角的中远景；桌沿、人物工作区、后墙 | 门窗自然光，或明确的室内灯具；暗部可读 |
| 村镇/街道/工业空镜 | 真实可达的路边位置；路缘、主体建筑、远处环境 | 按阴晴选择散射光或直射日光；不强加湿地 |
| 车窗/船上等载具视角 | 先写摄影机在载具内还是外；只选一个框景或引导线 | 外部天空/日光与内部遮阴的亮度差；反射适度 |
| 现代整洁空间/夜景 | 用功能设施与实际尺度构图；保留干净表面 | 灯具位置决定亮区，窗外夜色只作合理弱光 |

需要焦段时仅给一个建议：环境视角通常24—35mm等效，自然观察通常35—50mm等效，远景压缩可用50—85mm等效。它们是设计建议，不能从截图断言原片焦段。优先正常透视、适中景深与可读环境；不默认超广角拉伸或人像式全背景虚化。

### 4. 按因果顺序写提示词

按“主体/场所与状态 → 前中后景关系 → 机位与构图 → 光源与表面响应 → 色彩与材质 → 成像约束”组织为连贯画面。

用可见细节落实形容词。例如把“破旧但真实”改成“卷帘门下沿漆层磨损，常用扳手集中挂在工作台上方”；把“高级电影感”改成具体机位、光线过渡和层次。

每幅保留一个主要行为或空间事件。人物存在时写位置、视线、动作与环境接触点；自然站姿或工作状态，不自动添加时装模特式摆拍、精致妆造、戏剧冲突或悲情故事。

翻译英文时与中文逐项等义，不扩写新人物、雨雾、灯光或道具。不把双语词条交错堆在同一段。

### 5. 自检并局部修正

逐项检查：

- 是否遵守晴天/夜间/干燥/整洁/无人等全部硬约束？
- 相机位置、视线、尺度、遮挡及人物接触点是否成立？
- 主光从哪里来，室内外曝光和阴影方向是否一致？
- 道具有用途吗？破损、锈迹、潮湿是否有局部原因？
- 是否只保留一个主构图手段，环境仍然可读？
- 是否把青绿、阴雨、破败或颗粒误当固定写实条件？
- 中英文是否描述同一幅画面？

发现问题只修冲突项，最多迭代两轮；不改写成另一处场景。文本检查通过仅代表提示词设计一致，不等于图像已经生成或质量已验证。

## 十条条件规则

1. 如果用户要求空镜，就让空间成为主体，不为“叙事感”擅自放人。（迁移自山村与工地环境镜头。）
2. 如果用户要求晴天，就保留日照方向、硬阴影与适度高反差。（对阴天样本的条件化扩展。）
3. 如果用户要求干净/新建，就使用维护状态、拼缝与功能布局表现真实，不添加污损。（对局部材质模型的条件化扩展。）
4. 如果使用门、窗或船架框景，就锁定相机与框架的相对位置。（列车、铁门、木船。）
5. 如果人物在车窗或船边，就明确身体、手部与载具的接触关系。（老人靠车、女子扶船沿。）
6. 如果场景暗，就保留物体轮廓和关键材质的可读信息，不用“死黑”替代氛围。（缝纫间、列车内。）
7. 如果需要远近层次，就先使用透视、遮挡与尺度，只有天气允许才加薄雾。（山村、工地。）
8. 如果需要强调色，就让它来自现场物件，限制画面占比。（黄机械、黄裙、红纸。）
9. 如果细碎纹理过多，就减少随机颗粒、砂砾感与均匀斑点，保留大中尺度材质变化。（从样本的克制质感推导的修正规则。）
10. 如果用户改主题或场景，就重建地点与物件，保留摄影方法；只在同一场景内沿用连续性锁。（跨场景生成规则。）

## 输出契约

默认按以下四项输出，每幅只给一套方案：

**场景设定**：一句话点出主题和必要默认值。

**中文提示词**：约250—450个汉字，单段，直接可复制；主题简单可更短，不为字数加物件。

**English prompt**：语义对应的单段英文，通常120—220词；不机械凑长度。

**排除项**：针对当前场景列6—10项。若目标模型有负面提示词字段，放入该字段；没有时，把最关键的2—3项融入正向约束，不输出未经核实的模型参数。

用户指定“只要提示词”时，省略场景设定及附加解释；指定单一语言时只输出该语言。画幅参数仅在模型语法已经确认时使用专用格式，否则写自然语言；不臆造seed、步数、CFG或专有开关。

## 连续性与修改

多幅同场景先锁定：年代地点、天气时段、建筑平面关系、主要物件位置、材质状态、主光方向；有人时补人物服装与外貌。改机位只改变可见关系，不能让门窗、道路、山体和人物位置无故换边。另一个地点允许重新设定。

用户说“更写实”：优先修几何、光照、接触与物件逻辑。
用户说“更有电影感”：优先修视点、层次与视觉重点。
用户说“抑制点状纹理”：降低随机微纹理和颗粒，以大面积干净色块、中尺度磨损、自然边缘变化为主。
用户说“不要太脏/太暗/太绿”：直接解除相应默认倾向，保留其他锁定项。

## 反模式与修正

| 常见偏差 | 修正方式 |
| --- | --- |
| 8K、HDR、杰作、极致细节反复叠加 | 换成实际光照、表面与空间描述；避免光晕和过度锐化 |
| 任何题材都加锈、霉、水渍、雾 | 按时代、维护状态和天气逐项决定 |
| 全画面均匀点状噪声 | 降低细节密度，按材质分区，默认不强调胶片颗粒 |
| 大特写、美颜脸、时装姿态 | 回到环境人物中景与自然动作；纯空镜不添加人物 |
| 同时强写对称、三分、对角线和居中 | 选一个主手段，其余由空间自然形成 |
| 一边写柔和阴天一边写强烈直射硬影 | 根据硬约束选择唯一合理光照状态 |
| 复刻截图的字幕、黑边、手机状态栏 | 输出完整单幅场景；只有用户要求版式时才添加版式 |
| 把物理摄影写成3D引擎渲染 | 用表面反射、遮挡与实拍成像描述替换引擎术语 |

## 核心张力与选择

- 生活复杂度与视觉可读性：选择少量有效细节，保留空处，不把真实等同杂乱。
- 电影构图与偶然观察：给镜头一个明确视点，允许日常不对称，不把环境搭成精致展台。
- 暗调氛围与暗部信息：允许明暗差，保留叙事区域的轮廓和材质，不整体提灰或压死。
- 风格延续与题材迁移：保留光学、空间与叙事方法；让地区、冷暖和整洁度服从新主题。

## 边界与参考

- 六张用户截图是风格样本，不是已经核实的原片、导演、地区或拍摄参数；无法辨认的文字不能补作原文。
- 这是提示词生成技能，不能保证特定模型严格遵循空间关系、文字、手部、镜面与连续性；需要时应根据真实生成结果迭代。
- 夜景、晴天和现代洁净空间是从共同方法延伸的设计规则，不是六张样本已覆盖的实测风格。
- 风格提炼日期：2026-10-31。参考图出现年代范围不等于真实拍摄年代。
- 需要核查风格依据时读 [风格证据](references/style-evidence.md)；需要成品写法时读 [迁移示例](references/examples.md)。日常生成无需加载所有附录。
