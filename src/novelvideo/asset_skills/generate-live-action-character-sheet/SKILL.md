# 真人电影角色三视图

生成像真实演员穿实际服装拍摄的角色定妆资产。把角色身份、衣装结构、拍摄方式与版式分别约束，再组合成一个可直接使用的提示词。默认中文沟通；需要英文模型提示词时保持语义一致。

## 首版目标与执行顺序

首版以可信的真人演员定妆摄影为目标：保留自然面部结构、肤色变化、正常皮肤细节与实际衣料行为。局部修复词只用于实际缺陷；不能把一次修脸的柔化要求升级为所有角色的默认肤质。用户认可的参考图优先于技能默认设置。

1. 提取用户明确给出的年龄、五官、服装、装备与参考职责，保留全部关键要求。
2. 先确认参考职责与各栏穿戴、取景状态，再写演员身份、简短的自然皮肤描述、衣装和摄影方式。
3. 提交前检查各段是否有重复或冲突，尤其是皮肤与装备的粗糙度、局部裁切与完整头部、遮脸装备与露脸头像。
4. 一次生成一张，查看实际结果。只报告实际检查到的效果，不承诺首版必然成功。

## 先确定任务与参考职责

- 区分“只写提示词”和“实际生成图片”；用户只索要提示词时不要自动启动生成。
- 为每个参考指定职责：身份参考、服装参考、实拍质感参考、排版参考。只采用用户授权的维度。
- 用户指出“这张首版才对”“就按这张修”时，读取该图并锁定用户认可的人物、服装、质感、构图和穿戴状态；使用工具的图像引用机制传入，不只靠文字重新猜人物。若只要求对比，先对比；若只要求修技能，不自动生图。引用规则、工具与附件可用性以当前工具说明为准。
- 对用户认可图的局部修改，输出“参考职责 + 保留项 + 缺陷位置与修正目标”的短编辑指令。新建角色才使用完整新图提示词；不要把局部修复扩写成重新设计整张图。
- 用户说“只参考排版，不参考人物”时，重新设计年龄、五官、体型、发型、服装、配色、配件，不继承原图的显著人物特征。不要把排版图作为身份或服装参考。
- 默认只设计一个虚构成年角色；用户未给职业和时代时选一个合理方案，简短说明后执行。不要把某个示例的性别、年代或职业固定成技能默认身份。
- 只称实际读取的内容为原始提示词/参数；从画面提炼的规律称为视觉分析，从它归纳的流程称为建议。不要宣称能从图片精确反推出作者配方。
- 研究项目来源与方法差异时读取 [来源与方法分析](references/source-analysis.md)。需要完整成品提示词时读取 [实用示例](references/example-prompt.md)，替换整个角色身份与衣装，而非沿用示例人物。

## 默认版式：遵守画面含义而非“三视图”字面

这里的“三视图”指衣装正面、完整背面、正面头像三联定妆图，不是正面/侧面/背面的工程图。按“本轮明确要求 > 用户认可参考图 > 下表默认值”确定取景。参考图左栏包含完整头部、佩戴面罩或兜帽时，保留对应状态；只有用户明确要求改版式时才改变。

| 区域 | 默认宽度 | 取景与站位 |
| --- | --- | --- |
| 左 | 28% | 正面自然站立；上缘从颈根/锁骨附近裁切至鞋底；头部在取景框外，双手、衣服、双鞋完整可见 |
| 中 | 28% | 同一人严格旋转180度的完整背面，从后脑/发顶至鞋底全部可见；不回头、不露正脸 |
| 右 | 44% | 同一人正面头像与肩部特写，完整头顶与发型，眼平看镜头，衣领可见，脸部为视觉主体 |

- 使用横向16:9画幅；三栏相邻、不重叠。默认共用干净暖白或浅灰无缝背景，无文字、无装饰框、无分隔粗线。
- 左中身体的肩线、腰线、膝线与鞋底尺度尽量对齐，共用落地基线；右侧头像独立放大，不强行等比例。
- 把无头正面描述为“活人照片的局部取景，头部在该栏画面上缘之外”；不要表现断颈、平整切面、假人或血腥伤口。
- 无参考且采用下表默认裁切时，在版式段写“左栏仅从锁骨至鞋底、中栏发顶至鞋底、右栏完整头肩”。左栏要求完整头部时，改写为“从完整发顶至鞋底”。按栏限定“完整”，不通过拉伸人物强行对齐身高。
- 正背面双臂自然垂下，与身体留细小空隙，手为空，脚自然平行。避免摆拍、动态姿势、T-pose及夸张叉腿。

## 建立可复用的身份与衣装锁定段

先写短而具体的角色设定，再在所有视图重用同一段约束：

1. 身份：成年年龄、体型、时代与职业。
2. 脸：脸轮廓、颧骨/下颌、鼻形、眼形眼色、眉形、嘴唇；选择2—3个识别特征，保留小幅自然不对称。
3. 皮肤：保留符合年龄和观看距离的毛孔、细绒毛、眼周细纹、局部轻微色差与自然不对称。依据用户描述或参考图决定皮肤状态；不自行添加伤疤、污渍或明显衰老。冷酷、嗜血或反派气质通过眼神与表情体现。
4. 发型：发色、发长、发际线、分缝、盘发位置及有限饰品。背面发型必须可由正面设定推导。
5. 衣装：各层衣服从内到外的材质、领型、长短、袖口、裤/裙、鞋，使用少量清晰主色和大块整洁表面。
6. 一致性：锁定发型、衣领交叠方向、扣件、腰带、配件数量和位置。用“人物自身左/右”记录非对称细节，并注明正背面在画面中左右会变化，不能简单镜像。

按用户要求或认可参考图写明分栏穿戴状态。右栏要求摘面罩时，只在右栏摘下；不能推导为全部栏摘下。左栏包含头部且角色佩戴面罩时保留面罩；左栏头部在取景外时，面罩也在框外。摘下的面罩无需出镜，不擅自改为胸前悬挂、手持或腰挂。兜帽的佩戴/收起状态遵从用户或参考；用户要求所有栏遮脸时保留遮脸。

不要为表现真实堆叠罕见病征、伤疤、泥点或衰老。真实感依靠形体、材质和光线共同成立。

## 真人实拍质感

使用“真人演员试装与定妆摄影、实际衣料、保留自然皮肤细节的照片”作为主要媒介描述。保留演员的骨相、局部肤色差异、自然不对称及眼周阴影。概念设计、游戏资产、超写实3D、数字人等词容易把媒介引向渲染，应避免。

- 光：正前上方大面积柔和漫射日光，有轻微方向性、柔和体积过渡、鞋底接触阴影；眼睛有小而自然的高光。画面不出现灯具或摄影棚设备。
- 色：中性白平衡、自然肤色、克制饱和度和适中反差，保留暗部细节。资产图不默认套用影片场景的青橙调色、暗绿阴影或戏剧性低调光。
- 镜头：全身用自然人像透视和躯干高度机位；头像用眼平、约85mm人像透视作为视觉意图。不要谎称生成图真的使用了某支镜头或胶片。
- 皮肤：保留正常观看距离可见的自然皮肤结构、轻微色差、面部体积与真实反光；眼睛、眉毛、唇缘和发型清晰。浅肤色不写成粉白或瓷白。柔光是照明方式，不等于模糊或均匀化皮肤。
- 衣料：通过重量、厚度、缝线、受力褶皱和局部磨损表现材质。磨损集中在合理部位，如袖口、领缘、鞋底；大部分表面保持完整。
- 细节层次：全身图依靠轮廓、衣料厚度、受力褶皱和扣件结构；头像保留与放大尺度相符的五官和自然皮肤细节。避免全身图呈现微距般的夸张纹理，也不把头像处理成无毛孔的平滑表面。

### 首版肤质：自然细节与人物身份共同保留

在身份与五官之后，用简短描述写入以下语义；根据用户年龄、肤色及参考调整，中文与英文保持一致。自然皮肤描述写一次，不在多个段落反复压低皮肤微反差或强调柔润、细腻：

先确定画面中可见的皮肤范围。全部视图的脸和皮肤均被衣装遮蔽时，省略肤质段，直接约束遮蔽状态、体型和衣装；仅有局部皮肤可见时，把肤质描述限定到该区域。面罩遮挡范围以用户要求为准，不自行扩大到遮住眼睛或缩小为露出嘴鼻。

> 真人演员的自然皮肤，保留与年龄及取景距离相符的毛孔、细绒毛、眼周细节、轻微肤色变化和自然光泽。面部骨相、表情与不对称特征清晰可信，不做美颜磨皮。

英文可用：`Natural human skin with age- and distance-appropriate pores, fine facial hair, subtle eye-area detail, slight local colour variation and natural sheen. Preserve the actor's facial structure, expression and natural asymmetry, without beauty retouching.`

- 无参考的新图使用上述自然皮肤描述。用户认可的实拍参考图优先保留其肤质，不用通用肤质段覆盖它；局部编辑只描述实际缺陷。长串皮肤缺陷词留在检查流程中，不逐字重复到生成提示词的多个段落。
- 以“自然演员定妆摄影”描述媒介；清晰度落在眼睛、发型、缝线与扣件。删去全局性的“极致纹理、每寸清晰、微距毛孔、超强微反差、raw gritty skin、hyper-detailed pores、8K skin detail”。不把“未经修饰 / unretouched”当作强化皮肤粗糙度的要求。
- 年轻与中年角色不凭空添加明显疲惫、密集皱纹、斑点、胡茬或伤疤；保留与年龄相符的自然细节和参考已有的身份特征。用户明确要求老年、疲惫、伤疤或特效妆时照做。

### 材质按对象描述

| 对象 | 首版写法 |
| --- | --- |
| 皮肤 | 自然毛孔、细绒毛、轻微色差、真实反光与面部体积 |
| 衣料 | 厚度、重量、缝线、织物组织、受力褶皱和合理局部磨损 |
| 金属与陶瓷 | 形体、连接、受控反光；仅用户指定部位有局部磨损 |
| 机械与科技道具 | 明确固定点、承重关系、数量和位置；未启动状态按用户要求表现 |

把磨损直接绑定物件，例如“数据卷轴金属外壳边缘少量磨损，其余大部分表面完整”；避免用一条覆盖所有材料的“粗糙、风化、颗粒丰富”。巨刃通过背架、卡扣和承重带连接身体，视觉上能解释重量；未启动的导槽不自动加发光、黑烟或粒子。复杂装备增加的是结构信息，皮肤段保持简洁稳定。

### 局部处理异常纹理，保留真实材质

先区分自然细节与生成伪影：自然毛孔、细绒毛、织纹、眼周细纹与轻微肤色差异属于真实材质；跨材质均匀铺满的砂点、重复噪点、翘起白屑或不合理裂纹属于待检查的异常。不能把局部白屑问题扩展为全图去纹理。

- 用户要求抑制点状纹理时，明确限定对象、区域和异常类型，例如“清除鼻翼异常白屑，保留周围正常毛孔与肤色变化”。
- 不在全图使用“大面积色块、统一低对比、压低所有微观细节”替代摄影质感；衣料保留织纹、厚度与褶皱，金属保留真实反光。
- 检查实际异常后只修失败项，保留五官和衣装清晰度。用户明确要求的雀斑、纹身与特效妆属于角色特征，不能一并当成噪点删除。

## 提示词组织

按以下顺序写成一个完整提示词：

1. 媒介、参考职责与三栏版式：优先使用用户明确要求或认可参考的取景和穿戴状态；无参考时采用横向16:9、28/28/44默认值。
2. 演员：年龄、体型、少量识别性五官、发型、克制表情与分栏遮脸状态。
3. 简短肤质描述：保留自然细节；有认可参考时锁定参考肤质。
4. 衣装与装备：层次、结构、材质各自作用范围、固定关系及人体左右一致性。
5. 摄影：共用背景、柔光、中性曝光、自然透视、清晰五官与适度材质层次。
6. 一句集中排除：文字、额外视图、CG感与美颜磨皮；异常纹理只写实际相关项。

把核心提示词控制在约350—650英文词或信息量相近的中文作为精简参考；详细角色可以更长，保留用户必要信息。先删重复排除词、重复画质形容词和臆加细节，不删用户设定。不要把整份技能和检查清单复制给生成工具。

用户只要可复制提示词时直接给成品，勿把内部检查流程当成结果。用户要实际图时执行生成并展示真实输出。

## 生成与迭代

- 使用当前可用的图像生成工具。用户指定Higgsfield时先用该服务，读取当前模型参数与参考图角色规则；不要把网页显示名称当作模型ID。
- 历史案例中的模型名称和2K设置仅是来源记录，不保证当前账户可用。遇到套餐/权限限制时说明未提交成功，再使用用户允许的可用替代，并明确结果不是原模型复现；不升级套餐或自动重复付费任务。
- 首次按一次生成一张三联图验证。不要因“更稳定”默认发起多张付费生成。
- 用户只要求迭代技能时，完成技能更新与文本应用检查；实际生图验证在用户要求的范围内进行，不为宣称技能优化成功而额外自动生图。
- 若身份不稳，先固定一张同角色头像/定妆基准，再将其作为身份参考生成其余视图；严格分离身份参考和排版参考。需要增加生成数量或费用时遵循工具的授权规则。
- 出现“起皮、干裂、粉状斑驳”时，引用原图作为编辑目标，限定实际缺陷位置和范围；保留周围正常毛孔、细绒毛、肤色差异、面部结构、年龄、身份、发型、衣装与版式。只处理局部异常表面，不整脸磨皮、统一肤色或降低全图清晰度；不能把局部修复配方自动写入所有后续首版。
- 单次生成与编辑的对比只能说明这次结果有改善，不能证明某个词是确定原因或宣称首版成功率提高；有后续生图对照证据时再报告视觉验证结论。
- 修正时锁住合格部分，只修改失败项。若采用分别生成再拼合，准确说明结果经过拼合，不称一次生成；保持光色、比例与身份一致。
- 按工具要求等待状态并展示，不把提示词交付、已提交或排队描述为图片完成。不要凭任务ID宣称视觉合格。

## 交付前检查

逐项查看实际图片；无法查看时明确说明只做了文本检查：

- 是否恰好三视图，顺序与取景符合本轮要求或认可参考？无参考的默认顺序为无头正面衣装、完整背面、正面头像。
- 是否为同一成年人，脸部比例、年龄、肤色、发型、衣领和服装一致？
- 是否完整显示双手和两双鞋，中栏完整发型，右栏完整头顶？
- 是否正背体型与鞋底基线匹配，配件数量和人体左右位置正确？
- 面罩、兜帽的分栏状态是否符合用户或认可参考？是否擅自增加/删除完整头部、将面罩挪到胸前、手里或腰侧？
- 是否有自然体积光、皮肤过渡和衣物重量，没有CG塑料感或美颜脸？
- 在整体观看与头像正常大小下，额头、鼻翼、双颊和下巴是否保持连续自然的肤色，无翘起皮屑、干裂、粉状白斑或砂纸感？皮肤伪影不应被解释为“更真实”，出现时应列为失败项并修正。
- 额头与双颊是否出现不符合年龄的密集细纹，面部是否因过度抑制纹理变成蜡像？按实际观看尺度判断，不把极端放大后的正常细节误判为缺陷。
- 是否只去除异常散点、白屑和过度锐化，并保留正常毛孔、局部肤色差异、织纹、衣物褶皱与真实材质反光？
- 若参考只用于排版，是否确实重新设计人物与衣装？

报告实际局限；不要承诺单张生成能严格保证身份一致或像素级排版。
