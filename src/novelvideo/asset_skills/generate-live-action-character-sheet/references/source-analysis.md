# 来源与方法分析

来源：Higgsfield 用户 pandaproduction 的公开项目 [THREAD](https://higgsfield.ai/@pandaproduction/projects/thread)。于2026-11-02通过页面的资产详情查看两张女性头像和一张女性正面全身图的提示词与参数。

## 实际读取的内容（摘要，不逐字复制原文）

- 三个抽查人物资产均标为 Nano Banana Pro、2k；头像尺寸1696×2528，全身1536×2752。
- 单张资产分别描述一个正面头肩头像或一个正面完整站立全身，并非多格版式图。
- 提示词先固定拍摄对象数量、无缝中灰背景、机位、取景与正前上方漫射光，然后描述演员具体五官、肤色与不对称特征。
- 五官不使用单一“美女”概念；描述脸型、鼻子、嘴、眼睛、眉毛，再补少量年龄或生活痕迹。
- 根据剧情状态写出疲惫、肤色泛红、潮湿头发与磨损衣料；情绪主要是克制的表情，不依赖夸张表演。
- 服装细化到具体面料、轮廓、系结方式、褶皱和磨损位置；历史年代为1780年代。
- 明确排除美妆、时尚广告式人物、修图、机械对称和磨皮。资产光色自然中性。

## 由此归纳的可复用写法

摄影约束 + 可识别的演员形体 + 具体皮肤状态 + 实际衣料行为 + 排除美颜/渲染。

把普通人的自然差异与可解释的材质行为写清，比反复堆砌“8K、超真实、极致细节”更有操作性。这是基于上述案例的归纳，不是已进行模型对照实验的性能结论。

## 第二来源：教师四宫格提示词与版式示例图（2026-11-17）

用户在对话中提供两张图片：一张是教师讲解视频的截图，内含一段英文提示词；另一张是竖版四宫格版式示例图。以下只记录实际读到和量到的内容。

### 教师提示词（视频截图，逐项归纳，未逐字复制）

- 任务：把上传的角色参考图转成4格角色设定图；上传图是唯一设计来源，要精确保留五官、发际线与发型、年龄、肤色与皮肤质感（真实毛孔）、体型与重量、全部衣装细节与鞋；不美化、不重设计、不改善脸；四格是同一人。
- 版式：单张图，2×2，四个等大格，细分隔线，各格角落有小号角标 FACE FRONT / FACE SIDE / BODY FRONT / BACK。
- 逐格：左上正面头肩特写，表情平静中性；右上同一取景尺度的纯侧面，表情与发型状态相同；左下全身正面，**脸部有意处理成无五官、低细节，留给后期编辑**，双臂自然垂下；右下全身背面，同一站位。
- 摄影棚：无缝背景和光色用占位符，单一硬主光位于镜头左侧45°，无补光，无布景和道具，地面只有自然接触阴影。
- 质量与排除：用于影片制作的摄影式设定图，曝光均匀，织物织纹准确，哑光皮肤，真实毛孔；排除美颜滤镜、偶像妆、塑料皮肤、瘦脸、放大眼睛、磨皮、格间姿势变化、增加配件、身高变化、环境色溢出和轮廓光。
- 截图上叠有视频字幕“啊可能有点长”，说明讲者也认为这段提示词偏长。字幕遮住了 AVOID 里 FACE 条的结尾（可见到 “no skin smoothi”）和 BODY 条的中间部分；截图到 LIGHT 条为止，我不能确认提示词是否还有后续内容。

### 版式示例图（755×1248，约0.605:1；9:16为0.5625:1）

- 测量方法：用脚本找分隔线，再对中心列取暗像素范围；这是对一张压缩截图的近似值，边缘有截图边框和暗角，不是原图数据。
- 分格：竖直分隔线在 x=379，水平分隔线在 y=621，四格近似等大（379×621、375×621、379×626、375×626）。
- 上排：左格正面头肩特写，右格纯侧面，同一人，同一布光。
- 下排：左格 BODY FRONT 全身正面，**脸部是一块无五官的肤色椭圆**（约占格宽7%—8%、格高8%—9%），头发、发际线、颈部、衣领和肩线保留；右格 BACK 全身背面，同一站位。放大后看，这块椭圆颜色均匀、偏粉，与灰色背景和黑发的反差明显，像是后期涂抹或高度平滑的结果。我无法判断它是模型直接生成的，还是生成后处理的；这也是技能保留无头备选和局部编辑指令的原因。
- 全身格：人物约占格高90%—91%；按人物暗像素范围估算，发顶距上缘约5%，鞋底距下缘约3%—4%。
- 角标：只有下排两格有可见小角标（BODY FRONT、BACK，位于各格左上角，白色小号无衬线字）；上排两格在左上角没有可见文字，尽管教师提示词要求四格都有。这一差异的原因我没有核实。
- 背景与光（目测，未量化）：中灰背景，带轻微明暗渐变；地面阴影边缘偏柔，不像强硬光。示例人物为黑色长发、全黑哥特式多层衣装，此示例的人物特征不属于技能默认设置。

### 对本技能的影响

- 版式由横向16:9三联改为竖版9:16四宫格，BODY FRONT 脸部默认用空白脸，用户要求时改为无头（用户明确提出做不到空白脸时的备选）。
- 参考图转换结构沿用教师提示词的大写小标题，作为示例B。
- “硬光”与示例图的柔阴影存在出入，技能默认写“边缘柔和的单一主光”，用户要硬光时照写。
- 以上是依据一份教师提示词和一张示例图归纳的规则；我没有用任何图像模型做生成对照，不知道各模型能否稳定生成“空白脸”，所以技能里保留无头备选和局部编辑指令。
