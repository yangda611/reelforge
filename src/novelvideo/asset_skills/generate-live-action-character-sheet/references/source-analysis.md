# 来源与方法分析

来源：Higgsfield 用户 pandaproduction 的公开项目 [THREAD](https://higgsfield.ai/@pandaproduction/projects/thread)。于2026-11-02通过页面的资产详情查看两张女性头像和一张女性正面全身图的提示词与参数。

## 实际读取的内容（摘要，不逐字复制原文）

- 三个抽查人物资产均标为 Nano Banana Pro、2k；头像尺寸1696×2528，全身1536×2752。
- 单张资产分别描述一个正面头肩头像或一个正面完整站立全身，并非用户要求的横向三联图。
- 提示词先固定拍摄对象数量、无缝中灰背景、机位、取景与正前上方漫射光，然后描述演员具体五官、肤色与不对称特征。
- 五官不使用单一“美女”概念；描述脸型、鼻子、嘴、眼睛、眉毛，再补少量年龄或生活痕迹。
- 根据剧情状态写出疲惫、肤色泛红、潮湿头发与磨损衣料；情绪主要是克制的表情，不依赖夸张表演。
- 服装细化到具体面料、轮廓、系结方式、褶皱和磨损位置；历史年代为1780年代。
- 明确排除美妆、时尚广告式人物、修图、机械对称和磨皮。资产光色自然中性。

## 由此归纳的可复用写法

摄影约束 + 可识别的演员形体 + 具体皮肤状态 + 实际衣料行为 + 排除美颜/渲染。

把普通人的自然差异与可解释的材质行为写清，比反复堆砌“8K、超真实、极致细节”更有操作性。这是基于上述案例的归纳，不是已进行模型对照实验的性能结论。

## 针对本技能新增的规则

三联布局、无参考时的左侧颈根裁切与28/28/44比例、正背面尺度对齐、配件人体左右锁定、反向排版参考泄漏和异常点状纹理的局部处理，均为本技能针对用户需求整合的规则，不宣称是作者原始配方。用户认可参考图的取景、穿戴与质感优先于这些默认值；正常皮肤与织物细节不属于待去除的噪点。
