- 科幻装备：替换衣装段，保留用户要求的层次、连接点、承重、数量、位置和开关状态；不用额外的皮肤纹理强化科幻感。
- 面罩与兜帽：在演员段分别指定各栏穿戴状态。右栏露脸不改变其他栏的面罩状态。认可参考左栏为佩戴面罩的完整全身时照此保留；采用无头默认裁切时面罩在框外，不挪到胸前或腰侧展示。摘下的面罩无需出镜。
