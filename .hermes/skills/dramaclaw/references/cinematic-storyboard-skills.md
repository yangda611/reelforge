## 二、Skill 1：15 套景别组合与情景应用

1. **五级标准景别**：`远景`（环境吞没人物）、`全景`（全身+空间走位）、`中景`（膝/腰以上双人互动）、`近景`（胸以上情绪微表情）、`特写`（器官/关键道具戏剧重音）。
2. **15 套经典组合速查（01–15）**：
   - **2 镜头**：`01 远+近`（环境孤独→情绪特写）、`02 全+特`（空间确立→戏剧钩子）、`03 中+特`（互动→关键细节）。
   - **3 镜头**：`04 远+全+近`（渐进压入）、`05 全+中+特`（线性递进）、`06 中+近+特`（冲突升级）、`07 近+特+近`（心理震荡）、`08 特+近+全`（局部悬念→拉全揭晓）。
   - **4 镜头**：`09 远+全+中+特`（完整叙事链）、`10 全+中+近+特`（紧凑情绪递推）、`11 特+近+中+全`（悬念开局→空间释放）、`12 中+特+近+特`（双人交锋/心理反打）。
   - **5 镜头**：`13 远+全+中+近+特`（终极线性递进）、`14 特+近+中+全+远`（倒置抽离/悲壮落幕）。
   - **6 镜头**：`15 全+中+近+特+近+全`（标准封闭戏剧弧光）。
3. **防同质化铁律（严禁连续相近中景死切）**：
   - 同一场景内**严禁连续 3 拍及以上相同角度、相同景别（如连续中景正反打）**；必须推进景别梯度、调整机位角度，或穿插手部动作/眼神/关键道具特写。
4. **静态瞬时画面 vs 动态运镜分离**：
   - 分镜首帧 `visual_description` / 草图只写静态构图与动作起势瞬间，不混入连续推拉摇移过程。

## 三、Skill 2：阿泽 AI 运镜系统（5 变量、视差证明与 26 卡）

1. **摄影机 5 变量（必须与人物动作分离描写）**：
   - `前后推拉 (Dolly In/Out)`、`轴线摇俯 (Pan/Tilt/Dutch)`、`垂直升降 (Crane/Pedestal)`、`横向与环绕 (Truck/Arc Orbit)`、`焦距变化 (Optical Zoom)`。
2. **可见视差证明（拒绝 2D 贴片感）**：
   - 凡涉及机身位移的运镜，必须写明前景遮挡物、中景主体与远景建筑之间的相对位移差。
3. **光学因果与希区柯克变焦（`f/d` 守恒）**：
   - 物理推轨改变透视与视差；长焦变焦仅压缩纵深无视差；滑动变焦必须明确“机身快速后拉的同时光学长焦推进（或反之），人物在画面中占比不变而背景急剧拉伸/压缩”。
4. **18 类运镜架构与 26 张标准卡（A01–A26）+ 固定机位锁**：
   - 依据叙事目的选用推进、拉远、横移、环绕、跟拍、升降、穿越、希区柯克或一镜到底；当 `[LOCKED FIXED CAMERA]` / `lock_camera_beat` 生效时严禁推拉摇移，仅保留人物与环境内部运动。

## 四、Skill 3：AI 分镜转场系统（6 大无痕桥梁）

相邻 Beat 与跨集开篇衔接必须显式选用至少一种转场逻辑：
1. **动作顺接 (Action Match)**：上一拍发力起势 → 下一拍换景别接住落点动作；
2. **相似形 / 构图 / 色彩匹配 (Form/Composition/Color Match)**：几何轮廓、画面重心或色调跨时空对齐；
3. **视线顺接 (Eyeline Match)**：角色凝视方向 → 切向视线目标或反应表情；
4. **前景遮挡擦除 (Foreground Wipe)**：前景门框/背影/货架掠过实现无缝换景；
5. **甩镜动势 (Whip Pan)**：高能同行向动势模糊过渡；
6. **声画错位 (J-Cut / L-Cut)**：声音先入画面或尾音延展缝合两镜。
